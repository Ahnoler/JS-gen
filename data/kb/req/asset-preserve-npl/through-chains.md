> 视图2（主链清单）。每条主链：闭环目标 / 有序步骤 / 前置条件 / 章节出处。状态口径：录入完成 → 审批中 → 审批通过（已生效）/ 审批否决（退回草稿）。

## 主链 1：债务减免申请 → 审批 → 批复 → 执行登记

- **闭环目标**：对不良资产借据发起债权减免，经多级审批通过后下载批复并完成减免执行登记。
- **前置条件**：用户为法人行级保全经理（或本机构角色）；客户为保全管辖内不良资产客户；该借据无在途冲突流程（文档未声明减免在途校验，参照诉讼口径，待湿测）。
- **步骤**：
  1. 查询减免申请主页【ZJJK00210761】→【新增】→ 选择客户类型弹窗（必选，否则提示「请先选择客户类型！」）→ 客户查询弹窗；
  2. 新增减免申请大页面（场景 FS00084850，流程 AP_RELIEF_APLY）任务页【ZJJK00210791】按步骤录入：基本信息【ZJJK00210495】（可【金额试算】）→ 查询借据信息【ZJJK00248265】（新增/删除借据）→ 查询减免信息【ZJJK00210756】（修改弹窗 ZJJK00211435）→ 查询担保合同【ZJJK00211237】→ 查询抵质押物【ZJJK00210751】→ 提交影像资料【ZJJK00211311】→ 尽职调查报告【ZJJK00248159】→ 提交减免申请【ZJJK00210607】；
  3. 有权限用户审批任务页【ZJJK00210606】：查看信用风险委员会审议结果【ZJJK00210544】→ 新增有权机构审批结果【ZJJK00210543/弹窗 ZJJK00211337】→ 撰写批复意见【ZJJK00210542/弹窗 ZJJK00211336】→ 提交；节点配置见 AP_RELIEF_APLY（对公线/普惠线多级：支行保全审核/审查/审批 → 总行资产保全部 → 风委会 → 行长办公会）；
  4. 审批通过后主页【下载批复】；
  5. 查询债务减免申请列表主页【ZJJK00210444】→【执行登记】→ 执行登记债务减免大页面（FS00084841，任务页 ZJJK00210797 保存、查询基本信息 ZJJK00210494、查询借据信息 ZJJK00210493）。
- **章节出处**：03-债务减免管理.md（新增减免申请 / 查询执行结果）。
- **建议挂载**：叶子 `减免申请-提交`、`减免审批-同意`、`减免-执行登记`。

## 主链 2：不良资产核销申请 → 审批 → 执行登记

- **闭环目标**：呆账核销方案从录入到审批生效并完成执行登记。
- **前置条件**：客户经理（本人经办）/审批人员权限；借据属可核销不良资产（文档未给校验，待湿测）。
- **步骤**：
  1. jlnx-核销申请主页面主页【ZJJK00210703】→【新增】（方案编号 = HX+机构编号+8位随机数字）；
  2. 新增核销申请大页面（场景 FS00084840，流程 AP_WRIOFF_APLY）录入核销方案 → 提交；
  3. 审批核销申请任务页审批（同意/不同意/退回）；
  4. 审批通过后【下载批复】；
  5. 核销查询主页【ZJJK00210569】→【执行登记】→ 执行登记核销方案大页面（场景 FS00084847）。
- **章节出处**：04-不良资产核销.md（新增核销申请 / 查询执行结果）。

## 主链 3：表外销案申请 → 审批 → 下载批复

- **闭环目标**：表外资产销案从申请到批复落地。
- **前置条件**：表外销案主页菜单权限（ZJJK00160058JLCP）。
- **步骤**：主页【ZJJK00160058JLCP】→【新增】→ 新增表外销案大页面（场景 FS00084814，流程 AP_WRIOFF_SALES）→ 提交审批 → 审批通过【下载批复】；草稿可修改/取消。
- **章节出处**：04-不良资产核销.md（表外销案）。

## 主链 4：司法诉讼申请 → 审批（AP_LGT_LGTAPLY）

- **闭环目标**：对不良资产借据发起诉讼申请，经多级审批生效。
- **前置条件**：法人行级保全经理（本人经办）；一般/应诉案件一审或非标程序对应的借据/案件数据可用。
- **步骤**：
  1. 管理-司法诉讼主页【ZJJK00210734】→【新增】→ 向导第一步选业务类型（01 诉讼申请，需选客户类型）；
  2. 向导第二步：选申诉案件类型 + 是否一审 → 从客户/案件列表选中记录（一审或非标程序 → 全辖借据中主办资产保全经理=当前用户；非一审 → 本人经办案件）；
  3. 确认进入新增诉讼场景 FS00084823，任务页【ZJJK00210583】三步：基本信息（方案/借据/当事人/抵质押物/担保合同）→【下一步】（必填校验 + 在途校验：存在审查审批中的在途诉讼申请则提示借据编号并中断）→ 影像信息 → 签署意见 → 提交；
  4. 审批流 AP_LGT_LGTAPLY：客户经理提交 → 一级支行资产保全部负责人 → 二级支行行长 → 总行资产保全部总经理 → 中心支行资产保全部负责人（同意/不同意/退回发起人）。
- **章节出处**：05-司法诉讼.md（新增司法诉讼）+ 06-业务审批流程.md（诉讼申请-新增诉讼）。
- **旁路**：变更诉讼（FS00084822）/ 撤诉（FS00084824）复用同一流程 AP_LGT_LGTAPLY；诉讼登记各审级场景（一审 FS00084830、二审/再审 FS00084914、公证 FS00084826、仲裁 FS00084827、破产 FS00084828、实现担保物特别程序 FS00084829）走 AP_LGT_REGISTER。

## 主链 5：诉讼执行情况登记 → 结案

- **闭环目标**：诉讼案件执行结果登记并结案。
- **前置条件**：存在已生效（审批通过）的诉讼/诉讼登记方案。
- **步骤**：管理-诉讼登记主页【ZJJK00210699】→【执行登记】→ 提交执行情况审批流程；后续对已结案件【结案】。
- **章节出处**：06-业务审批流程.md（新增执行情况登记）。
- **待湿测**：结案状态迁移与案件登记模块联动。

## 主链 6：债权重组申请 → 审批 → 执行登记

- **闭环目标**：债务重组方案审批生效并完成重组执行登记。
- **前置条件**：法人行级保全经理（本人经办）/其他角色（本机构及下级）。
- **步骤**：
  1. 债权重组主页【ZJJK00211296】→【新增】→ 债权重组大页面（场景 FS00084843）录入重组方案 → 提交审批；
  2. 审批通过后【下载批复】；
  3. 重组登记主页【ZJJK00211278】→【执行登记】→ 债权重组执行登记大页面（场景 FS00108604）。
- **章节出处**：07-债务重组.md（新增债权重组流程 / 新增债权重组执行登记）。

## 主链 7（子链）：已核销资产分类认定与重检

- **闭环目标**：对已核销资产做分类认定（首分/定期重检）与及时重检，并审批分类结果。
- **前置条件**：资产已核销完成（主链 2 之后）。
- **步骤**：已核销资产主页【ZJJK00210539】→ 资产分类认定与重检（分类认定大页面 FS00084816 / 及时重检认定大页面 FS00084815，流程 AP_WRIOFF_CATG）→ 提交；审批资产分类结果任务页分类认定 → 返回；配套：财产线索核查（详情 FS00084818）、重大项目管理（FS00084817）。
- **章节出处**：04-不良资产核销.md（查询已核销资产 / 审批资产分类结果）。
