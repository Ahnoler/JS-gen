# 业务综述（O01 统一门户需求分册）

- 标题路径：业务综述 > 业务范围 > 涉及用户 / 功能清单；业务综述 > 参考资料 > 系统岗位角色 / 系统菜单与角色对应关系

## 涉及用户
- 系统管理员、行长、主管、客户经理等。

## 功能清单（两级结构摘要）
- 首页：主题切换、布局切换、菜单搜索、自定义首页、用户（机构/角色）切换、卡片功能（常用功能、待办功能、消息中心、系统公告、日历）。
- 系统管理 > 基础管理：
  - 卡片库管理：列表查询 / 新增 / 修改 / 删除
  - 子应用管理：列表 / 新增 / 修改 / 启用 / 禁用
  - 搜索历史管理：查询 / 删除
  - 图片库管理：列表查询 / 新增 / 修改 / 删除 / 查看
  - 首页管理：自定义首页（含角色卡片库查询）
  - 公共信息配置管理：公共信息配置 / 水印配置
  - 外系统接入管理：列表查询 / 新增 / 修改 / 删除

## 系统岗位角色
- 客户经理、系统管理员。

## 菜单与角色对应关系（规则）
- 首页全部功能（主题/布局切换、菜单搜索、自定义首页、用户切换、5 类卡片）→ **客户经理**。
- 卡片库管理、首页管理、图片库管理、公共信息配置、子应用管理、外系统接入管理 → **系统管理员**。
- 搜索历史管理 → **客户经理**。
