# 首页 · 个性化设置（O01 统一门户需求分册）

- 标题路径：首页 > 主题切换 / 布局切换 / 菜单搜索 / 自定义首页 / 用户（机构、角色）切换
- 操作权限：均为客户经理（用户切换节正文写“系统管理员”，见下方差异）。

## 主题切换
- 功能：切换首页主题颜色，提供白色、蓝色、黑色三种主题。
- 操作流程：登录 → 点击右上侧【主题切换】按钮 → 切换主题。
- 业务规则 / 业务要素 / 外部接口：均无。

## 布局切换
- 功能：切换菜单布局，提供水平布局、垂直布局两种。
- 操作流程：登录 → 点击右上侧【布局切换】按钮 → 切换布局。
- 业务规则 / 业务要素 / 外部接口：均无。

## 菜单搜索
- 功能：按关键词搜索系统菜单，快速打开目标菜单页面。
- 操作流程：点击右上侧【菜单搜索】按钮 → 弹出下拉列表输入关键词 → 搜索符合条件菜单列表 → 点击节点跳转目标菜单页面。
- 关键规则：可搜索范围为**当前用户有权限的全部菜单**。

## 自定义首页（用户侧）
- 功能：用户按自身业务需求与操作习惯设置首页登录展示；从卡片库中选择卡片，用拖拽 + 设置大小的方式自定义首页布局。
- 操作流程：点击上方导航栏【自定义首页】进入 → 拖动所需卡片到右侧展示区域，设置卡片颜色、大小等 → 点【完成】保存自定义设置。
- 关键规则：左侧可供选择的卡片数据**来源于首页管理中对应角色已配置的卡片信息**（依赖系统管理-首页管理）。

> SUT 实测 2026-09-06（叶4）：入口存在（顶栏 tooltip=「自定义首页」），配置页标题「检查管理组长-首页配置」，右侧展示当前首页全部卡片（待办/系统公告/常用功能/提醒事项/3 个统计卡），左侧卡片库面板（「全部」tab+关键字搜索框）。差异①（wording）：底部按钮为【取消】【预览】【保存】，非文档口径【完成】——SUT 用户侧与管理员侧同为【保存】。差异②（behavior）：左侧候选卡列表显示「暂无匹配卡片」（当前角色「检查管理组长」左侧可选卡片库为空，而右侧已展示卡片）——候选卡库与首页管理角色配置不同步或该角色未配置候选卡（对照章8 叶24/25 管理员侧同现象）。以 SUT 实测为准，原需求口径保留待角色配置数据复核。未保存，【取消】关闭。


## 用户（机构、角色）切换
- 功能：用户根据业务需求切换所属机构、部门和角色。
- 操作流程：点击上方导航栏用户图标弹出用户信息弹框 → 点击角色信息弹出【机构、角色切换弹框】→ 选择所需机构、角色。
- 关键规则：角色切换 / 机构切换两种模式由后端配置参数 `sys.switchTp` 控制（role-角色切换；inst-机构切换）。
- 业务要素（输出）：
  - 角色名称（文本，只读）：反显当前登录用户归属的所有角色。
  - 机构名称（文本，只读）：根据当前角色反显该角色下归属的机构。

> SUT 实测 2026-09-06（叶5）：structure drift——用户图标点击弹的是**用户信息卡**（角色：检查管理组长／法人机构／机构／电话 + 临时转授权/修改密码/退出），点「角色：」行弹出角色列表；**非文档所述模态【机构、角色切换弹框】**，实为悬浮卡+角色下拉列表。角色列表 35 项均为「角色名-机构名」合体格式（如「客户经理-9881**银行股份有限公司」「系统管理员-9881**银行股份有限公司」），role/inst 两模式无独立入口（与 `sys.switchTp` 单参数口径相符，但文档描述的独立弹框形态不成立）。只读未切换角色。

- 自定义首页保存按钮文案：用户侧为【完成】，管理员侧（首页管理）为【保存】——待湿测核对。
  - > SUT 实测 2026-09-06（叶4）：已核——用户侧与管理员侧均为【保存】，文档用户侧【完成】文案不成立（wording drift，见自定义首页节引注）。
