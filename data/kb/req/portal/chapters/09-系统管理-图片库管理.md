# 系统管理 · 基础管理 · 图片库管理（O01 统一门户需求分册）

- 标题路径：系统管理 > 基础管理 > 图片库管理（总体描述 / 列表查询 / 新增 / 修改 / 删除 / 查看）
- 菜单路径：系统管理 -> 基础管理 -> 图片库管理；操作权限：系统管理员。

## 总体描述
- 功能：管理统一门户中的图片库信息；图片库中的图片可用于公共信息配置中对应类型的图片选择。

## 列表查询
- 操作流程：进入列表页 → 可输入【图片类型】【是否默认图片】条件 → 点【查询】搜索；【重置】清空。
- 业务要素：
  - 输入：图片类型（下拉，字典 `ImageType`）、是否默认图片（下拉：是/否）均选填；查询/重置按钮。
  - 输出：序号、图片（缩略图）、图片类型、是否默认图片、上传日期（均系统反显）；操作（修改、删除、查看）。

## 新增
- 操作流程：点【新增】弹出页面 → 填写图片信息 → 点【确定】关闭回图片库列表页。
- 业务要素（输入）：图片类型（必填，下拉，字典 `ImageType`）、是否默认图片（选填，开关，默认“非默认”）、图片（必填，文件上传）。

## 修改
- 操作流程：选择需修改的图片 → 点【修改】弹出页面 → 调整后点【确定】回列表。
- 业务要素（输入）：同新增。

## 删除
- 操作流程：选择图片 → 点【删除】→ 弹【提示】框二次确认 → 确认后删除并提示【操作成功】。

## 查看
- 操作流程：选择图片 → 点【查看】弹出【查看】页面。
- 业务要素（输出）：图片（缩略图，系统反显）、是否默认图片（系统反显）、取消按钮。

## 关键规则
- 图片类型取数据字典 `ImageType`；是否默认图片默认为“非默认”；删除需二次确认。
- 与公共信息配置的联动（从图片库选择图片）——待湿测。
