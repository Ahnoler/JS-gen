## 候选可贯通主链

### MC-1 卡片库配置 → 角色首页配置 → 用户自定义首页（核心闭环）
- 闭环目标：系统管理员把卡片引入卡片库并配置到某角色，客户经理在该角色下将卡片拖拽配置为个人首页并保存生效。
- 前置条件：系统管理员账号可登录；已开发卡片组件可用。
- 有序步骤：
  1. 系统管理员：系统管理 → 基础管理 → 卡片库管理 → 新增卡片（所属系统、组件名称、组件路由、卡片名称、缩略图路径、状态）。（chapters/05）
  2. 系统管理员：系统管理 → 基础管理 → 首页管理 → 选择角色 → 自定义首页 → 左侧卡片库拖拽配置该角色首页卡片 → 预览 → 保存。（chapters/08）
  3. 客户经理（同角色）登录 → 首页 → 自定义首页 → 左侧可选卡片即角色已配置卡片 → 拖拽/设大小/设颜色 → 点【完成】保存。（chapters/03）
  4. 首页展示自定义布局卡片（待办、公告、常用功能、消息中心、日历）。（chapters/04）
- 章节出处：卡片库管理 / 首页管理 / 自定义首页（用户侧）/ 卡片功能。
- 待湿测点：卡片删除对已配置角色首页的影响；未个人配置时按角色默认展示。

### MC-2 子应用接入（内嵌子系统）闭环
- 闭环目标：新子系统页面路由配置并启用后，门户可跳转子系统。
- 前置条件：子应用已部署（有地址/端口）。
- 步骤：系统管理 → 基础管理 → 子应用管理 → 新增（应用名称、端口、地址、状态、路由，多路由逗号分隔）→ 启用 → 门户点击子系统功能跳转子系统页面；失效走【禁用】。（chapters/06）
- 待湿测点：跳转入口（菜单）如何挂接子应用路由；禁用后即时生效性。

### MC-3 外部系统接入（链接跳转）闭环
- 闭环目标：无法前端集成的子系统通过系统链接从门户跳转。
- 步骤：系统管理 → 基础管理 → 外系统接入管理 → 新增（系统名称、编号、系统链接）→ 列表查询验证 → 门户跳转外部系统；支持修改/删除。（chapters/07）
- 待湿测点：跳转是否带单点登录/免登参数。

### MC-4 品牌与水印配置生效闭环
- 闭环目标：登录页/首页品牌信息（logo、标题、背景）与页面水印按配置生效。
- 前置条件：所需图片已在图片库。
- 步骤：
  1. 系统管理 → 基础管理 → 图片库管理 → 新增图片（类型 ImageType、是否默认、文件上传）。（chapters/09）
  2. 系统管理 → 基础管理 → 门户公共信息配置管理 → 公共信息配置：设首页标题/导语，从图片库选择/上传各主题 logo、登录页图片背景 → 保存；可还原默认。（chapters/10）
  3. 同菜单 → 水印配置：选文字/图片水印、水印生效 → 保存。（chapters/10）
  4. 重新进入登录页/首页验证展示与水印。
- 待湿测点：水印对已登录会话是否即时生效。

### MC-5 首页日常使用（用户侧短链）
- 闭环目标：客户经理通过首页完成待办处理与信息触达。
- 步骤：登录 → 待办卡片（待办/已办未结/已办已结）→ 点【处理】跳处理页 /【流程跟踪】看流程历史 → 消息中心查看消息详情 → 系统公告看公告详情 → 日历新增今天及以后的提醒（删除需二次确认）。（chapters/04）
- 待湿测点：处理页跳转的目标业务模块（跨册）。

### MC-6 菜单搜索与搜索历史（短链）
- 闭环目标：用关键词快速打开有权限的菜单，且历史可复用/清理。
- 步骤：首页 → 菜单搜索输入关键词 → 点结果跳转菜单页 → 系统管理 → 基础管理 → 搜索历史管理 → 查看/点击历史打开页面/删除记录。（chapters/03、10）
- 待湿测点：搜索历史记录的生成时机与归属（客户经理）。

## 旁路（非主链 / 独立小功能）
- 主题切换（白/蓝/黑）、布局切换（水平/垂直）：页面偏好设置，无后端闭环描述。（chapters/03）
- 用户（机构、角色）切换：受 `sys.switchTp` 参数控制 role/inst 模式。（chapters/03）
- 常用功能设置：添加/删除/排序/图标颜色，仅首页内生效。（chapters/04）
- 图片库的修改/删除/查看：支撑配置的维护操作。（chapters/09）
