# 02 对公还款管理

> 章节路径：`对公还款管理` → `总体描述` / `对公提前还款管理`

## 要点摘要

对公客户提前还款业务全流程：客户经理发起主动（提前）还款申请 → 选择借据 → 风险探测 → 维护借据/还款计划/还款信息/试算 → 提交审批 → 有权审批人审批 → 末节点通过后核心账务扣款 → （必要时）手动推动信贷核算。

- 菜单：`【放还款管理】→【还款管理】→【对公提前还款】`
- 主页：对公提前还款申请管理主页【ZJJK00136653】
- 权限：法人行级客户经理；查询/重置/更多/新增/查看/修改/手动推动信贷核算/撤销/流程跟踪；数据权限=按业务条件查询，无身份维度隔离

## 关键规则 / 字段 / 校验

### 主页【ZJJK00136653】

- 页面初始化：自动分页查询对公客户、还款类型=提前还款、未删除记录。
- 查询条件：aplyNo / cstNo / iouNo / cstNm / ctrNo / crdtNo / aplyStdt~aplyEddt；【更多】展开高级条件。
- 列表列含 流程状态 pcsSt、还款结果 repyRslt、来源渠道 repyChnl（字典见 01 章）。
- 按钮：
  - 【查看】：未选中提示「请选择有效数据」；进入详情（查看模式）。
  - 【修改】：未选中同上；申请状态为「审批中或已通过」时提示「申请状态为审批中、通过状态的数据不允许修改!」中断；否则进详情（可编辑）。
  - 【手动推动信贷核算】：须 流程状态=通过 且 还款结果=待入账，否则提示「需选择流程状态为通过 且 还款结果为待入账的数据!」；还款结果=还款异常时提示「还款结果为还款异常的数据请前往异常管理处理!」。
  - 【撤销】：须还款状态=待发起或打回，否则提示「只允许撤销还款状态为【待发起】、【打回】的还款申请数据！」；确认「确认撤销此条记录嘛？」后终止审批流程、申请状态→已撤销，成功后刷新。
  - 【流程跟踪】：按申请编号查询流程信息，弹窗展示审批历史。

### 向导页：发起主动还款申请主页【ZJJK00148993PDCP】

- 两步向导：基本信息（借据选择）、风险探测。
- 【下一步(基本信息)】未选借据提示「请选择借据进行还款」。
- 【下一步(风险探测)】：风控未通过提示「风险控制未通过！」；校验借款日期不得为当日（提示「还款异常，当日借款不得当日还！」）；查借据/还款账户，调用 C502089 查账户状态与可用余额（状态非正常提示「还款账户状态异常！」）；通过后创建还款申请，编号=`TQHKSQ+yyyyMMdd+6位序列`。
- 选择对公借据信息【ZJJK00098437】：默认查询生效借据、排除已失效、以当前登录用户为经办人过滤；确认/取消按钮始终不展示。
- 风险拦截【ZJJK00067996】：同放款分册对公放款的风险拦截（无差异化规则）。

### 审批流程（场景 FS00028713 / 流程 repayAplyTstPcs）

| 节点 | 任务 | 处理人 | 操作 |
|---|---|---|---|
| 1 | 客户经理发起主动还款申请 | 客户经理/部门客户经理 | 提交 |
| 2 | 有权审批人审批主动还款申请 | 部门负责人/业务部门分管负责人/部门分管领导/需求部门分管负责人 | 提交、退回上一步 |

### 客户经理任务页【ZJJK00136666】

三步：基本信息（借据信息+还款计划+还款信息+试算信息）→ 影像信息（维护文件列表【ZJJK00136662】，内嵌公共影像组件【ZJJK00100615】，同放款分册）→ 审批意见【ZJJK00148812PDCP】（启动流程提交审批）。

- 维护借据基本信息【ZJJK00066404】：全部字段只读（cstNo/cstNm/crdtTp/crdtNo/ctrNo/iouNo/pdNm/iouStdt/iouExdt/iouBal/repyTp/dtsrc/repyChnl）。
- 维护还款计划【ZJJK00098869】：按 iouNo 查还款计划（还款时间/金额/账号）；调 NCMS01050002（借据信息）+ NCMS01050003（还款计划），从账户列表筛选「还款账户」回显账号。
- 维护还款信息【ZJJK00098871】（核心输入页）：
  - 字段：aplyNo（只读）、prerpyTp（必填，InitRepyTp）、aplyRepypnpAmt（必填；提前结清时不可编辑）、repyintAmt/retRcvbPnyint/retRcvbAcrInt/repypnpAmt/totRepyAmt（必填但只读，试算回显）。
  - 【还款计划试算】：提前结清→金额自动=借据余额；部分提前→金额必填（「请填写主动还款金额!」）且 ≤ 借据余额（「输入的主动还款金额不得大于借据余额!」）；部分提前→利息类型=利随本清、金额类型=本息合计；提前结清→全部结息、全部提前还款；调 NCMS01020003；归还本金=拖欠本金+归还未到期本金；还息=拖欠利息+归还未到期利息；罚息取应收总罚息；正常利息取拖欠利息；试算成功再调 NCMS01050002 取还款账号。
  - 【保存】：必须先试算（「请先进行【还款计划试算】操作!」）；保存还款信息+未来还款计划（旧计划标记删除后重建）。
  - 【提前还款类型】规则：提前结清→隐藏还款计划子页面；部分提前→展示。
- 维护还款计划试算信息【ZJJK00100850】：只读展示还款日期/金额/账号，重新试算后刷新。
- 维护审批意见【ZJJK00148812PDCP】流程状态机：
  - 流程启动：传申请编号/客户编号/客户名称/客户类型/合同编号/申请状态入流程。
  - 终止/否决 → 流程状态=审批拒绝，申请状态=失效。
  - 同意 → 流程状态=审批中，申请状态=审批中；不同意 → 审批拒绝/否决。
  - 流程结束（末节点）：通过→核心账务完成还款，流程状态=审批通过、申请状态=生效、还款结果=还款成功；不通过→审批拒绝/失效/已取消。

### 有权审批人任务页【ZJJK00136665】

六个标签页一次性加载：借据基本信息 / 还款计划 / 还款信息 / 还款计划试算信息 / 文件列表 / 审批意见【ZJJK00164421PDCP】。审批意见维护页含流程启动/提交/否决/结束规则（与发起侧一致；启动时按客户类型+还款类型路由审批场景；启动时申请状态置「待还款」；末节点通过调核心账务以还款申请编号为业务编号、提前还款为还款类型记账）。

### 手动推动信贷核算（场景 FS00032603）

- 查询还款试算任务页【ZJJK00140025】：两个标签页「原申请试算还款计划」与「重新计算」；【发送】比对还款总金额/归还本金/归还利息/正常利息/罚息，逐期比对还款账户、金额、日期（忽略时分秒）；不一致提示「重新试算计划和原始试算计划不一致，是否确定发送??」需确认；成功提示「操作成功」；发送成功后按钮隐藏。
- 还款计划试算（原）【ZJJK00101038】：可再点【还款计划试算】重算（NCMS01020003 + NCMS01050002）。
- 获取还款试算（新）【ZJJK00101039】：只读展示新试算结果。
