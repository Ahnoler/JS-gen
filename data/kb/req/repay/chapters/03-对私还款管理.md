# 03 对私还款管理

> 章节路径：`对私还款管理` → `总体描述` / `对私提前还款管理` → `新增对私提前还款申请`

## 要点摘要

对私（个人）客户提前还款业务，结构与对公高度对称：客户经理发起申请（选借据→风险探测）→ 分步维护（基本信息/影像/意见）→ 审批 → 末节点核心账务。差异点在页面 ZJJK 编号、数据权限（本人经办的业务）与部分校验文案。

- 主页：对私提前还款申请管理主页【ZJJK00148777PDCP】
- 权限：法人行级客户经理；数据权限=**本人经办的业务**（比对公的「无身份维度隔离」更严）
- 查询区比对公多 合同编号、还款类型（默认 3=提前还款）两个条件

## 关键规则 / 字段 / 校验

### 主页【ZJJK00148777PDCP】

- 初始化：客户类型=对私、还款类型=提前还款、未删除记录分页展示。
- 按钮：
  - 【新增】→ 打开抽屉【客户经理发起提前还款申请】；新增成功自动刷新列表。
  - 【查看】→ 只读详情；【修改】→ 申请状态为「审批中或已通过」不允许修改；可编辑详情。
  - 【手动推送信贷核算】→ 须流程状态=通过 且 还款结果=待入账；还款异常提示前往异常管理处理（同对公）。
  - 【撤销】→ 须还款状态=待发起或打回；确认「确认撤销此条记录嘛？」后终止流程、申请状态→已撤销。
  - 【流程跟踪】→ 弹窗审批历史。

### 向导页：客户经理发起提前还款申请主页【ZJJK00149019PDCP】

- 两步向导：基本信息（选借据）、风险探测。
- 未选借据提示「请选择借据」（比对公的「请选择借据进行还款」措辞不同）。
- 风险探测【下一步】：风控未通过「风险控制未通过！」；当日借款不得当日还；账户状态非正常「还款账户状态异常！」；通过后创建申请，编号=`TQHKSQ+yyyyMMdd+6位序列`；调 C502089。
- 选择对私借据信息【ZJJK00148781PDCP】：条件 cstNo/cstNm/crdtNo/iouNo；默认排除失效借据；以当前登录用户为经办人过滤。
- 风险拦截【ZJJK00067996】：同放款分册（无差异化）。

### 客户经理任务页【ZJJK00148810PDCP】

三步：基本信息 → 影像信息 → 意见。

- 维护借据基本信息【ZJJK00148784PDCP】：字段同对公版，全只读。
- 维护还款计划【ZJJK00148789PDCP】：NCMS01050002 + NCMS01050003，回显还款账户。
- 维护还款信息【ZJJK00148790PDCP】：与对公版同构（prerpyTp / aplyRepypnpAmt / 试算回显金额）；试算前校验申请编号、提前还款类型、主动还款金额必填；提前结清→金额=借据余额；NCMS01020003 试算；保存前须已试算。
- 维护还款计划试算信息【ZJJK00148802PDCP】：列 序号/计划还款日 plnRepydy/还款金额 crnprdRepyTamt/还款账户账号；文档在此页重复写了试算与保存规则（口径同维护还款信息）。
- 维护文件列表主页【ZJJK00148806PDCP】：内嵌公共影像组件【ZJJK00100615】（同放款分册）。
- 维护审批意见【ZJJK00148809PDCP】：流程启动/提交/否决/结束状态机与对公一致（末节点通过→审批通过/生效/还款成功；不通过→审批拒绝/失效/已取消）。

### 有权审批人任务页【ZJJK00148811PDCP】

六信息区展示（借据/还款计划/还款信息/试算/文件/审批意见）；权限=法人行级审批人、当前法人行所有业务。

### 手动推送信贷核算 / 撤销 / 流程跟踪

- 手动推送：同对公（场景 FS00032603 引用对公章节，无差异化规则）。
- 撤销 / 流程跟踪规则同对公主页按钮规则。
