# 03 贷后预警自动生成

- 标题路径：I02贷后风险预警分册 > 贷后预警 > 贷后预警自动生成 > 新增贷后预警自动生成
- 场景：FS00005836；流程：wf_riskwarn_001（系统预警确认失效流程）

## 要点摘要

- 查询系统生成的预警生成与推送记录，办理确认生效（列表内完成）、确认失效（进任务页走审批）、详情查看。
- 确认失效任务链：任务页【ZJJK00108994】→ 查看客户信息 → 查看合同信息 → 查看借据信息 → 选择预警失效原因 → 影像信息（填报文件列表）→ 签署意见（填报审批意见）→ 提交流程审批。
- 审批链（6 节点，选人模式）：客户经理提交 → 网点负责人 → 部门负责人 → 部门分管领导 → 最终有权审批人 → 部门负责人（复核）。各审核环节的任务页 ZJJK：00109741 / 00109743 / 00109752 / 00109755。

## 关键规则/字段/校验

### 列表主页【ZJJK00110169】
- 查询范围固定为系统预警；列表按预警日期倒序；支持多选批量确认生效，确认失效/详情仅单条。
- 查询条件：客户名称（弹窗客户放大镜 ZJJK00109101 带回）、客户编号（模糊）、预警等级、预警类型、信号状态（多值）、预警日期、指标一级分类、是否逾期、当前逾期天数。
- 输出列表字段：预警类型/等级、客户名称/编号、指标一级分类/名称、预警日期、是否逾期、当前逾期天数、合同编号/金额/余额、信号状态、审批状态（warnPcsSt）。

### 【确认生效】
- 校验：未选记录提示"请选择有效数据"；存在非待确认提示"仅能对待确认的信号做确认生效处理！"；存在未结束且未否决的确认失效审批则中断。
- 确认后：信号状态→已生效、审批状态→通过；同一预警编号只创建一笔待发起的系统预警处置申请并提交处置审批流程；成功后提示并刷新列表。

### 【确认失效】
- 校验：单条；仅待确认；审批状态为空/待发起/打回可继续，否决提示"该预警审批为否决，请点击确认生效"，其他提示流程中勿重复操作。
- 生成失效业务编号；预警等级为二/三级时获取当前机构等级参与审批路径判断；已有待发起/打回申请则沿用不重复创建；发起后审批状态→待发起。

### 任务页与子页
- 步骤序：基本信息 → 影像信息 → 签署意见；【下一步】校验通过才切换。
- 查看客户信息【ZJJK00109353】：客户/预警基础信息只读；对私取个人客户详情（含登记注册、标签、黑名单、配偶、脱贫户、最近年收入），对公取对公详情（含实控人、法代、特种经营、唯一认证）。
- 查看合同信息【ZJJK00108989】：仅展示已放款/已逾期/已转让合同；含合同编号、产品、金额、余额、起止日、状态（RtlCtrStCd）、风险分类（FQ01~FQ05 五级）、经办人/机构。
- 查看借据信息【ZJJK00108990】：排除未生效借据，仅本人经办，登记时间倒序；字段含借据编号/状态（iouSt：1生效 0未生效 2结清 3逾期 4已核销 5已置换 6已冲正 7已转让 8正常）/金额/余额/放款日/到期日/执行利率/展期/续贷次数。
- 选择预警失效原因【ZJJK00108991】：warnSgnlExpyRsnId 单选必填（01数据错误 02阈值不合理 03风险相关性不高 04重复预警 05业务无余额或结清 06其他）；保存时无方案则创建、有则更新。
- 填报文件列表【ZJJK00100615】：业务/客户/合同编号任一存在才展示；影像目录见附件《影像资料目录》。
- 填报审批意见【ZJJK00100595】：apvopn 必填，≤300 字符；查看办理时不可编辑。
- 提交流程审批【ZJJK00109737】：流程启动/提交/取回/撤销/轨迹；启动校验预警等级+编号非空（"入参对象不能为空。"），二/三级预警取机构等级；提交需选流程操作与意见详情，选人不可重复；状态联动：提交→审批中、不同意→否决、回退首节点前→打回、终止→已撤销、结束同意→通过且预警状态→已失效。
