# 02 贷后预警-总体描述

- 标题路径：I02贷后风险预警分册 > 贷后预警 > 总体描述（功能说明 / 业务流程图 / 状态说明）

## 要点摘要

- 贷后预警用于识别和处置客户贷后阶段风险信号，参与角色：客户经理、网点负责人、部门负责人（兼部门分管领导/最终有权审批人处理人）、最终有权审批人。
- 五条能力线：
  1. 系统预警信号处置：客户经理查看客户/合同/借据与处置方案，补影像、签意见后发起审批。
  2. 贷后预警人工发起与处置：客户选择 → 客户/合同/借据查看 → 人工预警信号维护 → 处理方案维护。
  3. 贷后预警自动生成：查询系统生成的预警生成与推送记录，办理确认生效/确认失效/详情。
  4. 贷后预警解除：对符合条件预警发起解除，登记解除原因并跟踪审批轨迹。
- 菜单入口统一为：【风险预警】→【贷后预警】→ 各子菜单。

## 业务流程图（Mermaid 摘要）

- 客户经理全流程：系统自动预警 → 确认生效（生成系统预警处置申请）/ 确认失效（生成失效申请）；人工发起预警 → 处置方案 → 提交审批 → 多级审核；预警信号审批通过 →（失效/已处置）。
- 审批流程：发起申请 → 网点负责人 → 部门负责人 → 部门分管领导 → 最终有权审批人 →（结束/打回/否决/撤销）→ 结果同步预警状态。

## 状态说明（关键状态机）

**预警流程状态**（审批办理阶段）：待发起 → 审批中 → 通过 / 否决 / 已撤销 / 打回（打回 → 待发起）。
- 待发起：审批未正式提交，可补充资料或重新发起
- 审批中：已提交未到最终节点
- 打回：退回首节点；通过：最终同意并同步预警结果；否决：不同意；已撤销：首节点撤销或流程终止

**审批任务处理状态**：待处理 → 已处理（审批人提交任务）。

**预警状态**（业务结果）：
- 待确认 → 已生效（列表确认生效）
- 待确认 → 已失效（确认失效审批通过）
- 处置审批通过 → 已处置（系统预警信号处置流程结束）
- 解除审批通过 → 已解除（贷后预警解除流程结束）
- 码值（预警信号处理状态 warnSt）：01待确认 04已生效 05已失效 06已处置 07已解除 08失效中 09处置中 10跟踪中 11解除中 12已跟踪

## 关键规则/字段/校验

- 预警等级（warnGrdCd）：0提示 / 1一级预警 / 2二级预警 / 3三级预警。
- 预警类型（warnTpcd）：01预警类 / 02提示类。
- 预警来源（warnSrcId，collTskSrccd）：1系统 / 2人工。
