## 主链 1：系统预警确认生效

- 闭环目标：待确认系统预警 → 已生效（并联动生成一笔待发起的系统预警处置申请）
- 前置条件：存在系统生成的信号状态=待确认的预警记录；所选预警无未结束且未否决的确认失效审批
- 有序步骤：
  1. 【风险预警】→【贷后预警】→【贷后预警自动生成】进入列表【ZJJK00110169】
  2. 录入查询条件（客户名称弹窗带回等）→【查询】筛选
  3. 勾选待确认记录（可多条）→【确认生效】
  4. 确认提示后系统置信号状态=已生效、审批状态=通过，创建处置申请并提交处置审批流程
  5. 提示处理结果并刷新列表
- 章节出处：chapters/03（列表主页、确认生效规则）

## 主链 2：系统预警确认失效（wf_riskwarn_001，FS00005836）

- 闭环目标：待确认系统预警 → 确认失效审批通过 → 已失效
- 前置条件：信号状态=待确认、单条；审批状态为空/待发起/打回
- 有序步骤：
  1. 列表【00110169】选择单条 →【确认失效】（校验后打开办理页，生成失效业务编号）
  2. 客户经理任务页【00108994】：基本信息（查看客户信息 00109353 / 合同 00108989 / 借据 00108990 / 选择预警失效原因 00108991 保存）→【下一步】
  3. 影像信息（填报文件列表 00100615，可编辑）→【下一步】
  4. 签署意见（00100595，必填≤300字）→ 提交流程审批【00109737】流程启动
  5. 审批链：网点负责人【00109741】→ 部门负责人【00109743】→ 部门分管领导【00109752】→ 最终有权审批人【00109755】→ 部门负责人复核；支持同意/不同意/退回上一步、取回、撤销
  6. 流程结束同意 → 预警状态=已失效
- 章节出处：chapters/03（确认失效、任务页、各审核任务页、提交流程审批规则）

## 主链 3：系统预警信号处置（wf_riskwarn_002，FS00006002）

- 闭环目标：已生效预警 → 处置审批通过 → 已处置（并自动创建一笔预警解除业务）
- 前置条件：信号状态=已生效；审批状态=待发起或打回；由主链 1 确认生效产生，或直接对存量已生效信号操作
- 有序步骤：
  1. 【系统预警信号处置】列表【00109310】查询 → 选择单条 →【处置】
  2. 客户经理任务页【00109324】：查看客户信息【00109320】/ 合同 / 借据 / 维护贷后预警处置方案【00109321】（调查结果、应急措施、四类处置措施、后续管控）保存
  3. 影像信息（可上传）→ 签署意见 → 提交流程审批【00109758】启动（含智能风控校验）
  4. 审批链：网点负责人【00109764】→ 部门负责人【00109771】→ 部门分管领导【00109772】→ 最终有权审批人【00109775】→ 部门负责人复核
  5. 结束同意 → 预警流程=通过、预警状态=已处置；系统生成贷后预警解除业务编号并创建解除任务（衔接主链 5）
- 章节出处：chapters/04（列表、处置按钮、维护方案、提交流程审批）

## 主链 4：贷后预警人工发起与处置（wf_riskwarn_003，FS00006041）

- 闭环目标：客户经理人工登记预警信号 → 保存生成处置任务 → 审批通过 → 已处置（并创建预警解除任务）
- 前置条件：客户名下存在已放款/已逾期/已转让合同；新增时审批状态为空，修改时审批状态为空/待发起/已撤销且信号状态=已生效
- 有序步骤：
  1. 【贷后预警人工生成与处置】列表【00109786】→【新增】
  2. 任务页【00109819】基本信息：查看客户信息主页【00109793】（【引入】客户放大镜【00109101】选客户，可新增潜户）→ 查看合同信息【00109813】→ 查看借据信息【00112656】
  3. 维护人工预警信号信息【00109816】（预警类型/指标一级分类/等级/触发原因/日期）→【保存】生成预警编号+人工预警处置编号
  4. 维护贷后预警处置方案【00112632】保存
  5. 【下一步】→ 影像信息 → 签署意见 → 提交流程审批【00109818】启动（智能控制校验）
  6. 审批链：网点负责人【00109910】→ 部门负责人【00109911】→ 部门分管领导【00109913】→ 最终有权审批人【00109914】→ 部门负责人复核
  7. 结束同意 → 预警状态=已处置；创建预警解除任务（衔接主链 5）
- 章节出处：chapters/05（列表按钮规则、新增任务页、客户引入、人工预警信号、处置方案、提交流程审批）

## 主链 5：贷后预警解除（wf_riskwarn_004，FS00006051）

- 闭环目标：已处置预警 → 解除审批通过 → 已解除
- 前置条件：信号状态=已处置；客户经理（本人经办）或审查岗（法人行）权限；解除原因可登记
- 有序步骤：
  1. 【贷后预警解除】列表【00109938】查询 → 选择单条 →【解除】（发起"预警解除"审批，审批状态→待发起）
  2. 客户经理任务页【00109932】：查看客户信息【00109927】/ 合同【00108989】/ 借据【00108990】/ 选择解除原因【00109929】（10 项多选，选其他填说明）保存
  3. 影像信息（已有材料不可删改）→ 签署意见 → 提交流程审批【00110251】启动
  4. 网点负责人审核【00109937】：【审批】弹窗填意见提交
  5. 结束同意 → 记录人工解除日期、解除类型=人工、预警状态=已解除
- 章节出处：chapters/06（列表、解除、任务页、解除原因、提交流程审批、网点审核）

## 端到端贯穿主线（跨主链）

> 系统自动预警：待确认 —(主链1)→ 已生效 —(主链3)→ 已处置 —(主链5)→ 已解除
> 人工预警：人工登记 —(主链4 保存)→ 待确认/处置任务 —(主链4 审批)→ 已处置 —(主链5)→ 已解除
> 四条流程共享同一审批状态机与"提交/回退/取回/撤销/否决"状态联动规则（见 chapters/02）。

## 旁路 / 非闭环操作（单列）

- 【详情】/【查看详情】：03/04/05/06 列表单条仅可查看打开场景页。
- 【修改】：人工预警列表（已生效+待发起/空/已撤销）、解除列表（已处置+待发起/打回）。
- 【删除】：仅人工预警列表，审批状态=待发起，逻辑删除。
- 【流程轨迹】：解除列表查看审批历史弹窗。
- 客户放大镜【00109101】/ 新增潜户：公共选择器，可独立新增潜在客户后回带。
- 影像资料目录：填报文件列表【00100615】通用组件，目录规则引用附件《影像资料目录》（本册未含）。

## 建议优先湿测主链

1. 主链 3（系统预警信号处置，含自动创建解除业务的衔接）
2. 主链 5（贷后预警解除，审批链最短、状态机完整）
3. 主链 2（确认失效，二级/三级预警的机构等级审批路径分支）
