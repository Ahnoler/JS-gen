# 03 同业综合授信-新增同业授信：主页与向导页

- 标题路径：同业授信管理 > 同业综合授信 > 新增同业授信（总体说明 / 新增同业授信主页 / 新增 / 向导页）
- 出处：Heading2「同业综合授信」> Heading3「新增同业授信」（段落 71–198）

## 要点摘要

- 功能说明：同业授信含新增申请与变更，申请内容包含额度申请维护（授信方案、调查报告）、审批、生成同业授信批复。「授信性质」域值=同业授信新增/同业授信变更；入口「授信管理－同业授信－同业综合授信－授信新增/授信变更」。
- 业务流程：主页查询 → 新增入口 → 选同业客户 + 风险阻断确认 → 发起新增申请 → 按序维护授信基本信息、额度信息、额度分项、调查报告、风险评价报告、影像资料 → 提交流程发起审批 → 网点负责人/信审会委员/信审会办公室主任会签汇总 → 末节点同意形成批复并登记额度。

## 新增同业授信主页【ZJJK00107421】

- 功能描述：按同业客户信息查询、查看、新增、修改、撤销授信申请。
- 操作权限：法人行级 / 客户经理 /【查询】【重置】【更多】【新增】【修改】【查看】【撤销】【流程轨迹】/ 数据权限=本人经办的业务。
- 操作步骤：【授信管理】→【同业授信管理】→【新增同业授信管理】；查询条件：同业授信申请编号、同业客户号、同业客户名称（放大镜）、额度流程状态（【更多】展开）。
- 输入要素：crgAplyNo(32)、cstNo(32)、cstNm(200，经【客户放大镜选择器 ZJJK00109101】)、lmtPcsSt（字典 AprvSt：1待发起/2审批中/3已撤销/4打回/5通过/6否决/7作废）。
- 输出列表：crgAplyNo、cstNo、cstNm、smbsnCstTp(cstTpcd)、授信额度crgln、币种ccy(CcyCd)、期限ddln、期限单位ddlnUnit(01年/02月/03日)、审批状态lmtPcsSt、createTime、aplyCstmgr + 行按钮。
- 业务规则：
  - 页面初始化：默认限定客户类别=同业客户、授信额度类型=同业综合授信、申请性质=新增；额度流程状态条件默认隐藏，【更多】后展示。
  - 查询：固定限定同业客户/同业综合授信/新增，仅返回当前操作人经办未删除、授信性质=同业授信新增的申请；编号/客户号精确、名称模糊、状态精确；按创建时间和申请编号倒序。
  - 重置：清空四个查询条件（文本清空、下拉恢复未选）。
  - 同业客户名称：打开「选择同业客户」弹窗限定同业客户范围；确认带入名称+客户号，取消不变更。

## 【新增】按钮规则

- 点击【新增】打开新增同业授信办理页面，限定从同业客户范围选择客户。

## 向导页：客户经理发起新增同业授信申请主页【ZJJK00107430】

- 步骤条：业务主体选择 → 风险阻断。权限：用户级（经办人）/客户经理/【下一步】【返回】【上一步】【确认】。
- 流程：选同业客户 →【下一步】校验（未选提示「请选择有效数据」）→ 切「风险阻断」步骤查看结果 →（【上一步】可返回）→【确认】发起审批并打开「新增同业授信」办理场景；【返回】关闭主页。
- 业务规则：
  - 初始化：默认显示「业务主体选择」，暂不展示「风险阻断」。
  - 确认：风险阻断未通过提示「风险拦截不通过，无法做业务！」中断；通过后按同业客户额度+授信新增准备申请并发起审批，成功后关闭主页打开办理场景。
  - 流程发起前：业务参数空提示「参数异常，自定义业务参数不能为空」；校验流程场景、授信额度类型、申请性质、客户编号/名称、客户类别、同业客户类型（任一空提示「参数异常，{字段}不能为空」）；校验客户在途授信申请（风险阻断返回不通过按原因中断）；生成新同业授信申请编号并创建主申请+分项额度申请；按同业授信额度类型选择审批流程。
- 客户放大镜选择器【ZJJK00109101】：选择同业客户的弹窗组件。
- 风险拦截（新增同业授信向导页）【ZJJK00196053PDCP】：同【公共组件需求】>【风险阻断】；差异化=展示新增同业授信申请的风险拦截校验结果和规则明细。

## 关键规则 / 字段 / 校验（汇总）

- 额度流程状态字典：1待发起/2审批中/3已撤销/4打回/5通过/6否决/7作废（AprvSt 分组"2"）。
- 列表数据权限：本人经办；授信性质固定为「同业授信新增」。
