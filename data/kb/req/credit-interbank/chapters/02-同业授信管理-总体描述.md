# 02 同业授信管理-总体描述

- 标题路径：同业授信管理 > 总体描述（功能说明 / 业务流程图 / 状态说明）
- 出处：Heading1「同业授信管理」> Heading2「总体描述」（段落 26–69）

## 要点摘要

- 功能说明：同业授信管理用于办理同业客户综合授信的**新增、变更、审批和流程跟踪**。客户经理从新增/变更主页发起申请、查询本人经办业务、修改待处理或打回申请、查看流程轨迹；审批角色在任务页查看授信方案、影像、风险阻断、会议安排、汇总意见，按节点会签/汇总/审批。系统在发起、提交、取回、打回、终止各环节校验客户、额度、期限、分项额度、审批权限和风险阻断结果。
- 业务流程图（mermaid，客户经理全流程）：进入同业授信管理 → 选业务（新增主页/变更主页）→ 新增选同业客户/变更选已生效批复 → 风险阻断确认发起 → 维护授信信息/额度/分项/报告/影像 → 提交流程 → 查询流程轨迹。
- 审批流程（mermaid）：客户经理提交 → 网点负责人审批 →（打回退回客户经理 / 通过→）信审会委员会签 → 信审会办公室主任安排会议并汇总意见 → 末节点批复：同意→形成授信批复并登记额度；否决或终止→申请结束批复失效。
- 角色×外部系统泳道：客户经理 / 审批办理角色 / 同业授信业务服务 / 平台服务（工作流引擎、影像、风险阻断结果、会议信息、电子文档上传）。

## 状态说明（关键状态机）

- **额度流程状态**（申请阶段）：待发起 / 审批中 / 通过 / 否决 / 打回 / 已撤销
  - 待发起 → 审批中（流程启动）
  - 审批中 → 通过（末节点同意）；→ 否决（末节点否决或非首节点终止）；→ 打回（打回首节点）；→ 待发起（取回首节点）
  - 待发起 → 已撤销（撤销申请）
- **授信批复状态**：生效 / 失效
  - 审批中 → 生效（末节点同意）；审批中 → 失效（否决）；生效 → 失效（新批复替换原批复）
- **审批节点处理状态**（流程轨迹）：待处理（无处理日期）→ 已处理（有处理日期）

## 关键规则 / 字段 / 校验

- 批复替换关系：新批复生效后原批复失效，不再作为有效授信依据（变更链的前置语义）。
