# 02 基础管理

## 标题路径
系统管理分册 > 基础管理（菜单管理 / 账务机构管理 / 角色管理 / 用户管理 / 机构管理 / 外部用户管理 / 法人管理 / 租户开通配置 / 密码策略）

## 要点摘要
纯管理维护类 CRUD 分册，无审批流程；主页列表 + 新增/修改/删除/查看 + 二次确认 + 逻辑删除是全章统一模式。

### 菜单管理
- 菜单新增/修改支持 5 类终端（PC/PAD/移动等）页签，页签由「菜单展示参数」控制；参数缺失/失败时默认展示 PC/PAD/移动。
- 菜单树形展示，删除需二次确认，修改时父菜单/编码等约束「待湿测」。

### 账务机构管理
- 贷款核销机构标志为单选；删除前二次确认。

### 角色管理
- 角色名称唯一；角色编码由系统自动生成，不可编辑。
- 互斥角色 4 条规则：互斥选择提示、新增时校验与已有互斥组冲突、修改时保持互斥关系一致、删除互斥角色时同步解除互斥关系。
- 状态失效级联：角色置失效时，关联用户-角色关系同步失效。
- 删除前置引用检查：角色已被用户引用时不允许删除。
- 数据范围：总行用户可查全部机构数据；非总行仅本机构及下属。

### 用户管理
- 作废用户采用 2 步向导（选择用户 → 确认注销）。
- 用户状态：1 生效 / 2 失效 / 3 注销；生效→失效为单向，失效可回生效以外需「待湿测」确认；注销不可逆。
- 默认角色不可移除；用户至少归属一个机构。
- 机构失效级联删除该机构下用户角色关系。
- 初始密码 = 用户编号 + 身份证后四位。
- 用户导入文件 ≤ 1MB。
- 注销、重置所有密码按钮在特定状态下隐藏（页面按状态显隐）。

### 机构管理
- 仅超级管理员可增删机构。
- 行政区划五级联动选择。
- 「是否部门」与「是否网点」互斥。
- 父机构与法人级联：父机构变更联动法人归属。
- 新增法人级机构自动创建租户 + 租户管理员。

### 外部用户管理
- 审查用户：身份核验码 00/01 视为通过。
- 外部用户初始密码 123456（首登强制改密「待湿测」）。
- 有效到期日期必须 ≥ 当天。
- 内部人员（存在内部用户记录）禁止注册为外部用户。

### 法人管理
- 法人失效需校验在途流程，有在途流程不允许失效。
- 资本净额通过 Excel 导入，含格式/数值校验。
- 新增法人 3 步向导：法人信息 → 管理员信息 → 分配菜单。

### 租户开通配置
- 开通门户渠道时初始化 5 类门户角色；角色编码 = TENA + 租户编号。
- 菜单权限采用先删后建全量替换。
- 客户端编码：10001 门户 / 10002 后台。

### 密码策略
- 密码类型唯一（同类型不重复）。
- 密码复杂度多选（大写/小写/数字/特殊字符），系统自动拼接生成校验正则表达式，表达式字段禁手编。
- 删除为逻辑删除。

## 关键规则/字段/校验
- 通用：列表操作（修改/删除/查看）需先选中记录，未选中提示「请选择有效数据」；删除均二次确认、逻辑删除。
- 权限过滤：总行（法人 9881）查全部，非总行仅本机构及下属（跨模块页面章有同款规则）。
- 字典：用户状态 usrStcd；密码类型 pswdTp；密码复杂度 pswdCmpl；权限范围 perScope。
