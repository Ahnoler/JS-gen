## 要点摘要
- 业务闭环：申请发起 → 授信方案维护 → 审批流转 → 批复查看 → 存量批复变更与作废。
- 客户经理主路径：选择对公客户 → 风险阻断 → 维护额度与分项额度 → 征信/调查报告/风险报告/授信登记/影像 → 提交审批。
- 审批角色：审批人员、信审会主任、信审会委员、信审会办公室主任（安排会议、投票会签、意见查询汇总）。
- 批复生效后在对公授信批复页查询授信/用信批复、查看明细、下载报告，符合条件时发起作废审批与重新发起。

## 状态机（核心）
额度流程状态（新增/变更申请）：
- 待发起 →（首节点提交）→ 审批中 →（打回首节点）→ 打回；（末节点同意）→ 通过（生成已生效批复并登记额度）；（末节点否决/非首节点终止）→ 否决；（首节点终止）→ 已撤销。
- 列表字典 AprvSt：1待发起 2审批中 3已撤销 4打回 5通过 6否决 7作废。

作废申请流程状态：待发起 → 审批中 → 通过（原批复已作废）/ 打回 / 否决 / 已撤销。

授信用信批复状态（LmtReplyStCd）：0待生效 1生效 2否决 3失效 4作废中 5已作废 6已终止 7变更中。
- 已生效 → 作废启动 → 作废中 →（作废审批通过）→ 已作废；变更末节点同意生成新批复后原批复 → 失效。

流程处理状态：待处理（无处理日期）/ 已处理（按处理时间算审批耗时）。
