# 集团授信管理 > 总体描述

## 要点摘要

- 集团授信管理支撑：新增集团综合授信、变更集团授信、查看授信批复、作废批复。
- 新增从"选择集团客户"开始，经风险阻断校验后创建申请进入办理页面（授信方案/影像/风险阻断/意见四步骤）；公共报告列表支持撰写/上传/下载/修改/删除调查报告。
- 变更从"选择生效且同意的批复"开始，确认批复+通过风险阻断后创建变更申请；审批角色含信审会办公室主任、信审会委员、最终有权审批人。
- 查看批复/作废批复任务提供客户、批复、集团成员批复信息查看与审批意见签署。

## 业务流程（客户经理全流程）

新增：选择集团客户 → 风险阻断 → 确认发起 → 维护授信方案+影像 → 查看风险阻断 → 提交审批意见 → 审批节点办理 → 查询过程意见/流程跟踪。
变更：选择生效且同意的批复 → 风险阻断 → 确认创建变更申请 → 维护授信方案和影像 → 信审会办公室主任组织会议/汇总意见 → 信审会委员办理会签 → 最终有权审批人审批。
查看与作废批复：进入批复任务 → 查看客户/批复/成员批复信息 → 维护影像资料 → 填写流程或审批意见 → 返回。

## 关键规则/校验

- 撤销前提：审批状态为"待发起"或"打回"。
- 批复选择前置：批复状态=生效、批复结论=同意。
