# 集团综合授信 > 新增集团授信申请

## 标题路径
集团授信管理 > 集团综合授信 > 新增集团授信申请

## 要点摘要

- 客户经理选择集团客户 → 风险阻断 → 创建申请（审批状态=待发起）→ 任务页四步骤：授信方案 / 影像信息 / 风险阻断 / 意见（提交流程）。
- 审批节点：信贷调查 → 客户经理二次调查 → 五级/四级机构风险评价员·业务审核员调查审查、网点负责人审批/复核 → 综合岗分配 → 部门负责人/分管领导/主任审批 → 风险总监审查 → 信审会办公室主任安排信审会 → 信审会委员投票 → 主任汇总委员意见 → 信审会主任审核 → 最终有权审批人审批（流程 wf_credit_002，22 节点，均有多种退回操作）。

## 关键界面与规则

### 新增集团授信主页【ZJJK00105897】
- 权限：法人行级客户经理，本人经办业务。
- 入口：【授信管理】→【集团授信管理】→【新增集团授信管理】。
- 页面初始化：查询客户类别=集团、申请性质=授信新增、客户经理=当前操作人；按创建时间+申请编号倒序；默认单选不选中；查询条件默认展示申请编号/客户号/客户名称，集团报表口径与额度流程状态需点【更多】。
- 【撤销】：仅"待发起/打回"可撤销，确认后状态置为"已撤销"。
- 【修改】：仅"待发起/打回"可修改；【查看】：仅可查看。

### 向导页【ZJJK00109160】
- 两步骤：选择集团（按集团名称/编号查询，列表含集团编号/名称/报表口径/成员数量/经办人/经办机构）→ 风险阻断（总校验结果+规则明细）。
- 【下一步】：未选集团提示"请选择有效数据"。
- 【确认】：风险校验通过后启动流程，审批状态=待发起，进入新增申请办理页。
- 客户放大镜【ZJJK00109101】、风险拦截【ZJJK00196050PDCP】同公共组件需求，差异化规则：无。

### 流程审批通过/否决规则（核心业务结果）
- 通过：流程状态→审批通过；生成批复状态"已生效"的集团授信批复 + 每个集团成员一份"已生效"子批复；调额度组件生成额度信息。
- 否决：流程状态→审批否决；生成"已否决"批复与子批复。

### 客户经理新增任务页【ZJJK00107651】
- 步骤条：授信方案（授信基本信息/集团授信额度/成员列表/调查报告/风险评价报告/授信登记）→ 影像信息 → 风险阻断（拦截智能控制）→ 意见（提交流程）。

#### 查看基本信息【ZJJK00095791】
- 集团报表口径=合并报表时才展示集团评级、集团评级到期日；其余不展示。

#### 维护额度信息【ZJJK00110022】
- 【获取】集团授信额度理论值（仅合并报表口径）：
  - 校验母公司信用等级、行业非空；授信系数需已配置；需上一年度财务报表。
  - 有效资产总额 = 资产合计 − 待处理流动资产损失 − 待处理固定资产净损失；负债总额=负债合计。
  - 母公司行业属采矿业/制造业/电力热力燃气及水生产供应业：理论值 =（成员现有贷款余额 + 2.33×有效资产 − 3.33×负债）×授信系数；否则 =（成员现有贷款余额 + 4×有效资产 − 5×负债）×授信系数。
  - 测算结果 <0 按 0 展示。
- 【保存】：必填校验；授信期限 ≤12 个月（超过提示"授信期限只能小于等于12个月"）；非合并报表口径下集团授信额度可编辑，合并口径不可编辑。
- 变更申请额外展示：原集团授信额度/理论值、原始期限、原授信生效/到期日期（不可编辑）。

#### 维护成员额度主页【ZJJK00095793】
- 按申请性质显示按钮：新增→【额度分配】【重置】【修改】【查看】；变更→【变更分配】【取消变更分配】；【注销】【取消注销】【刷新成员】始终显示。
- 状态前置：额度分配需"初始"；重置/修改需"已分配"（重置后状态→待分配，清空分配信息，非合并报表需重算集团授信额度）；变更分配后状态→"已变更"；取消变更分配恢复为当前汇总额度并将状态恢复"已分配"。
- 注销：新增申请需"初始"，变更申请需"已分配"；取消注销恢复（新增→初始，变更→已分配）。
- 刷新成员：新增申请发现新增成员→列表追加；变更申请发现新增成员→提示"校验到集团成员有新增，若要授信，请重新发起。"并中断；减少成员→标记删除并移除。

#### 额度分配【ZJJK00106212】
- 【保存】：授信额度 ≥ 占用额度；合并报表口径需先保存集团授信申请额度（"请先保存集团授信申请信息"）；非合并口径集团授信额度=各成员额度之和；新增→成员状态"已分配"，变更→"已变更"。
- 成员理论值【获取】：项目融资主体需项目总投+最低资本金比例>0；成立不到一年企业需金融押品评估价值+抵押率；事业法人/成立一年以上取上一年财报+授信系数+贷款余额。
- 占用余额【获取】：需先填授信额度；无额度信息则占用余额=0、可用额度=授信额度；可用额度=授信额度−占用余额。
- 分项额度明细弹窗：授信产品（树选择）/循环标志/币种/占用余额/分项授信额度；校验：先保存额度基本信息、分项额度>0、≥占用余额、≤授信额度、产品不重复；修改态产品与循环标志不可改。
- 分项额度删除：占用余额>0 不可删除。
- 征信信息同公共组件【征信查询】。

#### 报告与影像
- 撰写调查报告、维护影像资料、拦截智能控制【ZJJK00111900】均同公共组件需求。
- 查询风险报告主页【ZJJK00117151】：上传/删除按钮仅在风险评价相关审批环节且可编辑时展示；下载始终可用。
- 上传调查报告弹窗【ZJJK00117383】：最多1个文件、≤1024MB、仅 doc/docx/PDF；文件名不可重复；按目录编号/文件类型校验。

#### 提交流程【ZJJK00107650】
- 按钮状态机：未发起→【流程启动】；已发起未处理→【流程提交】【流程撤销】；已处理且流程未结束可取回→【流程取回】；已发起→【流程轨迹】。
- 【流程提交】校验：授信期限已录入；成员已分配额度（"请先对集团成员【{0}】进行额度分配"，已注销成员不纳入汇总）；分项额度明细已维护且金额>0；集团授信额度=成员额度汇总（不一致提示差额）。
- 【流程取回】：仅"审批中"可取回；下一节点未提交"签署意见"才可取回；退回首节点，状态→待处理。
- 【流程撤销】：仅"待发起/打回"可撤销，确认后状态→已撤销。
- 【回退第一节点】：额度流程状态→打回。
