# credit-group · 候选可贯通主链清单

> 时效声明：本文为需求文档口径提炼，叶级真值以同目录 wet-test.md 湿测判定为准；链级修订由 Lead 在模块收口时统一处理。（2026-09-06 协议 v4）

> 口径：主链 = 有闭环目标、有序步骤、前置条件、章节出处，可据此设计湿测回放的候选链。

## 主链 1：新增集团综合授信（全审批闭环）

- **闭环目标**：客户经理选择集团客户，完成风险阻断与额度/成员额度维护，提交审批；审批通过后生成已生效批复与成员子批复并生成额度信息。
- **前置条件**：存在集团客户（正式/潜在）；合并报表口径下母公司有信用等级、行业、上一年度财务报表、授信系数配置；成员额度分配完整。
- **有序步骤**：
  1. 【新增集团授信管理】列表 →【新增】→ 向导页选择集团客户（下一步）
  2. 风险阻断步骤查看总校验结果 → 通过后【确认】创建申请（状态=待发起）
  3. 任务页：查看基本信息 → 维护额度信息（可获取理论值）→ 保存
  4. 维护成员额度 → 额度分配（授信额度/占用余额/分项额度明细）→ 保存（成员状态=已分配）
  5. 维护影像资料 / 上传调查报告 / 风险评价报告
  6. 提交流程：流程提交（校验期限、成员分配、分项额度、总额一致）→ 选人确认
  7. 审批链（wf_credit_002 22 节点，可截断为代表性片段）：客户经理调查 → 信审会办公室主任安排会议会签 → 信审会委员提交会议会签 → 办公室主任提交意见汇总 → 总行行长审批
  8. 通过 → 生成已生效批复+子批复+额度；否决 → 已否决批复
- **出处**：chapters/03（03-集团综合授信-新增集团授信申请.md）
- **建议湿测切点**：步骤 1-6（发起+提交校验全在这段，含最丰富的提示文案）；审批链按湿测账号可用性截取。

## 主链 2：变更集团授信（批复驱动闭环）

- **闭环目标**：基于已生效且同意的批复发起变更审批；通过后原批复及子批复失效，生成新批复。
- **前置条件**：主链 1 完成且批复状态=生效、终审意见=同意；变更申请下集团成员无新增（有新增则要求重新发起）。
- **有序步骤**：
  1. 【变更集团授信管理】→【新增】→ 向导页批复授信【ZJJK00107655】选择批复
  2. 风险阻断步骤 → 通过后【确定】创建变更申请（新申请编号，带入原批复信息）
  3. 变更任务页：授信方案（展示原额度/原期限/原生效到期日）→ 影像信息 → 风险拦截（不通过则停留，可重试）→ 意见
  4. 维护成员额度 →【变更分配】/【取消变更分配】（成员状态=已变更/恢复已分配）
  5. 提交流程 → 审批链（办公室主任安排会议 → 委员提交意见 → 汇总 → 最终有权审批人）
  6. 通过 → 原批复+子批复置"已失效"，生成新"已生效"批复
- **出处**：chapters/04（04-集团综合授信-变更集团授信申请.md）

## 主链 3：作废集团授信批复（wf_credit_008 小闭环）

- **闭环目标**：作废生效批复，批复及子批复置"已作废"，额度状态置"失效"；否决则还原。
- **前置条件**：存在可作废批复（SUT 中批复状态允许作废的具体取值待湿测确认——文档未写【作废】按钮规则正文）。
- **有序步骤**：
  1. 【集团授信批复主页】选中批复 →【作废】
  2. 作废任务页：维护客户基本信息（填作废申请理由→保存）→ 影像信息 → 意见（提交流程）
  3. 网点负责人审批（同意/不同意/退回第一步）
  4. 通过 → 批复状态已作废、额度失效
- **出处**：chapters/05（05-查看授信批复-查看集团授信批复.md）

## 旁路 / 独立操作链（非闭环或短闭环）

1. **列表管理旁路（新增/变更共用）**：查询/重置/修改（待发起/打回）/查看（只读）/撤销（待发起/打回→已撤销）/流程轨迹。【ZJJK00105897】【ZJJK00105894】【ZJJK00124779】
2. **查看批复旁路**：批复主页 → 查看 → 三页签（客户/批复/成员批复信息），成员详情跳对公批复查看。
3. **重新发起旁路**：已失效/已作废/已终止批复 → 复制生成新申请（编号 DGSX+日期+序号）→ 进入办理页面。
4. **下载旁路**：批复文件/审查报告/调查报告/风险评价报告四个下载按钮。
5. **流程操作旁路**：流程取回（审批中且下节点未签意见）、流程撤销（待发起/打回）、回退第一节点（状态→打回）。
6. **成员额度维护旁路**：注销/取消注销/刷新成员（变更申请新增成员→阻断提示）；重置（已分配→待分配，非合并重算额度）。
7. **报告/影像旁路**：公共报告列表撰写/上传（doc/docx/PDF，≤1024MB，文件名唯一）/下载/删除；风险评价报告上传仅限风险评价审批环节。

## 湿测优先建议

首推主链 1 的步骤 1-6：单账号（客户经理）即可完成，校验与提示文案密度最高；主链 3 最短（2 节点流程），适合快速冒通。
