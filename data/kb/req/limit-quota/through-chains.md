## 主链 1：新增单户限额（创建→审批→生效）【主推，首湿测候选】
- **闭环目标**：额度管控人员为法人客户新建一条单户限额，经额度复核人员审批通过后限额生效。
- **前置条件**：有额度管控人员/额度复核人员角色账号；进入【额度管控】-【限额管理】-【单户限额管理】。
- **有序步骤**：
  1. 单户限额设置列表主页【ZJJK00070857】点【新增】（系统生成限额编号 QOT+日期+4位序号）。
  2. 任务页【ZJJK00090489】：基本信息步骤 → 维护单户限额信息【ZJJK00070898】填写限额名称、目标金额、起始日期、管控措施、维度（机构/产品）→【保存】。
  3. 【下一步】→ 签署意见步骤 → 提交流程【ZJJK00091084】流程启动（待办展示限额编号/类型/名称/目标金额），提交 → 流程状态=审批中。
  4. 额度复核人员任务页【ZJJK00090491】查看详情 →【审批】弹窗签署意见提交。
  5. 流程结束：状态=审批通过（生效），系统计算监控区间起始/到期日期。
  6. 回列表主页验证：限额状态=生效、流程状态=审批通过。
- **验证点**：编号规则、必填校验、状态流转（待提交→审批中→生效）、监控区间日期计算。
- **章节出处**：2.1.3 状态说明；2.2.2 主页；2.2.3 新增（FS00001634 / qotAply）。

## 主链 2：新增组合限额（创建→多维配置→审批→生效）
- **闭环目标**：额度管控人员按多维度组合创建限额方案并审批生效。
- **前置条件**：同主链 1；进入【组合限额管理】。
- **有序步骤**：
  1. 限额设置列表主页【ZJJK00067174】点【新增】→ 生成限额编号。
  2. 任务页【ZJJK00090478】基本信息 → 维护限额设置详情【ZJJK00067183】：填名称/目标金额/使用率阈值(0~1)/起始日期/控制方式(余额才显监控频率)/管控措施/管控时点；选限额维度类型并配机构、产品、区域、行业、币种、客户类型、客户、期限、担保方式等维度；选监控频率（月/季/年→区间类型；日→天数；区间→起止日期）→【保存】。
  3. 【下一步】→ 签署意见 → 提交流程【ZJJK00091083】提交 → 审批中。
  4. 复核人员任务页【ZJJK00090479】审批通过 → 流程结束 → 状态=审批通过，重算监控区间起止日期。
  5. 回主页验证列表（含使用率阈值、已用/可用金额字段）。
- **验证点**：可用金额=目标−已用、阈值 0~1 提示「大小在 0 到 1 之间」、客户维度未选客户类型提示「请先选择客户类型维度！」、维度类型变更清空维度值、监控频率变更清空区间配置。
- **章节出处**：2.3.1~2.3.3（FS00001640）。

## 主链 3：修改单户限额（待提交状态）
- **闭环目标**：对未提交的单户限额修改信息并重新保存。
- **前置条件**：列表中存在流程状态=待提交的限额。
- **有序步骤**：主页选中记录 →【修改】（校验待提交，否则提示「流程状态不是待提交,不允许修改」）→ 修改页（同新增）→ 改字段 →【保存】→ 回列表验证。
- **章节出处**：2.2.4。

## 主链 4：修改组合限额（待提交状态，维度重配）
- **闭环目标**：修改组合限额基本信息与维度配置（先清后存）。
- **前置条件**：组合限额流程状态=待提交。
- **有序步骤**：主页【修改】→ 可编辑详情 → 变更限额维度类型（观察维度字段清空/重显）→ 重新选择维度值 →【保存】→ 验证保存后维度为新配置。
- **章节出处**：2.3.4 + 2.3.3 维护限额设置详情保存规则。

## 主链 5：注销（失效）已生效限额
- **闭环目标**：将生效限额（单户或组合）置为失效。
- **前置条件**：存在限额状态=生效的限额。
- **有序步骤**：主页选中 →【失效】（校验非失效）→ 注销任务页（单户【ZJJK00090412】/组合【ZJJK00090475】）→ 查看限额信息（只读）→【注销】→ 二次确认「将限额置为失效后无法恢复，确认修改？」→ 状态=失效 → 回列表验证仅可查看。
- **章节出处**：2.2.8（FS00001734）、2.3.8（FS00001641）。

## 主链 6：复制生效限额生成新限额
- **闭环目标**：以生效限额为模板复制生成新限额（进入新增流程）。
- **前置条件**：限额状态=生效。
- **有序步骤**：主页选中 →【复制】（校验生效，否则「只允许拷贝生效状态的限额」）→ 复制信息+维度 → 新限额编号 → 填写页面（起始日期=当天、状态=待生效、流程状态=待提交、已用/可用金额重置；组合：可用金额=原目标金额）→ 走主链 1/2 审批。
- **章节出处**：2.2.7、2.3.7。

## 旁路 / Out
- **删除**（单户 2.2.6 / 组合 2.3.6）：仅待提交且已用金额=0；弹窗确认后标记删除。为旁路操作，非端到端闭环主链。
- **查询/重置**（2.2.2 / 2.3.2）：列表筛选，无独立闭环。
- **查看**（2.2.5 / 2.3.5）：只读详情，旁路。
- **流程轨迹**（2.2.9 / 2.3.9，ZJJK00124779）：只读弹窗，展示节点状态/处理人/耗时/意见。
- **撤回/否决分支**：审批中首节点撤回→已撤销；非首节点否决→否决（可作为主链 1/2 的异常分支湿测）。
