# 押品-功能（collateral-func）候选主链清单

> 参考风格：tmp/product-mgmt/req-mainchain.md。

## 有闭环的候选主链（审批类）

### 主链 1：权证入库（新增权证入库全流程）

- 闭环目标：押品权证从申请到柜面确认完成入库，实物状态更新为在库。
- 步骤：1) 权证入库管理主页查询记录 → 2) 【发起入库】打开向导页（押品基本信息 → 担保合同 → 选择权证信息）→ 3) 任务页（下一步校验）→ 新增影像资料 → 新增审批意见 → 4) 流程提交启动审批（待发起→审批中）→ 5) 审批通过 → 6) 打印入库凭证 → 7) 柜面确认（更新实物状态）/柜面拒绝（释放占用）。
- 前置：客户经理或押品实物管理员角色；有效押品与权证数据；关联担保合同。
- 出处：chapters/02（权证入库管理，UML00048584）。
- 备注：柜面确认按权证管理模式（集中/分散）差异「待湿测」。

### 主链 2：权证替换入库（分散模式，FS00005723）

- 闭环目标：替换权证完成入库审批闭环。
- 步骤：1) 替换入库主页【发起替换】→ 2) 向导页（权证押品基本信息 → 客户引入 → 担保合同 → 选择权证信息【确认替换】）→ 3) 任务页 → 影像 → 审批意见 → 流程审批 → 4) 客户经理发起 → 5) 支行行长审批（任务页【审批】）→ 6) 权证保管岗复核（跨步骤数据关联/前置条件/后置结果）→ 7) 柜面确认/拒绝。
- 前置：审批状态为待发起才可发起；担保合同与权证关联有效。
- 出处：chapters/02（权证替换入库管理）。

### 主链 3：权证期转现入库

- 闭环目标：期房权证转现房后完成入库审批与柜面确认。
- 步骤：主页查询 → 发起流程 → 向导录入 → 审批流（同主链 2 模式）→ 柜面确认。
- 出处：chapters/02（权证期转现入库管理，UML00048962）。

### 主链 4：权证借阅 → 归还（借还闭环）

- 闭环目标：权证借出并按期归还，占用释放。
- 步骤：1) 借阅主页【发起借阅】→ 修改（仅待发起/打回）→ 审批通过 → 柜面确认（更新实物状态、同步借阅人信息）→ 2) 借阅到期后：续借流程（UML00049216）或归还流程（UML00049230：发起归还 → 审批 → 打印 → 柜面确认）。柜面拒绝则释放权证占用。
- 前置：权证在库；客户经理/押品实物管理员角色。
- 出处：chapters/02（权证借阅管理、权证续借管理、权证归还管理）。
- 关联旁路：借阅未按期归还触发预警提示（chapters/05）。

### 主链 5：权证出库（正式 / 强制）

- 闭环目标：权证完成出库审批并柜面确认出库。
- 步骤：出库主页 → 发起流程（向导页）→ 审批流 → 打印（仅审批通过）→ 柜面确认/拒绝。强制出库由押品实物管理员/客户经理发起。
- 前置：网点负责人角色下发起/修改/打印按钮不可见（正式出库）。
- 出处：chapters/02（权证正式出库管理 UML00049338、权证强制出库管理 UML00049341）。
- 关联旁路：业务已结清权证未出库触发预警提示（chapters/05）。

### 主链 6：权证移库

- 闭环目标：权证跨机构/库位移库完成审批与柜面两侧确认。
- 步骤：移库主页（按业务编号、接收人、接收机构等查询）→ 发起移库申请 → 审批流 → 打印移库单据 → 移库出库柜面确认 + 移库入库柜面确认（均可拒绝）。
- 前置：仅允许操作本人发起的流程数据。
- 出处：chapters/02（权证移库管理，UML00088073）。

### 主链 7：手工盘库

- 闭环目标：权证实物盘点结果登记并审批生效，账实一致确认。
- 步骤：盘库管理主页（押品实物管理员）→ 手动生成盘库任务 → 选择记录【手动盘库】（审批状态校验"流程节点不支持盘库"）→ 五步向导（基本信息含不匹配权证增删改 → 影像 → 审批意见 → 流程）→ 提交 → 客户经理复核（审批弹窗，同意/驳回）→ 审批通过后盘库结果生效。
- 出处：chapters/03（盘库管理 > 申请手工盘库流程）。

### 主链 8：自动盘库（含结果文件导入）

- 闭环目标：自动盘库任务发起、结果导入、复核审批闭环。
- 步骤：盘库主页【自动盘库】→ 三步向导（自动盘库基本信息：开始/结束盘库为硬件预留、导入盘库结果 Excel ≤1MB → 影像 → 审批意见）→ 串行复核（客户经理→部门负责人→部门分管领导，审批意见必填）。
- 出处：chapters/03（盘库管理 > 申请自动盘库流程）。

### 主链 9：不动产抵押登记（其他城市 / 南宁两变体）

- 闭环目标：不动产抵押登记提交至不动产登记系统并回写登记结果。
- 步骤：抵押登记管理主页 → 【新增】（角色 X0018）→ 按城市分流南宁/其他城市详情页 → 录入基本信息、选择已生效担保合同（自动带出债权金额等）、维护抵押人信息与影像 → 【确认】提交（校验合同已生效、抵押人非空）→ 认证 + 异步创建登记业务 → 登记状态"登记中" → 主页【结果查询】回写登记状态/结果。
- 出处：chapters/04（不动产抵押登记业务）。
- 备注：外部系统（不动产登记中心）对接，SUT 无法直连「待湿测」。

### 主链 10：不动产抵押注销

- 闭环目标：不动产抵押注销办理提交并回写注销结果。
- 步骤：注销办理列表 → 新增注销申请（按城市分流详情页）→ 录入并提交 → 注销状态流转 → 列表查询/导出/南宁市结果查询。
- 出处：chapters/04（不动产抵押注销办理）。

### 主链 11：评估费用维护审批

- 闭环目标：评估费用标准经审批后生效，作为外部评估计费依据。
- 步骤：评估费用主页【新增】（评估标准经办员，创建流水）→ 录入 → 审批（评估标准复核员）→ 审批通过 →【置为生效】；【置为失效】排除已失效/审批中记录。唯一性：同一机构同时仅一条生效或在途。
- 出处：chapters/08（评估费用维护）。

## 弱闭环 / 半流程主链

### 主链 12：外部评估管理人员维护（带状态流转）

- 目标：维护外部评估人员名单。新增创建流程事务 → 录入 → 审批状态流转；修改/删除仅限待发起/退回。文档未展开审批节点配置「待湿测」。
- 出处：chapters/08（外部评估管理人员维护）。

## 旁路（非主链，单点操作/查询，无审批）

- 权证实物管理（chapters/03）：入库/出库直接生效、打印标签、标签录入（需先打印标签）、打印货架标签（同业务+同合同+同库位校验）、上传影像（仅新增/查看权限）。
- 不动产信息管理：查询/新增（向登记中心查询，需授权书上传）/查看详情/电子证照下载；柳州、北海限制「待湿测」（chapters/04）。
- 不动产查档：新增查档（V6 平台认证+查询）、查看、下载（chapters/04）。
- 押品预警 6 项查询+导出（保险到期/评估到期/权证到期/借阅逾期/结清未出库/不足值），导出上限与公式见 chapters/05。
- 押品台账 4 项查询+导出（记账台账/担保物担保详情统计/权证出入库台账/缓释拆分结果），见 chapters/06。
- 押品参数管理：押品种类树维护、样本数据 CRUD+导入、各农商行估值参数、商用最高限价比率、房产估值模型——直接生效无审批（chapters/07）。

## 建议优先湿测主链

1. 主链 1（权证入库）——全册最典型的「主页→向导→审批→柜面」模式，覆盖最多规则。
2. 主链 2（权证替换入库-分散）——三角色审批链最完整。
3. 主链 7（手工盘库）——不匹配权证录入校验独立可测。
4. 主链 9（不动产抵押登记）——字段联动最丰富（担保合同/持证方式/登记类型联动）。
