# 押品权证出入库管理

> 本册最大章（覆盖约 1/3 场景量），由 9 个二级管理模块组成，每个模块统一模式：**查询主页 + 向导页（录入押品基本信息/担保合同/选择权证）+ 审批流程（客户经理发起 → 支行行长审批 → 权证保管岗复核 → 柜面确认/拒绝）**。

标题路径：押品管理分册_押品功能 > 押品权证出入库管理

## 通用结构（全章各流程共用）

- 查询主页：按押品所有人名称、押品编号、押品名称、押品种类、审批状态、申请时间等条件查询记录列表；操作按钮：发起流程、修改、查看、打印、柜面确认、柜面拒绝。
- 审批状态机：待发起 → 审批中 → 通过/打回（已拒绝）；修改仅限「待发起/打回」状态且需权限校验；打印仅限「审批通过」后。
- 柜面确认/柜面拒绝：要求内部审批已通过且柜面尚未处理；柜面确认按权证管理模式（集中管理/分散管理）更新权证实物状态；柜面拒绝释放权证占用。
- 向导页步骤：任务页 → 权证押品基本信息（含押品所有人引入、是否权益争议联动、金额格式校验）→ 担保合同管理（查询/重置）→（客户放大镜选择器已标注「废弃」）→ 选择权证信息（查询/确定/返回/关联担保合同等按钮规则）。
- 流程任务：任务页（下一步/上一步/返回/流程提交/流程撤销按钮规则）→ 新增影像资料（影像上传、影像分类管理、页面加载初始化）→ 新增审批意见（意见结论=不同意时意见详情必填，意见详情 max 200 字符，流程提交前校验"请填写意见详情！"）→ 新增流程审批（申请说明录入、页面加载初始化）。
- 典型审批链（如权证替换入库-分散，FS00005723）：客户经理发起 → 支行行长审批 → 权证保管岗复核；各任务节点均含跨步骤数据关联、任务前置条件、任务后置结果规则。
- 角色权限：主页按钮按角色控制（如仅客户经理、押品实物管理员可发起/修改/打印；网点负责人下发起/修改/打印按钮不可见）；页面加载时有权限控制规则。

## 9 个二级模块

| 模块 | 场景（UML/流程） | 要点 |
|------|------------------|------|
| 权证入库管理 | 新增权证入库流程（UML00048584） | 入库申请全流程；含打印入库凭证、柜面确认/拒绝 |
| 权证替换入库管理 | 申请权证替换入库流程（UML00048598）；分散流程 FS00005723 | 客户经理发起 → 支行行长审批 → 权证保管岗复核；【确认替换】按钮、【权证信息列表】选择联动、押品种类树形选择 |
| 权证期转现入库管理 | 申请期转现入库流程（UML00048962） | 权证期房转现房后入库；同样含柜面确认环节 |
| 权证借阅管理 | 申请权证借阅流程（UML00049166） | 仅待发起/打回可修改；仅通过可打印借阅凭证；柜面确认更新实物状态并同步借阅人信息；柜面拒绝释放权证占用；列表含柜面返回结果及拒绝原因 |
| 权证续借管理 | 申请权证续借流程（UML00049216） | 借阅到期后续借；状态机与借阅一致 |
| 权证归还管理 | 申请权证归还流程（UML00049230） | 归还申请；仅待发起/审批拒绝可修改；审批通过后打印 |
| 权证正式出库管理 | 申请权证正式出库流程（UML00049338） | 向导页发起；网点负责人角色按钮受限；柜面确认/拒绝 |
| 权证强制出库管理 | 申请权证强制出库流程（UML00049341） | 押品实物管理员/客户经理发起；审批通过后柜面确认完成出库 |
| 权证移库管理 | 申请权证移库流程（UML00088073） | 按业务编号、接收人、接收机构、移交权证管护权标志等查询；支持移库入库/出库两侧柜面确认与拒绝；仅允许操作本人发起的数据 |

## ZJJK / 关键校验

- 【下一步】按钮规则：推进向导步骤时校验本步骤必填项（入库流程任务页）。
- 【页面加载】数据初始化规则：流程页加载时初始化记账机构、打印联动等数据。
- 【记账机构名称】选择联动规则；【保存】按钮规则；【必填项】校验规则（替换入库流程页）。
- 【跨步骤数据关联】/【任务前置条件】/【任务后置结果】规则（权证保管岗复核任务页）。
- 跨能力中心服务调用：系统管理（机构工作日期）、押品管理、用信（担保合同查询）等。
