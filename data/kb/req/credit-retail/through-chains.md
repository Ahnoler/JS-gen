## C1 新增合作方授信（楼盘/工程机械，长流程 wf_credit_004，场景 FS00004772）

- **闭环目标**：从列表新增入口到合作协议签订生效、合作额度注册至额度模块。
- **前置条件**：登录客户经理；合作方客户状态满足（合作方=生效；担保公司=信贷正式对公客户）；无在途申请（待发起/审批中/打回）。
- **有序步骤**：
  1. 【授信管理】→【合作方授信管理】→【新增合作额度管理】主页【ZJJK00106834】→【新增】
  2. 向导页【ZJJK00107305】：业务主体选择——选合作方客户（弹窗 ZJJK00107497 / 客户放大镜 ZJJK00109101），【下一步】过在途校验
  3. 风险拦截【ZJJK00180228PDCP】查看核查结果 →【确定】启动长流程
  4. 任务页【ZJJK00105855】授信方案步骤：按类别填楼盘合作协议【ZJJK00105891】（合作方信息 ZJJK00106293 / 合作额度信息 ZJJK00106294 / 资金监管账户 ZJJK00107406(+新增 ZJJK00107407) / 担保信息 ZJJK00106296 / 登记信息 ZJJK00106297；项目信息=ZJJK00106324/06325/06326/06327）或工程机械协议【ZJJK00105889】
  5. 影像信息步骤：维护影像资料【ZJJK00100615】
  6. （信审会环节）会议会签 /（汇总意见环节）汇总签署意见 —— 公共组件，待湿测
  7. 风险拦截步骤 → 意见步骤提交审批【ZJJK00107104】
  8. 审批通过 → 合作协议生成；登记信息【ZJJK00106297】点【签订】：校验日期必填+起始日期≥营业日 → 协议未生效→生效 → 非评估机构执行**额度注册**（失败中断）
- **关键校验**：合作总额度=分类额度自动汇总；合作期限≤批复期限（已签约/变更时）；到期日期=起始+期限月-1天；保证金金额=额度×比例×1%。
- **章节出处**：ch03 §3.2–3.4。

## C2 新增担保公司合作申请（短流程 wf_credit_006，场景 FS00005502）

- **闭环目标**：担保公司合作协议签订生效并完成额度注册。
- **前置条件**：同 C1；共享范围选择决定合作机构页签（部分→展示）。
- **有序步骤**：
  1. 主页【ZJJK00106834】→【新增】→ 向导页【ZJJK00107305】选对公担保公司客户（校验对公+担保公司类型）→ 风险拦截 →【确定】走短流程（检测联社审批综合岗/风险总监岗位）
  2. 任务页【ZJJK00107427】四步：授信方案（合作协议主页【ZJJK00107420】：合作方信息 ZJJK00107425 含政银担参数 / 合作额度信息 ZJJK00107424 首存生成 EDBH 额度编号 / 合作机构页签：选择机构 ZJJK00105883、选择地级市 ZJJK00105847、修改、删除 / 担保信息 ZJJK00107423 基础保证金 C502089 / 登记信息 ZJJK00107422）→ 影像 → 风险拦截 → 意见提交【ZJJK00110621】
  3. 审批通过 → 登记信息【ZJJK00107422】点【签订】：校验合作机构到期日已设置 + 额度必填 + 起始日期 → 协议生效 → 额度注册（循环额度=可循环）
- **章节出处**：ch03 §3.5。

## C3 新增评估机构授信申请（短流程 wf_credit_006，场景 FS00004729）

- **闭环目标**：评估机构准入协议签订生效、额度注册。
- **有序步骤**：
  1. 主页【ZJJK00106834】→【新增】→ 向导【ZJJK00107305】选评估公司客户 → 风险拦截 →【确定】短流程（UML00081073）
  2. 任务页【ZJJK00105165】四步：授信方案（主页【ZJJK00105170】：基本信息 ZJJK00107410 / 资质信息 ZJJK00107411+新增资质 ZJJK00107412（同类型查重）/ 准入信息 ZJJK00107413 / 登记信息 ZJJK00107414 / 合作机构页签同 C2）→ 影像 → 风险阻断 → 意见
  3. 审批通过 →【签订】：查未生效协议→更新**准入信息**（评估机构特有）→ 额度注册 → 协议生效
- **章节出处**：ch03 §3.6。

## C4 变更合作方授信（长流程 wf_credit_004 / 短流程 wf_credit_006，场景 FS00005504/05505/05506）

- **闭环目标**：对已生效协议发起变更，生成新申请编号（前缀 PRTNM）并复制全部子数据，审批通过后更新协议。
- **前置条件**：原合作协议状态=生效；原协议有额度且可变更。
- **有序步骤**：
  1. 变更列表主页【ZJJK00107435】→【新增】
  2. 向导页【ZJJK00107436】：点原协议编号打开协议选择弹窗【ZJJK00107440】选协议（信息自动带入）→【下一步】风险探测（在途申请+冻结额度双重校验）→ 风险拦截（ZJJK00204005PDCP）→【确定】按类别匹配流程（担保公司短流程 UML00081072 / 评估公司 UML00081073，其余长流程）
  3. 变更任务页（ZJJK00107444 / 107448 / 107449）修改方案 → 影像 → 风险拦截 → 意见提交
  4. 审批通过 → 新合作申请编号生效并更新合作协议（落库表现**待湿测**）
- **章节出处**：ch04。

## C5 合作协议查询 → 修改 / 注销（五类协议）

- **闭环目标**：未生效协议修改后签订；无已用额度的协议注销并执行额度注销。
- **有序步骤**：
  1. 协议管理主页（楼盘 ZJJK00106906 / 汽车 ZJJK00106915 / 工程机械 ZJJK00104736 / 担保公司 ZJJK00104737 / 评估机构 ZJJK00106918）查询
  2. 修改（仅未生效）：任务页四步（ZJJK00105278/05293/05292/05291/05169）→ 签订
  3. 注销：状态校验（已注销/已失效中断）→ 确认弹窗 → 在途业务/已用额度校验 → 未生效直接注销；生效需已用额度=0 → 状态置注销 + 额度注销服务
- **章节出处**：ch05。

## C6 查看对私授信批复（场景 FS00056648PACP）

- **闭环目标**：完整查阅一条对私授信批复及关联用信批复全部信息（只读闭环）。
- **前置条件**：存在对私授信批复记录。
- **有序步骤**：
  1. 主页【ZJJK00180124PDCP】查询（支持流水号/客户名称/编号/批复编号/状态/生效日期；更多条件默认收起）
  2. 选中记录 →【查看】（未选提示「请选择有效数据」）
  3. 任务页【ZJJK00180123PDCP】：授信批复页签（客户授信基本信息 ZJJK00208001 / 授信批复基本信息 ZJJK00180122）→ 切用信批复页签（7 子页 ZJJK00180155/00207221/00180157/00207222/00180159/00180160/00180161，一次性加载）
  4. 【返回】关闭
- **旁路**：批复文件/审查报告/调查报告/风险评价报告下载（须已生效批复，依赖影像系统，待湿测）。
- **章节出处**：ch02 §2.2。

## C7 作废对私授信批复（场景 FS00056649PACP，流程 wf_credit_008）

- **闭环目标**：已生效批复经审批作废，额度注册失效。
- **前置条件**：批复状态=已生效；无生效/作废中的用信批复；无在途或已生效合同；风控不拦截。
- **有序步骤**：
  1. 主页【ZJJK00180124PDCP】选中已生效记录 →【作废】（五重校验链见 ch02）→ 生成作废申请编号，批复状态→作废中
  2. 客户经理任务页【ZJJK00180125PDCP】：授信批复（维护客户授信基本信息 ZJJK00208001 填作废理由→【保存】）→ 用信批复（查看）→ 影像（ZJJK00100615）→ 意见提交（ZJJK16071660）
  3. 审批人员任务页【ZJJK00208002PDCP】查看 +【审批】弹窗提交意见
  4. 【流程结束】规则：流程状态→通过；批复状态→**已作废**；额度注册服务置额度失效（失败「额度注册异常」中断）
- **章节出处**：ch02 §2.2.2。

## C8 授信配置维护（授信系数 / 拨款系数 / 农户授信额度）

- **闭环目标**：新增一条配置记录并可在列表查到。
- **有序步骤**（三模块同构）：
  1. 主页（授信系数 ZJJK00110085 / 拨款系数 ZJJK00110187 / 农户授信额度 ZJJK00110196）→【新增】
  2. 弹窗（ZJJK00110089 / ZJJK00110195 / ZJJK00110201[+法人机构列表 ZJJK00110515]）填写必填项 →【保存】
  3. 列表刷新可见 →【查看】只读核验 →（可选）【修改】/【删除】（逻辑删除）
- **特殊规则**：授信类型联动信用等级字典分组（对公→分组3、零售→分组1、其他→9999999）。
- **章节出处**：ch06。
