# 1.1.15 限额释放

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.15 限额释放
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000136）

## 要点摘要
- 对外接口：释放已占用限额。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须提供**交易流水号、业务流水号、业务对象编号、交易金额**；交易金额须 ≥0；**同一交易流水号、业务流水号不能多次释放**。
2. 系统按**业务对象编号**查询原限额占用记录，**逐个限额编号**执行释放处理。
3. 释放金额计算公式：
   - 本次释放金额 = 本次释放金额原币 × 汇率，保留两位小数
4. 组合限额变化：
   - 组合限额已用金额 = 原组合限额已用金额 - 本次释放金额
   - 组合限额可用金额 = 组合限额总额 - 组合限额已用金额
5. 单户限额变化：
   - 单户限额已用金额 = 原单户限额已用金额 - 本次释放金额
   - 单户限额可用金额 = 单户限额总额 - 单户限额已用金额
6. 限额释放后生成一条**限额释放记录流水**。
