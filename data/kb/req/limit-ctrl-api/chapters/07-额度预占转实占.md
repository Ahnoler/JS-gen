# 1.1.7 额度预占转实占

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.7 额度预占转实占
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000055）

## 要点摘要
- 对外接口：将预占用转为正式实占。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验（1.1.7.5.1 参数规则）
1. **客户编号、预占用流水号、业务流水号**必须齐全；业务信息中**合同编号、合同金额、合同币种**必须齐全，金额类字段 ≥0。
2. 根据预占用流水号校验是否存在预占用信息，不存在则报错。
3. 本次转实占金额 = 申请金额原币 × 汇率；本次转实占金额 ≤ 预占用流水的**剩余可转实占金额**。
4. 若接口存在多占客户列表，须校验与预占用的多占客户列表**相同**。
5. 占用的额度状态必须为**生效且未到期**，否则报错。
6. 转实占成功后：额度上**预占金额减少、实占金额增加、额度已用金额不变**；若**释放剩余额度标志为是**，转实占后释放剩余预占用金额，同时恢复相应额度。
7. 转实占成功后生成一条**预占转实占流水**。

## 待湿测
- 「释放剩余额度标志」取值枚举待湿测；与 1.1.6 预占记账口径的衔接（见 06 章「待湿测」）待抓包确认。
