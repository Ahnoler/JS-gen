# 1.1.10 额度列表查询

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.10 额度列表查询
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000091）

## 要点摘要
- 对外接口：多条件分页查询额度列表。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须至少提供**客户编号、额度编号或客户编号列表**之一；三者均为空时拒绝查询。
2. 查询条件支持：**客户类型、客户编号、客户编号列表、额度编号、节点编号、批复编号、产品编号、状态、租户、查询类型**。
3. 系统将额度主表分页结果逐条复制为接口响应明细，并**保留分页信息**。
4. 查询无结果时，接口返回**空分页结果**（不报错）。

## 待湿测
- 分页参数（页大小/页码）名称与上限、查询类型枚举待湿测确认。
