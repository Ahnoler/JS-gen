# 1.1.4 额度释放

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.4 额度释放
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000028）

## 要点摘要
- 对外接口：按合同维度释放已占用额度。其余小节（功能描述等）均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须提供**客户编号、业务流水号、本次申请释放金额、币种、合同编号**；本次申请释放金额 ≥0。
2. 按**合同编号**查询实占汇总记录；找不到记录时拒绝释放。
3. 释放金额不能超过该笔合同占用的额度金额；释放敞口金额不能超过该笔合同占用的敞口额度金额。
4. 释放金额计算公式：
   - 折算释放金额 = 本次申请释放金额原币 × 占用时汇率，保留两位小数
   - 折算释放敞口金额 = 本次申请释放敞口金额原币 × 占用时汇率，保留两位小数
5. 额度已用、可用变化：
   - 已用金额 = 原已用金额 - 本次折算释放金额
   - 额度可用金额 = 额度金额 - 已用金额 - 冻结金额
6. 敞口变化：
   - 已用敞口金额 = 原已用敞口金额 - 本次折算释放敞口金额
   - 额度可用敞口金额 = 额度敞口金额 - 已用敞口金额
7. 释放后生成一条**释放记录流水**。（原文标题写作「额度占用后生成一条释放记录流水信息」，语义为释放成功后落流水。）

> SUT 实测 2026-09-06（锚=接口 1.1.4，证据源：wet-test.md 主链1叶3 + 运行记录报文映射表）：
> - SUT 交易码为 **`doOcpRevoke`**（tansun-tcp-ulm，历史报文窗口成功 2/失败 6）。SUT 措辞「Revoke」实为**释放**语义，冲正另有交易码 `doReverse`（wording 级差异，需求口径「额度释放」不变）。
> - 成功样本（2026-08-13）请求含 **`rlseRsn` 释放原因**字段（如「发生展期释放额度」）——文档必填清单（规则1）未记载该字段，实测报文按合同编号+释放金额+释放原因组织，与规则1/2 语义相容；rlseRsn 为 SUT 多出的报文字段，回填补记。
> - 失败原文：`占用额度金额为空`（无占用汇总记录时拒绝，同规则2语义）。另：失败样本 6 笔均为此错，说明有外部系统在无占用时反复调释放，SUT 无调用方引导/校验提示（详见 1.1.1 章「方法与行为对照」附节）。
