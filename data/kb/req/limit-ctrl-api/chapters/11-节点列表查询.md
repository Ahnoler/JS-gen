# 1.1.11 节点列表查询

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.11 节点列表查询
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000100）

## 要点摘要
- 对外接口：查询额度体系节点清单。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 支持过滤条件：**末级节点标志、节点编号、节点名称、节点编号列表**。
2. 系统从**额度体系节点表**查询节点清单，返回**节点编号、节点名称、额度体系类型、末级标志**等节点属性。

## 待湿测
- 返回节点属性的完整字段清单（原文无表格）待湿测核对。
