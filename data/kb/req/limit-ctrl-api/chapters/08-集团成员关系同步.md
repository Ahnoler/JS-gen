# 1.1.8 集团成员关系同步

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.8 集团成员关系同步
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000064）

## 要点摘要
- 对外接口：同步集团客户与成员客户的归属关系（加入/退出）。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须提供**集团客户编号、成员客户编号、变更类型**；变更类型有**加入、退出**。
2. 新增成员前系统按集团客户编号 + 成员客户编号查询现有关系；关系**已存在时直接忽略**本次新增（幂等）。
3. 删除成员前系统查询现有关系；关系**不存在时直接忽略**本次删除（幂等）。

## 待湿测
- 成员加入/退出后对集团额度（汇总/集团额度节点）的联动影响，本册未写明，待湿测或交叉参考 C03 集团授信分册。
