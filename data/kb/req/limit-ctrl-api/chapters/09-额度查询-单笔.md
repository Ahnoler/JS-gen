# 1.1.9 额度查询（单笔）

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.9 额度查询（单笔）
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000082）

## 要点摘要
- 对外接口：按额度编号单笔查询额度。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须提供**额度编号**。
2. 按额度编号查询额度主表；未找到记录时按额度编号返回**数据不存在**校验错误。
3. 查询成功后返回该额度编号对应的额度信息。

## 待湿测
- 返回的额度信息字段清单（原文无表格）待湿测抓包核对。
