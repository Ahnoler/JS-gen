# 1.1.6 额度预占用

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.6 额度预占用
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000046）

## 要点摘要
- 对外接口：预占（冻结性质）额度，供后续转实占。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须齐全：**客户编号、节点编号、业务流水号、汇率**；业务信息中**合同编号、合同金额、合同币种**必须齐全，金额类字段 ≥0，否则报错中断。
2. 多占客户：逐个校验多占客户、占用金额，以及节点编号或额度编号至少提供一个；同时为空中断。
3. 系统校验主客户和多占客户均已存在；任一客户信息不存在时提示客户信息缺失并中断。
4. 占用的额度状态必须为**生效且未到期**，否则报错。
5. 请求有传客户编号和额度编号时，校验该额度必须归属该客户。
6. 以合同金额作为本次预占用申请金额，以合同敞口金额作为预占用敞口金额，以合同币种作为占用币种。
7. 多占客户继承主交易币种和汇率。
8. 同一笔**合同编号不能进行多次额度预占用**。
9. 预占折算公式：
   - 折算预占用金额 = 原币预占用金额 × 汇率，保留两位小数
   - 折算预占用敞口金额 = 原币预占用敞口金额 × 汇率，保留两位小数
   - 多占客户未传金额、敞口或汇率时，分别继承主交易金额再折算
10. 额度已用、可用变化：
    - 已用金额 = 原已用金额 + 本次折算预占用金额
    - 额度可用金额 = 额度金额 - 已用金额 - 冻结金额
11. 敞口变化：
    - 已用敞口金额 = 原已用敞口金额 + 本次折算预占用敞口金额
    - 额度可用敞口金额 = 额度敞口金额 - 已用敞口金额
12. 预占用成功后生成一条**预占用记录流水**。
