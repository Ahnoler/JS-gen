# 1.1.5 额度冲正

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.5 额度冲正
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000037）

## 要点摘要
- 对外接口：对已发生的额度占用/释放做反向冲账。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须提供**原业务流水号**；本次冲正业务流水号不能为空（原文「不能未空」）。
2. 按原业务流水号查询**有效额度使用流水**；找不到有效流水时拒绝冲正。
3. 只支持对**额度占用、额度释放**进行冲正；其他发生类型不支持冲正。
4. 按原流水金额构造**反向额度发生额**，生成新的冲正额度使用流水，并将原流水标记为**已冲正**。
5. 按原交易类型分别回退实占汇总、预占汇总和额度主表相关金额。
6. 直接占用交易若已发生额度释放的**无法冲正**。
7. 本次冲正金额 = 占用/释放流水中的交易金额，金额变化：
   - 额度占用冲正：已用金额 = 原已用金额 - 本次冲正金额
   - 额度恢复冲正：已用金额 = 原已用金额 + 本次冲正金额
   - 额度可用金额 = 额度金额 - 已用金额 - 冻结金额

## 待湿测
- 「额度恢复冲正」与「额度释放冲正」的关系（释放冲正即恢复）待湿测确认；已释放部分占用能否部分冲正待确认。
