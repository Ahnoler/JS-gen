# 1.1.13 限额占用校验

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.13 限额占用校验
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000118）

## 要点摘要
- 对外接口：限额（limit，区别于额度）占用前的试算校验，不做数据操作。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 仅对限额是否可占用进行校验，**不进行具体数据操作**。
2. 校验请求中的交易金额按汇率折算；**汇率为空时按 1** 处理。
3. 限额占用按**机构、产品、区域、行业、客户、客户类型、期限、担保方式、投资行业、额度节点、贷款用途**等维度命中限额；所有命中的限额都需要**依次**进行校验。
4. 限额目标金额 × 阈值 < 限额已用金额 + 本次占用金额（折算后）时，触发**限额金额校验**。
5. 同一个**业务对象编号**不能进行多次限额占用。
6. 管控措施为**禁止** → 返回强校验结果；管控措施为**提示** → 返回弱校验结果。
