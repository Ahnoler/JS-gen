# 1.1.16 限额冲正

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.16 限额冲正
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000145）

## 要点摘要
- 对外接口：对限额占用/释放做反向冲账。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须提供**原业务流水号**；本次冲正业务流水号不能为空。
2. 按原业务流水号查询**有效限额使用流水**；找不到有效流水时拒绝冲正。
3. 只支持对**限额占用、限额释放**进行冲正；其他发生类型不支持冲正。
4. 按原流水金额构造**反向限额发生额**，生成新的冲正限额使用流水，并将原流水标记为**已冲正**。
5. 限额占用交易若已发生限额释放的**无法冲正**。
6. 本次冲正金额 = 占用/释放流水中的交易金额，金额变化：
   - 限额占用冲正：限额已用金额 = 原限额已用金额 - 本次冲正金额
   - 限额恢复冲正：限额已用金额 = 原限额已用金额 + 本次冲正金额
   - 限额可用金额 = 限额目标金额 - 已用金额
7. 冲正完成后生成一条**限额冲正流水**。
