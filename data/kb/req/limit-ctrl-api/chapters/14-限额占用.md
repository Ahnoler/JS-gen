# 1.1.14 限额占用

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.14 限额占用
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000127）

## 要点摘要
- 对外接口：正式占用限额。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 默认**超限占用标志为否**；汇率为空时默认按 1 折算。
2. 必须提供**交易流水号、业务流水号、业务对象编号、客户类型、客户编号、币种、交易金额**；交易金额须 ≥0。
3. 按机构、产品、区域、行业、客户、客户类型、期限、担保方式、投资行业、额度节点、贷款用途等维度命中限额；**命中多个限额则需要占用多个**。
4. 同一个**业务对象编号不能进行多次限额占用**。
5. 折算占用金额 = 占用金额原币 × 汇率，保留两位小数。
6. 组合限额金额变化：
   - 组合限额已用金额 = 原组合限额已用金额 + 本次折算占用金额
   - 组合限额可用金额 = 组合限额总额 - 组合限额已用金额
7. 单户限额金额变化：
   - 单户限额已用金额 = 原单户限额已用金额 + 本次折算占用金额
   - 单户限额可用金额 = 单户限额总额 - 单户限额已用金额
8. 限额占用后生成一条**限额占用记录流水**。
