# 1.1.17 限额重算

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.17 限额重算
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000154）

## 要点摘要
- 对外接口：按新维度重新命中限额（原占用恢复后重占）。其余小节均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须提供**业务对象编号、客户编号、重算交易金额**；重算交易金额须 ≥0。
2. 系统先按业务对象编号查询原占用的限额，**恢复原占用的限额**，再按新传入的维度**重新命中**新的限额。
3. 重新占用限额计算公式：
   - 折算占用金额 = 原币占用金额 × 汇率，保留两位小数
4. 组合限额变化：
   - 组合限额已用金额 = 原组合限额已用金额 + 本次折算占用金额
   - 组合限额可用金额 = 组合限额总额 - 组合限额已用金额
5. 单户限额变化：
   - 单户限额已用金额 = 原单户限额已用金额 + 本次折算占用金额
   - 单户限额可用金额 = 单户限额总额 - 单户限额已用金额

## 待湿测
- 重算未传汇率时默认按 1（同 1.1.14）是否适用待湿测；重算后是否生成新流水原文未明示，待确认。
