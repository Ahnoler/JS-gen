# 1.1.2 额度占用校验

**标题路径**：1 额度管理 > 1.1 额度管控接口 > 1.1.2 额度占用校验
**来源**：D03【管控接口】分册（RQM entry ZC00032131PDCP-000010）

## 要点摘要
- 对外接口：只校验不落账的额度占用试算。功能描述/操作权限/操作步骤/界面原型/输出输入/外部接口调用/补充说明均为「无」。ZJJK：无。

## 关键规则 / 字段 / 校验
1. 必须提供**客户编号、节点编号、业务流水号、合同编号、合同金额、币种**。
2. 多占客户：每个客户必须提供**客户编号、申请金额**，且必须至少提供节点编号或额度编号之一。
3. 占用校验只执行校验流程，**不做数据更新**；错误码、错误信息、校验结果、校验类型、校验标题逐条返回；返回空校验明细 = 校验通过。
4. 多占客户有传节点编号时，按客户编号+节点编号查询额度信息，未找到对应额度则拒绝校验。
5. 占用的额度必须为**生效状态且未到期**；否则形成强校验结果返回调用方。
6. 超额占用标志未否时，校验本次占用金额不能超过额度可用金额。
7. 同一笔**合同编号不能进行多次额度占用**。
8. 占用校验金额计算公式：
   - 折算申请金额 = 申请金额 × 汇率，保留两位小数
   - 折算申请敞口金额 = 申请敞口金额 × 汇率，保留两位小数
9. 非超额占用时额度可用校验公式：
   - 折算申请金额 ≤ 额度可用金额
   - 折算申请敞口金额 ≤ 敞口可用金额
