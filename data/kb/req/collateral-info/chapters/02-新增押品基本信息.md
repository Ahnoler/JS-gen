# 02 新增押品基本信息

> 标题路径：押品管理-押品信息管理 > 押品信息管理 > 新增押品基本信息
> 出处：tmp 源 dump「新增押品基本信息.txt」（~5500 行）

## 要点摘要

- 场景链：**主页（押品信息管理主页）→ 新增押品向导页 → 客户经理配置押品公共信息页面（12 标签页）→ ~60 类押品种类明细模板子页 → 各配置子页（共有权人/价值/权证/保险/补充/关联贷款/影像/管理团队/权限移交/违约损失）**，最终保存为「暂存」态押品，走准入后变「已准入」。
- 主页（ZJJK00095044）承载查询 + 16 个按钮规则；新增入口对客户经理（X0018）开放，按钮可见性受角色控制。

## 关键规则/字段/校验

### 主页按钮规则（摘要）
- 【新增】仅客户经理可见；跳转新增向导页。
- 【准入】准入校验规则链（全部通过才准入）：
  1. 押品状态须为「暂存」且经办人=当前登录人；
  2. 信贷正式客户校验（押品所有人须为正式客户）；
  3. 信息完整性校验（必填项齐备）；
  4. 共有权人校验（权益比例总和 ≤100%）；
  5. 保险信息校验；
  6. 详细信息必填校验（按押品种类明细模板）；
  7. 农合机构股权押品试算校验；
  8. 不动产联动校验。
  - 准入失败分支按提示定位到具体页签；成功后押品状态 暂存→已准入。
- 【修改】【删除】【查看】按记录状态（暂存/已准入等）与经办人约束；删除仅暂存态。
- 其余按钮：权限移交、打印等（详见源）。

### 新增向导页（下一步）
- 必填校验；模板缺失校验（押品种类未配置明细模板则拒绝）；
- **保证金账户类押品拒绝新增**；
- 权证文本编号唯一性校验；
- 初始化：基本信息/权证信息/押品管理团队/详细信息 各步骤数据。

### 配置押品公共信息页面（12 标签页）
基本信息 / 详细信息（按种类模板）/ 共有权人 / 押品价值 / 权证信息 / 保险信息 / 补充信息 / 关联贷款 / 影像信息 / 管理团队 / 权限移交 / 违约损失率。逐标签页保存；每页有独立必填与格式校验（字段级清单见源表，量大约 60 种类模板）。

### 业务约束（6 条，源 §新增押品基本信息 末尾）
1. 保证金账户类押品不可新增；
2. 权证文本编号全局唯一；
3. 共有权人权益比例总和 ≤100%；
4. 押品种类必须已配置明细模板；
5. 明细模板必填项齐备方可准入；
6. 其余见源（逐条）。
