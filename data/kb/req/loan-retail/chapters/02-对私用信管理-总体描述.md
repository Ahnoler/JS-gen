# 02 对私用信管理-总体描述

## 标题路径
用信管理需求分册-对私用信 > 对私用信管理 > 总体描述

## 要点摘要
- 功能说明：对私用信全生命周期；覆盖 20 种贷款产品类型；审批环节链：客户经理发起信贷调查 → 协办二次调查 → 审查 → 审批 → 有权审批人。
- 状态说明：4 组状态机（详见下）。

## 关键规则/字段/校验
- **用信流程状态（AprvSt）**：待发起 / 审批中 / 打回 / 已撤销 等；待发起、打回状态才可修改。
- **担保合同变更类型**：新增(引入) / 原担保 / 变更 / 弃用，及其状态迁移。
- **共同借款人变更类型**：原信息 / 新增 / 退出。
- **审批条件落实状态**：未落实 → 已落实（单向，不可回退）。
- 20 种产品类型：消费贷款、个人房屋装修、经营贷款、一手房按揭、二手房按揭、自建房按揭、一手车、二手车、农户贷款、工程机械、人才贷款、人才经营、农业保险保单融资、司法拍卖、司法拍卖经营、运动健将、运动健将经营、闪链、创业担保、家庭农场。
- 用信发起模式字典 crlineUseIttModeCd：1 单独发起 / 2 二合一 / 3 合并流程发起（三合一）/ 4 三合一（对应三合一场景）。
