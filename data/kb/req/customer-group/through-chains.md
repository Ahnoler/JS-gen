## 1. 候选可贯通主链

### 主链 C1：集群客户 — 新增 → 维护基本信息 → 新增成员（人工）闭环
- **闭环目标**：创建一个集群客户并人工加入至少一个成员，成员列表与成员数可查询验证。
- **前置条件**：已登录有集群管理角色的用户；放大镜中存在「信贷正式客户」；目标客户未归属其他集群。
- **有序步骤**：
  1. 进入【集群客户管理】主页（ZJJK00104877），列表自动加载。
  2. 点【新增】→ 新增集群客户向导页（ZJJK00107450）。
  3. 输入集群名称 →【保存】（必填校验「请输入集群名称」；文档口径：提交审批流程）→ 跳转维护页（任务页 ZJJK00104925）。
  4. 维护基本信息（ZJJK00104897）：仅集群名称可改，【保存】→「操作成功」。
  5. 维护集群成员信息主页（ZJJK00104900）→【新增】→ 集群成员弹窗（ZJJK00107302）。
  6. 放大镜引入成员客户 → 设置核心客户标识（默认否）→（非核心）选关联客户 + 关联关系类型 →【保存】。
  7. 保存校验链：核心客户唯一 → 关联关系×客户类别匹配（四类规则）→ 跨集群唯一归属 →「操作成功」，生成类型=人工。
  8. 回主页按集群编号【查询】验证新集群与成员数。
- **章节出处**：chapters/02-集群客户管理.md（ZJJK00104877 / 00107450 / 00104925 / 00104897 / 00104900 / 00107302）。
- **湿测风险点**：新增集群「提交审批流程」后是否可直接进入维护页；核心客户重复为硬中断。

### 主链 C2：集群客户 — 批量导入成员（Excel）闭环
- **闭环目标**：用模板 Excel 一次导入多个成员，成功后成员列表与成员变动记录可见。
- **前置条件**：已有集群（或与 C1 串联）；已下载模板 colonyTemplate.xlsx；客户存在于信贷系统。
- **有序步骤**：
  1. 主页选中集群（或直接点【导入成员模板】下载 colonyTemplate.xlsx）。
  2. 填写模板：所属集群编号、客户类别、成员客户编号、成员客户名称、核心客户状态（必填）；非核心需关联人+关联关系。
  3. 点【导入成员】→ 集群成员导入（ZJJK00128510）→ 选择文件 → 上传。
  4. 文件校验：xls/xlsx、非空、≤1MB、≤1000行。
  5. 行级校验：必填 → 已归属其他集群 → 核心唯一 → 客户存在 → 关联关系合法且与类别匹配（错误提示带行号）。
  6. 导入成功：批量新增、记录变更历史、重算各集群成员数。
  7. 验证：成员列表可查；其他信息页签「成员变动记录」（ZJJK00107528）出现「进入」记录。
- **章节出处**：chapters/02-集群客户管理.md（ZJJK00128510、ZJJK00107528）。
- **湿测风险点**：错误提示的行号定位；导入失败部分行的回滚行为（文档未写明）。

### 主链 C3：总集团客户 — 新增 → 维护信息 → 新增成员 闭环
- **闭环目标**：创建总集团并加入成员（含核心客户），成员数与变更历史可验证。
- **前置条件**：登录用户；成员客户未存在于该总集团。
- **有序步骤**：
  1. 进入【总集团客户管理】主页（ZJJK00105093）。
  2. 【新增】→ 新增总集团客户向导页（ZJJK00107648）：填总集团名称 →【保存】→ 跳转维护页（任务页 ZJJK00105128）。
  3. 维护总集团基本信息（ZJJK00105105）：可改名称，【保存】→「保存成功」。
  4. 维护总集团成员信息主页（ZJJK00105106）→【新增】→ 总集团成员弹窗（ZJJK00107660）：放大镜引入 → 核心=是（无需关联客户）或否（关联客户+关系类型）→【保存】。
  5. 校验链：必填 → 重复新增 → 关联关系必选 → 非核心须关联人 → 类别匹配 → 核心唯一（「请确认」确认提示）→「保存成功」+ 变更历史 + 重算成员数 + 更新集团成员表总集团编号。
  6. 验证：主页按总集团编号【查询】；成员变动记录（ZJJK00107658）出现「进入」。
- **章节出处**：chapters/03-总集团客户管理.md。
- **湿测风险点**：核心客户重复时「确认」后是否放行；向上查找所属总集团的查询联动。

### 主链 C4：集团客户 — 新增向导（基本信息→成员→母公司校验）闭环
- **闭环目标**：创建集团客户（挂某总集团），加入成员含母公司，通过【下一步】进入财务信息步骤。
- **前置条件**：已存在总集团（C3 前置链）；存在「信贷正式/潜在客户」作实际控制方与成员；登录用户。
- **有序步骤**：
  1. 进入【集团客户管理】主页（ZJJK00105164）→【新增】→ 新增集团客户主页（ZJJK00107802）。
  2. 填集团名称、所属总集团（下拉）、实际控制方（放大镜 ZJJK00109101 引入）、主营行业类型、集团报表口径 →【保存】。
  3. 校验链：必填 → 该总集团在本市县法人行已建集团则提示「请确认」→ 跳转【主办客户经理维护集团客户信息】（任务页 ZJJK00090114）。
  4. 维护集团基本信息（ZJJK00107808）：集团编号只读，改名称/口径，【保存】。
  5. 维护集团成员信息（ZJJK00107812 → 弹窗 ZJJK00107813）：放大镜范围限该总集团内成员；校验链：必填 → 集团内重复 → 母公司唯一 → 禁同业 → 成功后成员数+1、母公司回写集团母公司客户编号。
  6. 点【下一步】：成员列表非空 + 合并报表须有母公司成员（「请添加成员信息！」「该集团客户成员缺少母公司！」）→ 进入财务信息步骤（ZJJK00106437，仅合并报表展示）。
- **章节出处**：chapters/04-集团客户管理.md。
- **湿测风险点**：非合并报表时的拦截文案；成员数/母公司回写的可观测验证。

### 主链 C5：集团客户 — 查看完整档案（评级/额度/持股）闭环
- **闭环目标**：以只读模式浏览集团客户档案各页签，验证评级与额度列表的权限控制。
- **前置条件**：已存在集团客户（C4 产物或既有数据）；测试账号含/不含管户客户经理身份各一。
- **有序步骤**：
  1. 主页选中记录 →【查看】→ 查看集团客户信息（FS00003077，任务页 ZJJK00095919）。
  2. 基本信息页签：集团基本信息 + 评级列表（ZJJK00204258PDCP / ZJJK00114024）+ 额度列表（ZJJK00114016 / ZJJK00100609）。
  3. 选中评级/额度记录点【详情】：经办人或管户客户经理可看；否则「仅支持管户客户经理或业务经办人查看详情！」。
  4. 切换成员持股情况页签（ZJJK00105203）：【导出】空列表提示「列表数据为空不可导出」，非空确认「最大只能导出前1000条数据，是否确认导出？」。
  5. 切换其他信息页签：历史修改记录（ZJJK00107809）、成员变动记录（ZJJK00107810）、登记信息（ZJJK00114012）只读展示。
- **章节出处**：chapters/04-集团客户管理.md。
- **湿测风险点**：详情跳转的目标页面（评级/授信页）是否在 SUT 范围内。

## 2. 对偶/旁路操作（非独立主链，可并入 C1–C5 湿测）

| 操作 | 范围 | 关键规则 | 出处 |
|---|---|---|---|
| 修改 | 集群/总集团/集团 三类 | 需选中记录（「请选择有效数据」）；集群/总集团删除类按钮需角色；集团修改需管户客户经理；回显已录入信息 | 02/03/04 章 |
| 查看 | 三类 | 只读态跳转维护页/详情页 | 02/03/04 章 |
| 删除 | 三类 | 确认框「您确定删除这条记录吗?」；集团需管户客户经理，成功「删除成功」 | 02/03/04 章 |
| 查看关系 / 图谱 | 三类成员列表 | 需选中记录；图谱按集群/总集团编号渲染，无效关联虚线（总集团口径） | 02/03 章 |
| 导入成员模板 | 集群 | 下载 colonyTemplate.xlsx | 02 章 |
| 历史修改记录 / 成员变动记录 / 登记信息 | 三类 | 降序排列、每页10条；变动记录区分 手动/日终系统 来源 | 02/03/04 章 |
| 成员持股导出 | 三类 | 空不可导出；上限1000条确认框；日终批量更新 | 02/03/04 章 |

## 3. 建议下一湿测主链
- 首选 **C1**（集群新增+成员人工新增）：校验链最长、提示文案明确，最适合作为该模块首条贯通链。
- 次选 **C4**（集团向导+母公司校验）：依赖总集团数据，建议 C1/C3 跑通后串测。

## 4. 明确的 Out（文档口径中无法在 SUT 直接闭环的）
- 集群新增「提交至审批流程」的审批环节：文档未给审批页面，湿测只能验证提交后状态。
- 财务信息细则（附件《智能财报》）与影像目录规则（附件《影像信息目录》）：本分册不含附件内容。
- 日终批量（系统拉入/拉出成员、持股数据刷新）：湿测无法主动触发，只能观察既有数据。
- 「向额度系统同步集团成员关系」：无对应界面，仅可观察副作用。
