## 1. 候选主链

### 主链 A：产品建库→配置→启用（核心闭环）

- **闭环目标**：新建产品完成要素/阶段配置并启用，可供业务调用。
- **前置条件**：总行用户账号；产品要素库中已有可用要素/组件（最小闭环可不依赖，待湿测）；如需阶段管控则先在【产品阶段管理】建好阶段。
- **章节出处**：§配置产品信息 → §产品库管理（ZJJK00110131）；可选配置走 §产品详细信息（ZJJK00107304/136564/136733/94364/98070）；启用规则见主页【启用】规则。

### 主链 B：产品克隆→改配置→启用（复制型闭环）

- **闭环目标**：以既有产品为模板快速创建同类产品并启用。
- **前置条件**：总行用户；已有源产品。
- **章节出处**：§产品库管理 → §产品克隆（ZJJK00097067）。
- **有序步骤**：
  1. 产品库主页选中源产品 → 【产品克隆】（系统先生成新编号）；
  2. 弹窗填新产品名称（必填，空→"请输入新产品名称"）→【确定】→"克隆成功"；
  3. 副本 = 全部产品信息 + 阶段关系 + 管控要素 逐条复制，状态未启用、V-0.0.1；
  4. 回主链 A 第 6–9 步按需调整并启用。
- **待湿测**：克隆后副本在树中的挂载位置（是否同父分类）。

### 主链 C：产品修改→新版本→（再启用）

- **闭环目标**：对启用/禁用产品变更，产出未启用新版本，重新编辑后走启用。
- **前置条件**：总行用户；产品状态=启用或禁用；无同编号未启用待改记录。
- **章节出处**：§产品库管理 → §产品修改。
- **有序步骤**：选中启用/禁用产品 →【产品修改】→ 版本递增（V-X.Y.Z 三位规则）生成未启用新版本 + 复制阶段关系与管控要素 → 详情页编辑（主链 A 第 6–8 步）→【启用】。
- **边界**：已存在待修改记录→"已存在待修改记录"中断。

### 主链 D：维护核心产品映射（发布后闭环）

- **闭环目标**：为已配置/发布产品建立与核心产品的唯一映射，供核心系统同步。
- **前置条件**：存在启用或禁用状态产品（主页树仅显示这两态）。
- **章节出处**：§维护核心产品映射（ZJJK00095454 / 弹窗 ZJJK00095468）。
- **有序步骤**：
  1. 主页左侧产品树选中产品；
  2. （可选）按核心产品编号/名称【查询】过滤；
  3. 【新增】→ 弹窗填主体类型（默认对公）、核心产品编号/名称、涉农/垫款/社团标志 →【保存】（同产品下五维度组合不重复，重复→"录入信息重复，请检查！"）；
  4. （可选）选中记录【修改】→ 同弹窗回显编辑；
  5. （可选）选中记录【删除】→ 确认"您确认删除这条记录吗？"。

### 主链 E：产品要素库维护（前置支撑链）

- **闭环目标**：建成可被产品详情挂载的要素分组/组件/要素体系。
- **前置条件**：无（法人行级全员可操作分组；要素维护为产品管理员）。
- **章节出处**：§产品要素管理（ZJJK00094373/94374/94375/94376）。
- **有序步骤**：
  1. 【产品要素库】打开分组主页（左树：公共/个性化双根）；
  2. 【新增类型】（个性化侧）或【新增组件】（公共侧/个性化类型节点）→ 弹窗 ZJJK00094374 填名称+序号 → 保存（序号非零数字校验）；
  3. 选中组件 → 右侧产品要素页签 →【新增】要素（远程搜索产品数据项、自动编码、按要素类型配字典）→ 确定；
  4. （可选）【修改】/【删除】要素（被产品引用不可删）。
- **闭环出口**：组件/要素可在产品公共要素配置页签、设置管控要素-添加组件中被引用。

### 主链 F：维护产品阶段（前置支撑链）

- **闭环目标**：建成阶段主数据树供产品关联。
- **前置条件**：无。
- **章节出处**：§维护产品阶段（ZJJK00095902）。
- **有序步骤**：【新增阶段】（系统生成编号）→ 填阶段名称 →【保存】；（可选）【新增子阶段】；（可选）【删除】（有下级/被产品引用不可删）。
- **闭环出口**：产品个性化要素配置【设置阶段】弹窗可选到。

### 主链 G：查询产品→详情/历史/导出（只读闭环）

- **闭环目标**：检索并查看产品全生命周期配置。
- **前置条件**：产品已存在（列表仅叶子、状态禁用/启用/失效）。
- **章节出处**：§查询产品（ZJJK00095907；FS00003307 任务页 ZJJK00132798；版本历史 ZJJK00149164PDCP）。
- **有序步骤**：
  1. 主页输入名称/编号/状态/目录（目录递归含子节点）→【查询】；
  2. （可选）选中记录 →【产品详情】只读分页签查看（基本信息/公共要素/个性化要素）→【返回】；
  3. （可选）【产品历史】→ 版本历史列表 → 选版本【查看】版本详情；
  4. （可选）【导出】Excel（禁用/启用叶子，≤20000 条）。

## 3. 通用规则（跨主链）

- 逻辑删除统一模式：引用校验 → 确认弹窗 → 标记已删除 → 刷新。
- 区间类要素取值四元组（左值/左符号/右符号/右值）：同空或有、左≤右校验；存储"左值,左符号,右符号,右值"。
- 版本规则：V-X.Y.Z 三位递增；初始 V-0.0.1；克隆/修改复制阶段关系+管控要素。
- 状态字典 xdPdCd：1未启用 2流程中 3禁用 4启用 5失效。
- 状态机：未启用 →启用→ 禁用；启用/禁用 →修改→ 未启用新版本；未启用 →启用→ 旧启用/禁用版本失效。
