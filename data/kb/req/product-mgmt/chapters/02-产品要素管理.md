# 产品要素管理 → 维护产品要素

- 标题路径：产品管理 → 产品要素管理 → 维护产品要素
- 出处：源文档 §产品要素管理（全章）
- 菜单路径：【产品管理】→【产品要素管理】→【产品要素库】

## 要点摘要

管理产品要素分组的树形结构（左侧树：**产品公共要素 / 产品个性化要素** 两个根节点，按序号升序；右侧展示选中分组基本信息 + 产品要素页签）。分组类型为"要素组件"时右侧显示产品要素页签，可对要素做新增/修改/删除。新增要素从产品数据项中选要素名称自动填编码，按要素类型配数据字典类型/字典组。业务流程：无。

## 关键规则 / 字段 / 校验

### 分组主页 ZJJK00094373
- 权限：法人行级，全部用户；【新增类型】【新增组件】【删除】；数据权限按业务条件，无身份隔离。
- 页面初始化：数据类型=基本要素→返回产品公共要素根节点；=管控要素→返回产品个性化要素根节点；空→两个根节点。父级编号为空的记录自动挂对应根节点。
- 管控要素（个性化）：可新增多层级子类型，**组件是末级节点**；基本要素（公共）：可新增多层级子组件。
- 分组类型=要素组件→展示基本信息+产品要素页签；=要素类型→仅基本信息页签。
- 【搜索】：按分组名称过滤树节点。

### 新增类型 / 新增组件（弹窗 ZJJK00094374）
- 【新增类型】显示：数据类型=管控要素 且 节点分组类型=要素类型。
- 【新增组件】显示：数据类型=基本要素；或 =管控要素且节点为要素类型。打开弹窗自动带入上级编号、分组类型。
- 字段：组件编号 elmtGrpgNo（系统自动生成，不可编辑）；组件名称 elmtGrpgNm（必填）；组件类型 prnNo（上级分组，只读）；序号 seqNo（必填）。
- 保存校验：序号须为非零数字（"序号应为数字！"/"序号应为非零数字！"）；组件名称与序号非空（"必填字段不能为空！"）；存在则更新、不存在则新增；成功后刷新左侧树。

### 删除分组
- 选中非根节点才显示；有下级分类→"存在下级分类，不能直接删除"；被产品引用→"已经被XX产品编号引用"；确认"确认删除记录信息?"后逻辑删除。

### 组件产品要素 ZJJK00094375
- 权限：法人行级产品管理员；查询/重置/新增/修改/删除。按要素编码 elmtNo(32)、要素名称 elmtNm(200) 查询。
- 要素列：要素编码、要素名称、所属列表要素编码 elmtPrnNo、要素类型 elmtTp（字典 PdElmtTp）、数据字典 dctTp、数据组 dctGrp。

### 新增/修改产品要素（弹窗 ZJJK00094376）
- 要素名称 elmtNm：远程搜索产品数据项，选后自动填要素编码 elmtNo（不可编辑）；若数据项已关联字典类型自动带入，否则按要素编码查同名字典类型（去除租户过滤），无则清空。
- 所属列表要素编码 elmtPrnNo：仅要素数据类别为列表时展示。
- 数据字典 dctTp / 字典组 dctGrp：仅要素类型为 数据字典/多选框/复选框 时展示；切换要素类型清空已选值与取值来源。
- 阈值类型呈现：文本 / 区间 / 数字（含金额）/ 列表（先建列表要素，再建字段要素，字段要素 elmtPrnNo 必填）/ 下拉多选 / 单选 / 复选 / 树多选。
- 修改：未选中→"请选择一条数据！"；带入取值范围四元组（左符号值/左符号/右符号/右符号值）。
- 删除：被产品引用→"产品存在引用不可删除，请确认后重试"；否则确认"您确定删除这条记录吗?"后逻辑删除。
