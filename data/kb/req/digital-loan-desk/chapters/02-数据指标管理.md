# 数据指标管理

> 标题路径：数字化信贷办贷端-修订版 → 数据指标管理（数据指标模板管理 / 数据指标库配置）

## 要点摘要

- 两条主线：①数据指标模板（模板生命周期 + 模板下指标列表维护）；②数据指标库（全行统一指标资产登记）。
- 模板状态（TicpStDict 分组2）：0未生效 / 1生效 / 2失效 / 3失效（字典重复项，文档口径如此）。变更：未生效→生效→失效；仅未生效或失效可删除；删除为置删除标志（不物理删）。
- 指标删除标志：未删除/已删除；已删除不出现在列表。

## 关键规则 / 字段

### 指标模板管理主页【ZJJK00124943】
- 查询：模板名称 tplNmLike（模糊）、模板状态 st、模板所属环节 bsnLnk（默认隐藏，更多展开）；仅含未删除记录。
- 模板所属环节字典 TicpIdxBlngLnkDict：0预授信进件 / 1授信进件 / 2贷款进件 / 3提款进件 / 4提额进件。
- 【生效】：须选中；已生效提示「当前模板已生效，不可重复生效！」；确认「确认生效此条记录？」后置为生效并刷新。
- 【失效】：须选中且状态为已生效；确认后置为失效。
- 【删除】：生效中不可删（「生效的模板不允许删除！」）；确认后置删除标志。
- 【详情】：打开查看场景 FS00016710（任务页 ZJJK00128494 / 查看基本信息 ZJJK00128491 / 查看指标列表 ZJJK00128492 / 查看数据指标 ZJJK00128493，均只读）。

### 新增/维护模板（场景 FS00012839）
- 任务页【ZJJK00124950】→ 维护基本信息【ZJJK00124947】：模板名称 tplNm 必填；业务环节 bsnLnk、行业类别 idyCgy、业务模式 bsnMode（TicpBussModDict：应收类/预付类/存货类/金票/云贷场景/ABS/数据贷/政采贷/公共/再保理）。
- 维护指标列表主页【ZJJK00124948】：指标类型 idxTp（TicpIdxTpDict：下拉/单选/多选/文本框/文本域/日期）；指标属性 idxAttr（TicpIdxAttrDict：身份证/社会信用代码/小数/比率/字符串/手机号/日期/整数）。【新增/修改/删除/详情】均须先选中（提示「请先选择记录」）；删除为标记已删除。
- 数据指标维护弹窗【ZJJK00124949】：指标名称 idxNm（数据选择器，分页查询指标库）、指标代码 idxCd 必填；只读/唯一性/必填标志（TicpIndicatorDict）。新增保存前校验必填与编码唯一。

### 数据指标库配置（主页【ZJJK00128369】、弹窗【ZJJK00128391】）
- 主页查询：指标名称 idxNmLike（模糊，长度200）、指标状态 idxSt（TicpStDict 分组3）。
- 新增：按指标代码查重，占用时禁止保存。
- 弹窗字段联动：指标类型为下拉/单选/多选时显示【指标数据字典】与【指标数据字典分组】；文本框/文本域/日期时自动隐藏且不要求填写。
- 查看模式弹窗全部只读；删除为标记已删除；详情只读、仅【取消】。
