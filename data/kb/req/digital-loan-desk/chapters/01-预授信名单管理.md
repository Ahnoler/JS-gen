# 预授信名单管理

> 标题路径：数字化信贷办贷端-修订版 → 预授信名单管理（对公预授信名单管理 / 个人预授信名单管理）

## 要点摘要

- 面向客户经理提供预授信名单全生命周期维护：查询、新增、修改、查看、撤销、作废、批量导入；对公与个人两套结构对称的子功能。
- 名单状态（字典 TicpPcrNmlstStatusDict）：0待提交 / 1已生效 / 2已拒绝 / 3已失效 / 4已作废 / 5已撤销。状态变更：有效→撤销、有效→作废。
- 名单来源（TicpPcrNmlstSourceDict）：0自动生成 / 1人工录入 / 2系统推送。
- 维护流程（文档口径）：主页发起维护任务 → 任务页 → 对公/个人客户信息维护 → 上传影像资料（ZJJK00125149）→ 授信额度测算 → 提交复核；复核通过后名单生效，进入下游营销产品的可售名单分发。
- 数据权限（文档口径）：客户经理仅看本人经办；县市级、地市级法人行审查岗/审定岗看当前法人行全部业务。

## 关键规则 / 字段

### 对公预授信名单主页【ZJJK00248303PDCP】
- 查询条件：对公客户名称 cpctNmLike、证件号码 crdtNoLike、产品名称 pdNmLike（均模糊）；名单来源/名单状态（精确，藏在「更多查询条件」）。结果按最近更新时间倒序、分页；进入页面自动查询，列表默认为空。
- 【新增】不要求选中记录，整页跳转空白表单（场景 FS00108621PDCP）；任务页【ZJJK00248296PDCP】按环节串行：维护对公客户信息【ZJJK00248293PDCP，含保存/返回规则】→ 上传影像【ZJJK00125149】→ 维护授信额度测算【ZJJK00248295PDCP】。
- 【撤销】【作废】针对已生效记录，确认后更新名单状态；【导入】打开文件导入弹窗【ZJJK00128013】（含模板下载、成功/失败明细展示）。

### 个人预授信名单主页【ZJJK00248239PDCP】
- 结构与对公对称；任务页【ZJJK00248255PDCP】→ 维护个人客户信息【ZJJK00248251PDCP，含「产品名称联动规则」】→ 上传影像 → 授信额度测算【ZJJK00248253PDCP】。
- 查看侧（场景 FS00108620PDCP）：任务页【ZJJK00248275PDCP】→ 查看个人客户信息【ZJJK00248274PDCP】→ 查看影像 → 查看授信额度测算【ZJJK00248273PDCP】，均只读。

### 文件导入【ZJJK00128013】（对公/个人共用组件）
- 下载模板 → 填写 → 上传 → 系统展示导入成功/失败明细。
