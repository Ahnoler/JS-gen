# 营销产品管理

> 标题路径：数字化信贷办贷端-修订版 → 营销产品管理 → 营销产品管理 → 维护营销产品

## 要点摘要

- 面向系统管理员的营销产品主档全生命周期：新增、修改、查看、删除、发布、取消发布、生成二维码；发布/取消发布由管理员直接执行，无多级审批。
- 发布状态（TicpAncStDict）：0已发布 / 1未发布（状态说明文字另称 待发布/已发布/已取消发布——两套口径并存，待湿测）。
- 营销产品状态（TicpStCdDict）：0未生效 / 1已生效 / 2已失效；维护页字典 TicpCmpnPdStDict：0未生效 / 1启用 / 2禁用。

## 关键规则 / 字段

### 营销产品主页【ZJJK00171792PDCP】
- 左侧按租户层级机构树，右侧仅列当前租户内产品；查询：营销产品编号 cmpnPdNo、名称 cmpnPdNmLike（模糊）、业务条线 lob（TicpCstTpDict：1对公 / 2个人）。
- 【修改】：仅未发布可改（「当前记录已经启用，不能修改！」）；【删除】：仅未发布可删（「当前记录已经发布，不能删除！」），删除为标记已删除；【发布】：仅待发布可发，须信息完整（基本信息/定价规则/营销策略）；【取消发布】：仅已发布可取消，二次确认；【生成二维码】：打开二维码组件弹窗。

### 新增/维护（场景 FS00052611PDCP，任务页【ZJJK00171807PDCP】四环节）
1. **维护基本信息【ZJJK00171805PDCP】**：必填——营销产品编号 cmpnPdNo(32)、名称 cmpnPdNm(200)、状态 cmpnPdSt、更新时间、创建人、创建机构、热点产品标志 hotPdInd、发布状态 ancSt（默认1未发布）；可填生效/失效时间 effTm/expyTm、产品标签 pdLbl、业务条线 lob、产品简介 pdBrf、申请条件 aplyCnd、宣传图片 bannerFileId。
2. **维护可售产品**：主页【ZJJK00204071PDCP】列表仅可售产品编号 aspdNo / 名称 aspdNm；【新增】打开关联可售产品列表【ZJJK00204076PDCP】——编号不可手工编辑，由产品树节点带入；产品树按业务条线加载对公/个人额度产品树；已有关联时保存新配置前先删除旧配置；【删除】须选中+二次确认。
3. **维护参数信息【ZJJK00204072PDCP】**：四组参数（产品基本参数信息 / 产品流程配置信息 / 产品用信提款参数 / 产品还款参数）。关键校验：
   - 最高可贷金额 hgstCanLoanAmt、贷款利率 loanIntrt、最长可贷期限 lgstCanLoanDdln 须落在可售产品要素值域内，超出提示并中止保存。
   - 提款环节标志 dwmLnkInd（TicpWdDict：1授信额度项下提款 / 2借款合同项下提款）联动：选1则流程环节须含「授信进件」，选2则须含「贷款进件」。
   - 流程环节标志 pcsLnkInd（TicpWdStepDict：1客户准入/2授信进件/3贷款进件）联动刷新提款参数显示。
   - 其余开关：支持预授信、允许提额、受托支付审批、多笔提款/用信、分次提款、未登录申请、提前还款、利息抵扣券、还款维度 repyDmsn（0合同 / 1借据）。
4. **维护进件信息**：主页【ZJJK00171806PDCP】+ 影像文件【ZJJK00124982】（新增/删除/启用/停用目录行）+ 进件模板【ZJJK00124986】（模板编号 tplNo、业务环节 bsnLnk、模板名称/标题、模板类型 tplTp：0单笔/1多笔、模板顺序；新增模板/删除模板/维护指标明细/指标明细按钮）。
