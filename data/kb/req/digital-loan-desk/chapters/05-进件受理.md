# 进件受理

> 标题路径：数字化信贷办贷端-修订版 → 进件受理（个人进件管理 / 对公进件管理）

## 要点摘要

- 承接上游进件至客户经理工作台：列表查询、受理、退回、查看；覆盖授权准入、预授信、授信、贷款、提款、提额六类进件。
- 进件类型（TicpAplTpDict）：0授权准入 / 1预授信申请 / 2授信申请 / 3贷款申请 / 4提额申请 / 5提款申请。
- 进件状态（TicpAplStDict）：0待受理 / 1受理中 / 2受理通过 / 3受理拒绝。受理状态变更：待受理→受理→已受理；待受理→退回→已退回→上游补正→待受理。
- 数据来源（TicpDtsrcDict）：0渠道端。

## 关键规则 / 字段

### 个人进件管理列表主页【ZJJK00204625PDCP】
- 查询：客户名称 cstNm、进件申请编号 aplAplyNo、产品名称 cmpnPdNm；按产品名称查询先查产品编号集合再匹配进件；数据权限：客户经理仅本人经办。

### 受理（弹窗【ZJJK00244001PDCP】，个人与对公共用）
- 前置：须选中记录且状态=待受理。
- 弹窗输入：受理结果 acptRslt（TicpAcptRsltDict：0拒绝/1通过，必选）、意见 opin（必填）。
- 【确认】先确认「确定受理该笔进件」，再按进件类型分流：授权准入 / 预授信 / 授信 / 贷款 / 提额 / 提款（授信项下 vs 合同项下）。
- 受理结果处理（核心规则）：
  - 须携带进件申请编号+进件编号；记录不存在、结果非通过/拒绝均中止。
  - 通过→受理通过；拒绝→受理拒绝；意见留存。
  - 回传：预授信通过时附额度与期限；提额通过时附核准金额；贷款拒绝回传贷款申请。
  - 通过后触发后续：授信→生成综合授信合同签约任务；提款→生成提款协议签约任务；贷款→按主担保方式分流：信用→客户注册+对私评用一体；抵押/质押→客户注册+押品登记+商业住房详细信息登记+对私评用一体。
  - 贷款受理须取到营销产品、信贷产品详情、主担保方式，任一缺失中止。

### 退回
- 仅待受理行显示【退回】；确认「确认要退回当前记录吗？」；待分配（系统默认经办）进件不可重复退回；退回=经办人置系统默认、经办机构置空（含全部进件接收信息），并新增一条分配记录（分配状态=待分配、分配意见=退回）。
- 对公退回【退回】文档仅一句：「将该笔数据退回进件分配岗」。

### 查看（六类详情场景，均只读四页签）
- 授权准入 FS00100602PDCP（对公 FS00100601PDCP）：任务页 + 查看客户基本信息【ZJJK00204528PDCP 个人 / ZJJK00204599PDCP 对公】+ 查看产品信息【ZJJK00204529PDCP / ZJJK00204600PDCP】+ 查看风控结果【ZJJK00244003PDCP / ZJJK00244002PDCP】+ 查看相关文档【ZJJK00204584PDCP / ZJJK00204602PDCP】。
- 预授信/授信/贷款/提款/提额详情（FS00080659~663 个人，FS00080664~668 对公）：增加「查看进件详情」= 详情主页【ZJJK00207091PDCP 个人 / ZJJK00204601PDCP 对公】+ 无页签动态渲染数据查看组件-PC【ZJJK00204644PDCP】。
- 产品信息加载规则：按营销产品编号查询；编号为空提示「营销产品编号为空」；展示营销产品名称/编号、可售产品名称/编号、最高可贷金额。
- 风控结果加载规则（对公 ZJJK00244002PDCP）：按进件申请编号查风控评级（同笔仅一条，无记录展示为空不报错）；风险提示列表=命中规则逐条展示，不分页；受理意见取对公进件基本信息。
- 数标（数据指标）展示规则【ZJJK00204644PDCP】：按业务编号查数标，未配模板提示「数标模板为空，请联系管理员！」；分组按模板顺序号排序，组内按指标顺序号；表单/列表两种形态；金额两位小数、比率百分比两位小数（0.01%–100%）、日期年月日；字典类按字典译文；查看态全部只读。
- 进件详情数据来源规则（对公 ZJJK00204601PDCP）：按申请类型分别查预授信/授信/贷款/提额/提款（提款查申请信息）业务数标；单号为空返回空详情；无模板报错终止。
