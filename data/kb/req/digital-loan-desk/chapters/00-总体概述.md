## SUT 实测 behavior 对照（2026-09-06 湿测运行记录回填）

> SUT 实测 2026-09-06（digital-loan-desk 全模块 84 叶，wet-test 判定统计：match 31 / drift 2 / blocked 35 / not-found 16 / pending 0）。以下为跨页面通用行为，供自动化与后续模块对照。

- **列表主页进入即自动查（behavior，8 个列表主页一致）**：数据指标模板/指标库、营销产品、业务授权配置、对私/对公进件受理、对私/对公进件分配——全部**进入页面列表自动加载**，无需点查询。**与其他模块对照**：rating（评级）模块主页默认不自动加载、需手动查询——同系统内逐模块相反，不得当普适规则。
- **console 拦截族新成员（behavior，微前端框架前置钩子）**：`调用initBefore结果为false`（5 次：营销产品主页直达、模板指标【新增】弹窗前、进件列表页等）与 `调用editBefore结果为false`（4 次：业务授权配置非本人经办记录点【修改】3 次、对公进件分配页 1 次）。语义=数据权限/操作前置拦截（如仅本人经办可修改）。**注意：拦截报错不必然阻断 UI**——叶20 指标【新增】点下时 2×initBefore ERROR 但弹窗仍打开（「拦截报错+功能可达」按 match 并存 console 证据处理）；editBefore 则真实拦截（页面无跳转、不可进编辑态）。
- **not-found 16 叶的菜单树证据**：预授信名单管理（对公/个人）全部 16 叶 not-found 的最硬证据来自 `POST /tansun-tcp-sys/menu`（Bearer token 取自 localStorage）返回的**全量授权菜单树全文检索无「预授信」字样**，与顶部导航逐组展开实测一致；补测=需具备「预授信名单管理」菜单权限的账号。此 API 核对建议列为湿测标准动作（先于 UI 逐组展开）。
- **SUT 多出菜单组（归属待确认）**：「客户进件管理（对公/对私客户进件管理）」出现在本账号菜单树 JSON 中（数字信贷之外），未在本模块章节收录，也不在数字信贷 flyout 中展示——归属待 Lead 裁定。
