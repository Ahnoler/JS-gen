# 银社团管理

> 章节路径：银社团管理（H1）→ 总体描述 / 牵头行银社团贷款 / 社团份额维护 / 参与行银社团贷款。

## 要点摘要

- **功能说明**：牵头行和参与行对银团贷款用信业务全流程管理：查询社团贷款业务 → 选择客户/产品发起银社团用信申请 → 产品准入校验、客户风险阻断、授信额度检查 → 多角色审批（支持协办客户经理信贷二次调查）→ 审批通过可查看用信批复；另提供流程轨迹、修改、作废、社团份额维护。
- **状态说明**：
  - 流程状态：待发起（可修改/删除）→ 审批中（不可修改）→ 否决 / 终止；打回；已撤销。
  - 业务状态：未生效 →（审批通过）→ 生效。
  - 社团业务状态 msogBsnStcd：1待分配 2生效 3已撤销 4合同待签订 5合同已签订。

## 关键规则 / 字段 / 校验

- **牵头行查询列表（ZJJK00107729）**：展示牵头行经办申请（社团业务编号、社团总金额、参团比例、参团金额等）；按操作日期倒序；支持新增（抽屉向导）/修改/查看/流程轨迹（删除按钮不展示）。
- **发起向导（ZJJK00107778）【下一步(选择客户)】校验链**：
  - 必填项校验；同一法人机构下该客户无在途用信申请（按揭、票据、表外产品不校验）；
  - 授信额度校验：单独用信模式要求客户已完成授信；二合一模式若已有授信提示可改用单独用信方式；
  - 借新还旧/续贷：合同有且仅有一笔；收回再贷：合同非空；
  - 逐条合同校验：是否重组过、变更中、关联合同渠道（互联网贷款系统渠道合同只能发起重组/贷款详细信息变更/涉农标签调整/利率变更）；
  - 产品参数「允许借新还旧/续贷标志/次数」校验；
  - 续贷：企业规模须为中小微企业；
  - 在途放款校验（主合同校验所有子合同，子合同仅校验自身）；
  - 合同借据校验：存在核销/置换借据 → 提示确认后继续；无未结清借据 → 提示并中断。
- **基本信息（ZJJK00107776）**：产品编号须为四级或五级产品（否则提示并置空）；贷款业务类型=借新还旧/续贷/收回再贷时展示合同列表、隐藏产品编号；收回再贷/贷款重组时发起模式置「单独发起」不可编辑；银团角色字段默认"1"不展示。
- **【下一步(风险阻断)】**：总校验结果不通过提示「校验结果未通过！」；通过后启动流程（状态=待发起），按发起模式跳转对应页面。
- **流程 wf_usecredit_003（社团贷款用信申请）**：场景 FS00004519（单独发起）、FS00006404（二合一）；节点结构与对公用信流程类似（发起 → 二次调查 → 机构审查/审批/复核 → 领导审批等）。
- **社团份额维护（ZJJK00109731）**：
  - 数据来源：牵头行用信申请审批通过后自动生成一条「待分配」社团业务。
  - 客户经理仅见本人经办；其他角色见本机构及下级机构全部。
  - 【分配】：须为经办人；社团业务状态须为待分配或生效；打开新增社团份额维护页（任务页 ZJJK00109770：查看社团份额基本信息 ZJJK00109768 + 维护参团份额信息列表）。
  - 【撤销社团】：待分配或生效状态可撤销；生效状态须先校验所有用信审批已作废。
  - 【生成待签订合同】：仅生效状态；须所有参与行用信审批均已通过；复制担保信息、生成合同信息、业务状态 → 合同待签订。
- **参与行查询列表（ZJJK00109750）**：展示当前操作人经办的银社团**子**用信申请；修改限待发起/打回；【作废】限流程状态=通过（二次确认）；支持新增（同 ZJJK00107778 向导）/查看/流程轨迹。
