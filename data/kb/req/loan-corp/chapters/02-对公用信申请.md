# 对公用信申请

> 章节路径：对公用信申请（H1）→ 新增对公用信申请（H2）。本章为分册核心章，覆盖对公用信申请的新增/修改/查看/撤销/删除/流程轨迹及两条场景（FS00005745 单独发起、FS00006402 二合一）。

## 要点摘要

- **功能说明**：面向客户经理的新增对公用信申请端到端发起能力：客户引入 → 用信方案品种维护 → 担保/押品采集 → 影像上传 → 风险规则校验 → 审批意见录入。支持对公贷款、贸易融资、保函、保理、按揭、固定资产贷款等多产品类型；与智能控制、影像、额度、统一授信等外部系统协同。
- **业务流程**：对公用信申请主页发起 → 向导页第一步【选择客户】（客户放大镜选对公客户，录业务发生类型、用信发起模式；借新还旧/续贷引入关联合同、银社团合同）→ 第二步【风险阻断】（路由初始化校验、关联合同校验、关联方查询）→ 启动申报工作流 → 四步骤任务页【申报信息→影像信息→风险拦截→意见】→ 审查岗/审批岗调整用信要素并推进流程，形成发起与审批闭环。
- 修改/查看复用新增场景（同 FS00005745 / FS00006402，差异化规则：无）；撤销限待发起/打回；删除限已撤销；流程轨迹为只读弹窗。

## 关键规则 / 字段 / 校验

- **对公用信申请主页（ZJJK00108359）**：
  - 初始化：查询经办人为当前登录用户的申请；查询条件默认显示客户编号/名称/证件号码，其余点【更多】展开。
  - 流程状态字典 AprvSt：1待提交 2审批中 3生效 4否决 8流程终止 5通过 6否决；发起模式 crlineUseIttModeCd：1单独发起 2二合一（授信+用信） 3合并流程 4三合一（评级+授信+用信）。
  - 修改/撤销限「待发起或打回」；删除限「已撤销」；删除、撤销均二次确认。

  > **SUT 实测 2026-09-06**（wet-test 叶1，match）：列表**进入即自动加载**（37条/4页，behavior）。引擎对照：与授信/评级主页「需手动查询」**相反**——用信域 7 个列表主页（对公申请/对公批复/牵头行/份额维护/参与行/委托人/委托用信申请）全部「进入即查」（份额维护/参与行 0 条也自动查询出「共0条」），可定为用信域单据族普适规则；弹窗类同模块内相反（客户放大镜不自动加载 vs 委托人引用列表自动加载，见章5 叶48）。状态实测值：通过/待发起。
- **向导页【下一步(基本信息)】校验**：必填项校验（提示：请输入XXX！）；在途授信校验（调评级额度初始化接口，存在在途授信提示：该客户存在在途授信，请确认！）。
- **【下一步(风险阻断)】**：风险控制未通过提示"风险控制未通过!"；通过后创建用信申报流程并跳转申报大页面。
