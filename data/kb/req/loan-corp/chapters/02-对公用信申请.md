# 对公用信申请

> 章节路径：对公用信申请（H1）→ 新增对公用信申请（H2）。本章为分册核心章，覆盖对公用信申请的新增/修改/查看/撤销/删除/流程轨迹及两条场景（FS00005745 单独发起、FS00006402 二合一）。

## 要点摘要

- **功能说明**：面向客户经理的新增对公用信申请端到端发起能力：客户引入 → 用信方案品种维护 → 担保/押品采集 → 影像上传 → 风险规则校验 → 审批意见录入。支持对公贷款、贸易融资、保函、保理、按揭、固定资产贷款等多产品类型；与智能控制、影像、额度、统一授信等外部系统协同。
- **业务流程**：对公用信申请主页发起 → 向导页第一步【选择客户】（客户放大镜选对公客户，录业务发生类型、用信发起模式；借新还旧/续贷引入关联合同、银社团合同）→ 第二步【风险阻断】（路由初始化校验、关联合同校验、关联方查询）→ 启动申报工作流 → 四步骤任务页【申报信息→影像信息→风险拦截→意见】→ 审查岗/审批岗调整用信要素并推进流程，形成发起与审批闭环。
- 修改/查看复用新增场景（同 FS00005745 / FS00006402，差异化规则：无）；撤销限待发起/打回；删除限已撤销；流程轨迹为只读弹窗。

## 关键规则 / 字段 / 校验

- **对公用信申请主页（ZJJK00108359）**：
  - 初始化：查询经办人为当前登录用户的申请；查询条件默认显示客户编号/名称/证件号码，其余点【更多】展开。
  - 流程状态字典 AprvSt：1待提交 2审批中 3生效 4否决 8流程终止 5通过 6否决；发起模式 crlineUseIttModeCd：1单独发起 2二合一（授信+用信） 3合并流程 4三合一（评级+授信+用信）。
  - 修改/撤销限「待发起或打回」；删除限「已撤销」；删除、撤销均二次确认。
- **向导页【下一步(基本信息)】校验**：必填项校验（提示：请输入XXX！）；在途授信校验（调评级额度初始化接口，存在在途授信提示：该客户存在在途授信，请确认！）。
- **【下一步(风险阻断)】**：风险控制未通过提示"风险控制未通过!"；通过后创建用信申报流程并跳转申报大页面。
- **选择客户（ZJJK00108356）联动**：
  - 业务发生类型=借新还旧/续贷 → 展示合同列表（含【添加合同】【添加银社团合同】【删除】）；
  - 收回再贷/重组 → 用信发起模式自动置「单独发起」且不可编辑。
- **选择合同（ZJJK00113303）页面初始化**：借新还旧/续贷 → 查客户名下「已放款/已逾期」且「一般合同」；收回再贷 → 当前产品三级类目下「已放款、已终止、已结清≤6个月（可配置）、过滤参与行子合同」。
- **选择合同【选取】校验**：借新还旧/续贷必须且只能选一笔；重复添加拦截；合同「变更中」拦截；发生过贷款重组拦截；产品参数「允许借新还旧/续贷标志」「允许借新还旧/续贷次数」上限校验；（银社团合同另校验在途放款：放款审批中/待出账/出账中 → 拦截）。
- **流程 wf_usecredit_001（对公用信流程）**：多级节点（客户经理发起 → 信贷二次调查 → 五级/四级机构审查审批复核 → 综合岗分配 → 三级机构风险评价员审查 → 部门负责人/分管领导/主任审批 → 风险总监审查 → 信审会安排/委员审批/汇总/主任审核 → 总行有权审批人），各节点支持退回第一步/指定步骤/补充材料等操作。
  - **审批通过规则**：流程状态更新为审批通过；按产品参数「用信通过是否自动创建合同」决定是否自动创建合同；生成批复状态「已生效」的对公用信批复（一份用信批复下按产品维度关联多笔子批复）。
  - **审批否决规则**：流程状态更新为审批否决；生成「已否决」的用信批复（含产品维度子批复）。
  - 二合一场景（FS00006402）通过/否决时额外生成对公**授信**批复（同样按通过=已生效、否决=已否决）。
- **任务页（ZJJK00108367）步骤推进**：
  - 申报信息步骤导航：申报基本信息（客户概况、用信方案品种列表、征信信息、用信登记信息）+ 用信方案品种（贷款基本信息、利率、费用、产品、授信总额度、额度明细、合作方、担保、监管报送、银团信息、审批条件落实）+ 调查报告。
  - 【下一步(申报信息)】校验：所有产品大页面必输项；用信方案品种列表非空；担保信息须含与主担保方式一致的担保（如主担保=质押需有最高额质押合同/质押押品/保证金账户）；抵质押物必填项；最高额担保/担保合同组件必输项；调查报告非空；产品大类=保函且产品配置有「费率种类」时费用信息必录；表外产品（银行承兑汇票、保函等）保证金≠0、主担保含质押且「用信通过是否自动生成合同」=是时：保证金账户信息必录且保证金金额之和=产品保证金金额。
  - 导航菜单动态加载：新增贷款/重组/收回再贷 → 新增品种确定后在菜单动态加产品节点；借新还旧/续贷 → 按品种列表自动加载。
- **提交流程信息（ZJJK00109226）**：
  - 意见结论 OPIN_CNCLSN_CD：01同意 02不同意 03再议；是否上报/上报节点（1部门分管领导 2主任/行长 3信审会）/是否联合调查按角色展示。
  - 流程提交校验：发起岗校验各产品大页 LPR 基准利率与系统管理参数一致（不一致提示：当前LPR利率已发生变化，请重新确认！）；非发起岗校验审批要素页签已保存 + 必填项；通过后弹流程选人框，流程状态变「审批中」。
- **提交预审（ZJJK00114338）**：预审人员列表非空才可提交预审；新增预审人弹【选择预审人】（当前法人机构下用户），重复添加拦截（提示：用户编号XXX已添加）。
- **审批任务页（ZJJK00171666PDCP）**：页签：基本信息/影像信息/风险拦截；任务处于当前节点且审批状态=审批中时显示【审批】按钮；点击审批弹窗含风险阻断及提交流程组件。
- **流程跟踪信息（ZJJK00124779）**：展示节点名称、处理日期、处理人、处理机构、处理状态（有处理日期=已处理，否则待处理）、审批耗时（不足1分钟按1分钟计，X天X小时X分钟）、操作、审批意见。
