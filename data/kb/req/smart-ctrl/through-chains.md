# smart-ctrl 智能控制配置 — 候选可贯通主链清单

> 时效声明：本文为需求文档口径提炼，叶级真值以同目录 wet-test.md 湿测判定为准；链级修订由 Lead 在模块收口时统一处理。（2026-09-06 协议 v4）

> 源：`docs/天阳信贷系统需求文档/A_v5.2需求文档0824/M01天阳信贷管理系统-智能控制配置需求分册.docx`
> 口径：主链 = 有明确闭环目标 + 有序步骤 + 前置条件 + 章节出处的可回放操作流。文档无显式业务流程图（各章"业务流程"均为"无"），以下主链由操作步骤/按钮规则推导。

## 主链 1：新增控制规则（规则库建档）
- **闭环目标**：在控制规则库中创建一条智能控制规则并保存成功，列表刷新可见。
- **前置条件**：省联社管理员/法人行管理员登录；菜单【智能控制】→【智能控制管理】→【控制规则库】。
- **步骤**：
  1. 列表主页【ZJJK00096096】点击【新增】→ 抽屉打开维护控制信息主页【ZJJK00096101】（任务页 ZJJK00096102）。
  2. 填规则类别、归属部门、控制名称、控制说明、提示信息（均必填）；可点【查询相似控制】查看相似规则。
  3. 选适用范围（默认通用规则）；选"产品特有"时必选适用产品。
  4. 设是否允许跨阶段解除（默认否）；可填相关规章制度。
  5. 点【保存】→ 必填校验通过后保存并关抽屉，列表刷新。
- **出处**：chapters/03-控制规则库.md（控制规则库列表主页 / 新增 / 维护控制信息主页）。
- **关键校验**：必填为空提示"请选择或请输入"；产品特有未选产品提示"请选择适用产品"。

## 主链 2：修改 / 删除 / 查看控制规则
- **闭环目标**：对既有规则完成一次修改（或删除 / 只读查看）并回到刷新后的列表。
- **前置条件**：控制规则库列表已有记录；删除需规则未被引用口径待确认。
- **步骤**：列表选中记录 → 【修改】（带数据可编辑打开，同新增场景 FS00020620）/【删除】（确认框"是否确认删除该规则"）/【查看】（只读打开，可看关联方案列表 ZJJK00244006PDCP）→ 操作成功提示 + 刷新。
- **出处**：chapters/03-控制规则库.md（修改/删除/查看）。
- **关键校验**：未选记录提示"请选择有效数据"。

## 主链 3：控制配置（开发人员配置规则）→ 发布
- **闭环目标**：把"待开发"规则配置控制信息（处理方式/数据源/入参/映射）并发布为"已发布"版本。
- **前置条件**：规则存在且状态非"待开发/已拒绝"方可控制配置；发布前须完成配置（状态非"待开发"、处理方式非空）。
- **步骤**：
  1. 控制规则配置列表主页【ZJJK00096098】选中规则 → 【控制配置】→ 配置控制信息主页【ZJJK00096103】（场景 FS00003504）。
  2. 选控制处理方式：规则引擎（选规则调用编码+规则映射 ZJJK00096113）/ 表达式（表达式编辑器 ZJJK00095815）/ 数据源返回（数据源弹窗 ZJJK00188074PDCP）。
  3. 控制入参【新增】→ 选择数据项弹窗【ZJJK00096114】选字段 → 确认；可删除。
  4. 【保存】→ 成功关页。
  5. 列表选中 → 【发布】→ 版本号生成（首次 1，递增）、状态置"已发布"、刷新。
- **出处**：chapters/04-控制规则配置.md（控制配置 / 发布）。
- **关键校验**：已拒绝状态禁止任何操作；发布时"控制编号[xxx]的控制处理方式不能为空"；未选规则调用编码点【查询规则入参】提示"请选择规则调用编码！"。

## 主链 4：发布历史查看与版本回退
- **闭环目标**：查看某规则发布历史并把规则回退到指定历史版本。
- **前置条件**：规则已至少发布一次。
- **步骤**：列表选中 → 【发布历史】→ 发布历史列表【ZJJK00096116】→ 选版本【详情】（只读弹窗 ZJJK00096117，可看规则映射 ZJJK00132274）→【回退】→ 刷新。
- **出处**：chapters/04-控制规则配置.md（发布历史）。

## 主链 5：控制规则导出 / 导入（.ctrl）
- **闭环目标**：把规则集导出为 .ctrl 文件并在另一环境导入成功。
- **前置条件**：导出需规则状态默认筛选"已发布"（选择器 ZJJK00096200 默认状态 3）；导入需 .ctrl 格式文件。
- **步骤**：列表 → 【导出控制规则】→ 控制选择器选规则 → 确认 → 下载"控制导出.ctrl"；另一环境 →【导入控制规则】→ 选文件 → 解析 JSON 送后台 → "导入成功" → 【确认】保存规则与场景关联。
- **出处**：chapters/04-控制规则配置.md（导出控制规则 / 导入控制规则）。

## 主链 6：新增控制规则方案并引入控制
- **闭环目标**：创建智能控制方案（基本信息+规则信息）并成功引入控制规则、配置行参数。
- **前置条件**：存在"已发布"状态的规则可供引入（控制选择器默认状态"已发布"）。
- **步骤**：
  1. 方案列表【ZJJK00095811】→【新增】→ 任务页【ZJJK00095814】基本信息标签【ZJJK00095812】。
  2. 填方案名称、方案状态（必填）→【保存】→ 自动生成方案编号 → 出现规则信息标签页。
  3. 规则信息页【ZJJK00095813】→【引入控制】→ 控制选择器【ZJJK00096200】选规则确认 → 关联保存。
  4. 行级配置执行条件（表达式 ZJJK00095815）、风控措施、风险解除状态、生效状态 → 行自动保存。
  5. 【返回】关页。
- **出处**：chapters/05-控制规则方案.md（新增）。
- **关键校验**：行保存须依次选风控措施/风险解除状态/生效状态；变更风控措施自动清空风险解除状态。

## 主链 7：控制规则方案维护 / 删除 / 导入导出
- **闭环目标**：对既有方案完成修改、查看、删除，或 .ctrlscm 方案文件 / SQL 脚本 / Excel 的导入导出。
- **前置条件**：删除仅限方案状态非"生效"；导入需 .ctrlscm 文件。
- **步骤**：列表选中 → 【修改】（同新增场景 FS00003401）/【查看】（只读）/【删除】（确认；scmSt='1' 提示"生效状态的控制方案不允许删除！"）/【导出控制方案】（选择器 ZJJK00154495PDCP）/【导入控制方案】（ZJJK00244007PDCP）/【导出sql脚本】/【导出excel】。
- **出处**：chapters/05-控制规则方案.md（修改/查看/删除/导出/导入）。

## 主链 8：规则一键失效 / 生效（单条与批量）
- **闭环目标**：按需将规则-方案关联的生效状态置为失效或生效（单条或按条件批量）。
- **前置条件**：法人行级客户经理（本人经办业务）；存在规则-方案关联记录。
- **步骤**：【智能控制】→【规则一键失效及恢复】→ 规则关联方案主页【ZJJK00168657PDCP】→ 查询筛选 → 【失效规则】/【生效规则】（单条）或填条件后【批量失效规则】/【批量生效规则】→ 状态更新 + 刷新。
- **出处**：chapters/06-规则一键失效及恢复.md。
- **关键校验**：批量时规则编号/方案编号不能同时为空。

## 主链 9：智能控制测试（方案级 / 规则级）
- **闭环目标**：在正式环境外对方案/规则执行一次测试并查看校验结果（可导出）。
- **前置条件**：存在可选方案或规则。
- **步骤**：【智能控制】→【智能控制测试】→ 方案/规则标签页选目标 → 填参数（JSON 报文默认 / 格式化参数+获取参数列表+获取json参数）→【执行测试】→ 结果页看总数/通过（绿）/不通过（红），可【详情】看执行细节、【导出结果】导 Excel。
- **出处**：chapters/07-智能控制测试.md。
- **关键校验**：未选目标提示"请选择测试方案或规则"；获取参数列表未选提示"请先选择测试方案或规则！"。

## 主链 10：风险探测解除（查询页一键解除）
- **闭环目标**：对"有条件解除"状态的已触发规则完成一键/单条解除。
- **前置条件**：存在已触发的风险探测记录；解除操作人员（本人及下级机构业务）。
- **步骤**：【智能控制】→【智能控制解除】→ 查询主页【ZJJK00168653PDCP】选中 → 【解除】→ 解除页【ZJJK00168654PDCP】（默认查"有条件解除"规则，是否解除默认否）→ 规则选"是"或【一键解除】→ 确认 →【保存】生效。
- **出处**：chapters/08-智能控制解除.md（智能控制解除）。
- **关键校验**：保存未选中提示"无修改规则，数据保存失败"。

## 主链 11：风险探测解除申请（客户经理发起 → 管理员审批）
- **闭环目标**：走完 FS00076602PDCP 审批流程（客户经理申请 → 管理员审批通过），规则解除状态更新。
- **前置条件**：存在触发风险探测的业务数据；客户经理角色；所选规则归属部门一致、均非"不可解除"（或允许跨阶段解除）。
- **步骤**：
  1. 解除申请主页【ZJJK00196038PDCP】→【新增】→ 向导页【ZJJK00196039PDCP】选业务信息【确定】。
  2. 客户经理任务页【ZJJK00196043PDCP】：解除信息步【ZJJK00196040PDCP】选解除阶段（按应用场景 1/2/3 动态）、填解除原因、【添加】规则弹窗【ZJJK00196058PDCP】勾选规则 → 下一步校验 → 影像资料步【ZJJK00100615】→ 意见步 → 提交流程【ZJJK00196042PDCP】。
  3. 管理员审批（选人模式：系统管理员/总行系统管理员）：任务页【ZJJK00196044PDCP】查看 → 意见结论页【ZJJK00204420PDCP】选结论（通过时可改解除阶段）→ 提交。
  4. 主页可【查看】【流程轨迹】（ZJJK00124779）核验。
- **出处**：chapters/08-智能控制解除.md（智能控制解除申请）。
- **关键校验**：下一步时归属部门须一致；含"不可解除"规则提示"不可解除的规则不允许发起解除申请！规则编号：[列表]"；跨阶段需存在允许跨阶段解除规则；修改仅限"待发起/打回"，删除仅限"待审核/打回"。

## 旁路 / Out
- **智能控制日志查询**（ZJJK00171540/1550）：只读查询，默认展示失败日志 + 详情弹窗，无写操作闭环 → 旁路。出处 chapters/09。
- **智能控制记录查询**（ZJJK00204651）：只读查询 + Excel 导出 → 旁路。出处 chapters/09。
- **控制任务管理**（ZJJK00096119）：任务处理状态变更（开发过程管理），可作为主链 3 的伴随子流程，不独立成主链。出处 chapters/04。
- **导出excel（规则库/方案）**：数据导出旁路，附属于主链 2/7。

## 建议优先湿测

2. 主链 11（解除申请审批流）——流程节点、阶段动态、不可解除校验均涉及跨页校验。
3. 主链 6（方案+引入控制）——行级自动保存与风控措施级联清空。
