# 章节路径
M01天阳信贷管理系统-智能控制配置需求分册 > 智能控制配置 > 智能控制测试

## 要点摘要
- 在正式环境外验证控制方案/规则的功能是否符合预期，帮助【开发人员】上线前确认控制逻辑正确性。
- 主页两个标签页：智能控制方案测试 / 智能控制规则测试；选目标后进参数填写页，支持 JSON 报文测试（默认）与格式化参数测试两种方式，执行测试返回结果。
- 菜单：【智能控制】→【智能控制管理】→【智能控制测试】。

## 界面与 ZJJK
- **智能控制方案测试页面【ZJJK00168579PDCP】**：方案选择列表（方案编号/方案名称查询；输出方案编号/名称/状态）。
- **智能控制规则测试页面**：规则选择列表【ZJJK00168322PDCP】（查询=控制编号ctrlNumb/控制名称ctrlNm/控制状态ctrlSt；输出含控制处理方式、提出人、创建时间）。
- **填写测试参数页【ZJJK00168347PDCP】**：测试类型testType单选（1 JSON报文测试 / 2 格式化参数测试）；JSON报文jsonInput文本域；格式化参数模式提供【获取参数列表】（拉取所选方案/规则全部控制入参）、【获取json参数】（参数列表转 JSON）；参数列表含参数英文名fld/参数中文名fldNm/参数值fldVal；支持插入自定义参数行与删除（仅自定义行）；【执行测试】【重置测试参数】。
- **测试结果页【ZJJK00168353PDCP】**：输出=规则编号/规则名称/控制处理方式/规则校验结果rslt(ValidateResultTpCd)/规则控制类型ctrlGrd(ctrlLvlCd: 10刚控/20柔控/30提示/50豁免)/规则提示信息/【导出结果】/行操作【详情】；校验结果详情弹窗展示：处理方式、校验结果、控制类型、执行条件execCnd、数据源url及请求/响应、规则引擎调用/项目编码及请求/响应、表达式内容executedExpression、异常信息errorMsg（仅异常时展示）。

## 关键规则/字段/校验
- 页面初始化：默认标签页=智能控制方案测试；测试类型默认=JSON报文测试；校验结果列表默认为空。
- 【标签页切换】：切换时清空关联信息（当前控制编号/方案编号）、测试参数和测试结果。
- 【获取参数列表】：未选方案/规则提示"请先选择测试方案或规则！"；选中后拉取控制入参列表。
- 【获取json参数】：提示"请切换至json报文页面查看"，并把参数列表转换为 JSON 赋值到报文文本框。
- 【执行测试】：未选方案/规则提示"请选择测试方案或规则"；执行风险拦截校验并把结果展示在测试结果页；结果展示执行规则总数、通过数（绿色）、不通过数（红色）。
- 【重置测试参数】：清空 JSON 报文 / 格式化参数列表中参数值列。
- 【导出结果】：将测试结果列表导出 Excel。
