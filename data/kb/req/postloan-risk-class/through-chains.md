## 主链 1：新增人工分类（单笔）认定闭环

- **闭环目标**：客户经理对一笔未结清合同发起人工五级分类 → 填报 → 提交 → 网点负责人（及上级风管节点）审批通过 → 生成人工分类认定结果并更新合同/借据五级分类 → 分类查询可查、可出认定表。
- **前置条件**：
  - 客户经理账号，本人经办合同；合同状态为已放款/已逾期/已转让（对公另过滤社团主合同）。
  - 该合同无在途未审批通过的认定任务。
  - 配置前置（旁路，可无配置走默认）：脱期法配置、默认分类配置、观察期参数与白名单、法人机构分类配置（影响可上调范围）、认定理由配置（影响理由可选集）。
- **有序步骤**：
  1. 【风险分类】→【分类认定】，人工分类主页 ZJJK00102100 查询任务列表。
  2. 点【新增】→ 客户合同选择弹窗 ZJJK00102102：选客户类别（默认对私）→（可经客户放大镜 ZJJK00109101 选客户）→ 查询选中一笔合同 →【确定】（校验在途任务、初分一致性；资产类型按推导表；系统初分结果按脱期法/观察期/关系人/默认配置链生成）。
  3. 进入任务页（按资产类型，如担保 ZJJK00114946）：基本信息步骤 → 查看任务信息 ZJJK00106348 填【人工分类认定结果】（必填；受法人机构上调限制、已转让≤次级、审批额度范围判定）→ 选择认定理由（ZJJK00106266/6277，按上调/形态/下调带出）→（企事业贷款）填报审核意见 ZJJK00109791 风险防范措施必填 →【暂存】。
  4. 【下一步】→ 影像资料步骤（ZJJK00116420/公共影像组件查看）→【下一步】。
  5. 签署意见步骤 → 提交流程 ZJJK00102920 提交审批。
  6. 网点负责人审批任务页（ZJJK00171651PDCP 等）【审批】→ 同意/驳回；按 wf_classify_001 可流转至风管节点。
  7. 审批通过：更新合同及借据五级分类、分类日期=审批通过日；任务状态=通过。
  8. 【分类查询】ZJJK00102221 查记录 → 生成认定表/认定报告（仅企事业）/呈报表。
- **章节出处**：§分类认定>新增人工分类（总体说明、主页、新增向导、担保场景全链）；§总体描述（状态说明、审批流程）；§分类查询。
- **建议湿测入口**：人工分类主页新增 → 合同弹窗确定 → 任务页暂存 → 提交 → 网点负责人审批。

## 主链 2：新增批量认定闭环

- **闭环目标**：一次选多笔系统待认定任务创建批量认定 → 集中填报/保存 → 提交审批 → 通过后对所选合同集中生成分类结果。
- **前置条件**：批量列表可见本人待发起/打回任务；所选单笔任务满足（分类类型空、初分=上次结果、待发起且生效、未超时、无批量编号）；是否损失+有权审批人必选；首次分类合同会被自动移除。
- **有序步骤**：
  1. 【风险分类】→【批量认定】，列表 ZJJK00105335 查询。
  2. 【新增】→ 合同选择弹窗 ZJJK00105571：选是否损失/有权审批人 → 查询 → 勾选多笔 →【确定】（自动移除首次分类合同；人工结果=初分结果、理由按批量配置自动匹配；启动批量审批流）。
  3. 任务页 ZJJK00105347：填报任务信息（ZJJK00105341 只读）+ 填报批量认定合同（ZJJK00105345 添加/移除）→【保存】（人工结果更新为调度分类结果）。
  4. 签署意见 → 提交；wf_classify_001 审批；单笔任务分类类型=批量认定，写批量编号。
  5. 审批通过后批量生效；单笔暂存在批量审批中会被拦截（「不允许暂存」）。
- **章节出处**：§批量认定>新增批量认定（列表、合同弹窗、场景 FS00004717）。
- **建议湿测入口**：批量新增选 2 笔 → 保存 → 提交 → 审批。

## 主链 3：分类查询与材料输出

- **闭环目标**：检索已通过认定记录并输出认定表/报告/呈报表。
- **前置条件**：存在流程状态=通过的认定记录；认定报告仅企事业单位贷款。
- **有序步骤**：分类查询 ZJJK00102221 → 查询/重置 → 选中记录 →【生成认定表】/【生成认定报告】/【生成呈报表】（生成并上传影像平台后下载预览）/【查看】只读明细。
- **章节出处**：§分类查询。
