## 1.3 状态说明
### 放款申请状态（申请维度）
- 待发起 / 审批中 / 通过 / 否决 / 退回 / 已撤销（函证操作申请状态字典 LgntLcMnpltAplySt 另含：待提交/审批中/通过/否决/已撤销/退回/处理异常）。
- 提交流程规则（对公/零售通用）：审批通过 → 放款状态=待出账；否决 → 出账拒绝。

### 放款状态（放款/出账维度）
- 未推送 / 待确认 / 待出账 / 出账中 / 出账成功 / 出账撤销 / 出账异常 / 出账失败 / 出账拒绝 / 作废。
- 冲正结果字典 rvrsRslt：01冲正中 / 02冲正成功 / 03冲正失败 / 04取消冲正。

### 关键字典（跨章引用）
- 保函状态 LgntStcd、信用证状态 LcSt、垫款状态 AdcshSt(1未垫款/2已垫款/3已结清)、保证金状态 MrgnSt(1待扣划/2已扣划/3已冻结/4已解冻/5已退还/6已使用/7已冲正)、收费状态 FeeSt(1待收费/2扣收成功/3扣收失败/4已退费/5已冲正/6已撤销/7冲正异常)、借据状态 iouSt(1生效/0未生效/2结清/3逾期/4已核销/5已置换/6已冲正/7已转让/8正常)、交易执行状态 TxnExecSt(1待执行/2执行成功/4执行异常/5无需执行)、账务处理状态 AcgPcsgSt(1待处理/3已处理/4处理异常)。
