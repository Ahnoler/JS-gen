## 3.1 受托支付信息主页【ZJJK00096419】
- 查询/查看：按合同编号、借据编号、受托支付状态等查询受托支付记录，详情只读展示支付对象、金额、账户、支付方式等。
- 按钮规则：
  - 【受托支付】（发起）：仅当原记录状态=待支付 且 放款审批已通过 且 支付通道为大额/小额 时可发起；进入支付流程。
  - 【更新支付结果】：仅行外支付记录可手动更新支付结果。
- 受托支付状态机：待支付 / 支付中 / 已支付 / 失败 / 异常 / 已冲正 / 变更中 / 已失效 / 已变更。

## 3.2 受托支付变更【ZJJK00125075】
- 主页按钮：新增（申请向导）、修改（仅待发起/退回）、查看、取消申请（仅待发起）、流程轨迹。
- 申请向导：
  1. 基本信息 → 选择受托支付数据【ZJJK00125076】：选择支付状态=待支付且放款审批通过的受托支付记录。
  2. 风险拦截【ZJJK00067996】（同对公放款，差异化规则：无）。
  3. 变更场景 FS00012829 / 变更流程 entrstdPyMdf：维护变更后支付对象/金额/账户 → 提交流程【ZJJK00124885】（含审批任务页、修改、查看、取消申请、流程轨迹）。
- 变更编号规则：ZFBG + 8位日期(yyyyMMdd) + 6位序列。
- 末节点通过：原受托支付记录状态 → 已变更，新建一条【待支付】变更后记录。

## 关键校验
- 未选记录/状态不符中断；风险拦截不通过中断。
- 取消申请：仅待发起，二次确认后撤销审批流程并恢复原记录。
