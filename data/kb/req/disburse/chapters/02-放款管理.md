## 2.1 总体描述

## 2.2 对公放款管理
### 2.2.1 管理主页【ZJJK00106459】
- 按钮：新增 / 社团 / 修改 / 查看 / 删除 / 取消 / 出账撤销 / 出账确认 / 打印借据 / 放款通知书 / 打印提款申请书 / 流程跟踪。
- 通用按钮校验：未选记录提示"请选择有效数据"；修改仅限【待发起、退回】状态；取消仅限待发起，二次确认后撤销流程；打印/下载类按钮按对应状态拦截。
- 出账确认：分柜面 / 直连两种渠道；出账撤销针对出账成功的放款，二次确认后撤销并回退放款状态。
- 审批流（测试流程 dsbrAplyTstPcs）：两节点——客户经理发起 → 有权审批人审批。

> SUT 实测 2026-09-06（叶1，wording+structure）：菜单名/页签名 SUT 为「对公放款申请」≠ 文档「对公放款管理」；按钮措辞 SUT 为「新增放款/社团放款」（对应文档「新增/社团」）。按钮集实测 15 个：新增放款/社团放款/修改/查看/删除/取消/出账撤销/出账确认/打印借据/放款通知书/打印提款申请书/流程跟踪/模拟客户确认结果/联动核算出账/模拟柜面结果——后 3 个为文档未载的 SUT 多出按钮（测试环境特征，非产品口径）。文档原需求口径保留如上，以 SUT 实测为准。

### 2.2.2 新增对公放款申请 · 向导页
1. 选择合同【ZJJK00106460】：展示当前经办客户"已生效未放款/已放款"合同；营业日>合同到期日不展示；排除电票承兑/电票贴现；仅一般合同；变更标识为否。社团按钮则展示社团子合同。
2. 风险拦截【ZJJK00067996】：60秒轮询风险结果，1秒间隔；未通过提示"风险控制未通过！"中断。
3. 场景页（对公一般贷款 FS00008605 / 法人账户透支 FS00008612 / 银团贷款 FS00008622 / 委托贷款 FS00008618 / 社团贷款 FS00008623-08626 等）：维护放款基本信息、受托支付、还款计划、影像文件等。
   - 合同可用金额公式：循环额度 = 合同金额 − 贷款余额 − 在途金额；非循环 = 合同金额 − 已放款累计 − 在途金额。
   - 申请放款金额默认值规则：默认取合同可用金额与本次计划放款的较小值（文档按场景略有差异，待湿测）。
   - 维护文件列表 → 公共影像组件【ZJJK00100615】（被多章复用）。
4. 提交流程【ZJJK00106400 系】：流程启动（待办扩展+场景命中参数）→ 提交（申请状态=审批中，流程状态=审核中）→ 终止/否决（出账拒绝）→ 流程结束（末节点同意 → 放款状态=待出账，登记放款记录）。

> SUT 实测 2026-09-06（叶17，wording）：场景任务页最后一步 SUT 步骤名为「流程提交」≠ 文档「提交流程」（与 credit-corp/rating 模块同款措辞漂移，跨模块一致——SUT 侧统一用「流程提交」口径）。

## 湿测 behavior 对照（放还款域普适）
> SUT 实测 2026-09-06（叶1/11 等）：本模块（放还款管理域）9 个列表页**全部进入即自动查询**（对公放款 24 条、零售放款 8 条、受托支付变更 1 条等均无需手动触发）。与授信/评级域「主页列表默认不自动加载、需手动查询」相反——同系统内逐模块相反，自动化引擎不得把「进入页面即等待列表行」当作全系统普适规则，须按模块区分。
- console 拦截族新成员（引擎 cue：向导推进静默拦截）：`beforeQueryIou` / `tabformValid` / `rowClick`——向导步骤推进被 console 脚本静默拦截，Playwright 常规 click 不触发推进时优先排查该族拦截。

## 关键校验汇总
- 未选记录、状态不匹配类操作一律中断并提示。
- 风险拦截不通过 → 全部申请类操作中断。
- 金额校验：申请放款金额 ≤ 合同可用金额；超限中断。
