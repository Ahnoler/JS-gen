# customer-common · 可贯通主链清单（视图2）

- 源：A01天阳信贷管理系统-客户管理需求分册【公共功能】.docx（v5.2 0824）
- 口径：候选可贯通主链 = 有明确闭环目标 + 有序步骤 + 前置条件的操作链；「待湿测」表示文档口径与 SUT 可能存在差异，需湿测验证。

## 主链

### MC-01 新增黑名单并保存（闭环：客户进入黑名单+标签同步）
- 步骤：【客户管理】→【名单制管理】→【黑名单管理】→【新增】→ 任务页(基本信息)→ 引入客户（客户放大镜 ZJJK00109101）→ 填黑名单类型/拦截等级/认定类型/渠道来源/加入原因 →【保存】
- 前置：存在可选客户（正式/潜在）；客户经理权限
- 闭环校验点：保存成功生成业务编号 CHD+日期+6位序号；同步客户黑名单标签及集团/集群成员风险属性；主页列表可查询到
- 出处：chapters/02（2.2）；ZJJK00098110/00105226/00105222
- 变体：影像资料页签（未引入客户提示“请先引入客户！”）

### MC-02 变更黑名单（人工认定名单）
- 步骤：主页选中人工认定记录→【修改】→ 变更申请（ZJJK00105231）→ 变更基本信息（客户名称不可重选）→【保存】更新
- 前置：认定类型=人工认定；记录属于本机构及下级
- 出处：chapters/02（2.2.1.4）
- 待湿测：机构范围校验提示文案

### MC-03 删除黑名单
- 步骤：主页选中人工认定记录→【删除】→ 确认 → 标记删除 + 同步客户标签/集团集群属性 → 列表刷新
- 出处：chapters/02（2.2.1.6）

### MC-04 批量导入黑名单
- 步骤：主页【下载模板】(blackTemplate.xlsx)→【导入名单】→ 弹窗选 excel 文件→ 确认 → 文件/逐行校验（客户存在、名单类型、拦截等级、文件内不重复、名单内不重复）→ 逐条登记+标签同步 → 列表刷新
- 前置：模板文件；正式/潜在客户
- 出处：chapters/02（2.2.1.7/1.8）

### MC-05 新增灰名单申请（潜在风险名单）并同步成员状态
- 步骤：潜在风险客户名单主页(ZJJK00105237)→【新增】→ 任务页(ZJJK00105239)→ 引入客户→ 名单类型/拦截等级/加入原因→【保存】（同法人同类型查重）→ 同步总集团/集群成员灰名单状态
- 出处：chapters/02（2.3）；变体：导入 ZJJK00128514

### MC-06 新增不良合作机构
- 步骤：不良合作机构主页(ZJJK00105363)→【新增】→ 引入合作方（专用大镜 ZJJK00114498：机构/从业人员两页签）→ 名单类型+加入原因→【确定】（编号+类型查重）
- 出处：chapters/02（2.6）

### MC-07 新增关联关系过滤配置
- 步骤：过滤配置主页(ZJJK00105529)→【新增】→ 客户放大镜选客户→ 选排除关系类型→【保存】（客户+排除类型查重）
- 出处：chapters/03（3.4）；变体：批量导入 ZJJK00128513（relatedFilterTemplate.xlsx）

### MC-08 删除客户关联关系（留痕）
- 步骤：关联关系维护主页(ZJJK00105702)→ 条件查询（主/关联客户编号不可同时为空）→ 选中→【删除关系】→ 确认 → 标记删除+登记变更历史
- 出处：chapters/03（3.2）

### MC-09 创建客户圈并维护成员
- 步骤：客户圈主页(ZJJK00105545)→【新增】→ 向导页(ZJJK00107841)填名称/类型（≤100字符、同名校验）→ 维护基本信息(ZJJK00105546)→ 维护成员(ZJJK00110241)：新增（放大镜无同业入口，圈内查重）/删除/导入(ZJJK00105553)/导出
- 出处：chapters/05
- 待湿测：客户圈编号生成口径；修改/删除的机构权限判定

### MC-10 权限申请：客户主办/经办权限（全流程审批）
- 步骤：权限申请主页(ZJJK00067345)→【新增】→ 任务页(ZJJK00125200)→ 维护申请权限信息(ZJJK00067351)引入客户→【保存】（管户权/业务权/同机构唯一客户经理/在途申请校验；流水号 PMS…，状态待发起）→ 提交流程(ZJJK00090543)→ 网点负责人审批(ZJJK00113100)
- 出处：chapters/08（8.2，流程 wf_aply_permission）
- 待湿测：多角色审批链在 SUT 是否可走通

### MC-11 客户移交（发起→接收→三级审批）
- 步骤：客户移交申请主页(ZJJK00067359)→【新增】→ 任务页(ZJJK00090547)→ 维护移交客户基本信息(ZJJK00067376)：选移出/接收客户经理（不可相同）→ 一键添加或客户选择器(ZJJK00104178)加明细（在途/待移交校验）→【保存】→ 提交流程(ZJJK00090546)→ 客户经理接收(ZJJK00104181)→ 支行行长(ZJJK00104182)→ 业务管理部审核岗(ZJJK00090548)→ 部门综合员(ZJJK00115713)
- 前置：移出客户经理名下有管户客户；移交客户与业务时不得跨机构
- 出处：chapters/08（8.3，流程 wf_cust_handover）

### MC-12 业务移交（未结清合同移交）
- 步骤：业务移交申请主页(ZJJK00070007)→【新增】→ 向导页(ZJJK00091226)选移出/接收客户经理（可选变更账务机构，需入账资质）→ 任务页(ZJJK00090559)→ 维护业务移交基本信息(ZJJK00067407)：合同放大镜(ZJJK00101255)加未结清合同明细（在途业务校验）→【保存】（同法人行校验）→ 提交流程(ZJJK00090558)→ 客户经理接收(ZJJK00090560)→ 支行行长审批(ZJJK00104179)
- 出处：chapters/08（8.4，流程 wf_bus_handover）

### MC-13 集团移交
- 步骤：集团移交申请主页(ZJJK00114017)→【新增】→ 任务页(ZJJK00114314)→ 新增集团移交主页(ZJJK00114066)：一键添加当前登录人名下集团（或新增集团基本信息 ZJJK00114346 查询加入）→【保存】（必填/不能移交给自己/不能是当前登录人/仅集团移交须同法人行；流水号 CHD…）→ 提交流程(ZJJK00114361)→ 网点负责人审批(ZJJK00114359)→ 客户经理接收(ZJJK00114399)
- 出处：chapters/08（8.5，流程 wf_grp_handover）

### MC-14 新增征信查询申请并审批
- 步骤：征信查询主页(ZJJK00099371)→【新增】→ 任务页(ZJJK00099405)→ 新增征信查询(ZJJK00099361)：引入客户→ 授权日期（截止日=+29自然日）/查询事由/查询方式/策略（贷后管理才选关联合同）→【保存】（流水号 PMS…，状态待发起）→ 维护影像(ZJJK00100615)→ 下一步（须已保存）→ 提交征信查询(ZJJK00099403)→ 审批岗审批(ZJJK00099410)
- 旁路：授权书模板打印(ZJJK00099844)；查看(FS00003665)；修改限待发起类状态
- 出处：chapters/09（9.2，流程 wf_cust_100）

### MC-15 客户360视图只读查看（按客户类型分流）
- 步骤：从客户列表/台账进入 360 视图→ 任务页按客户类型（对公 ZJJK00114205 / 对私 ZJJK00114033 / 集群 ZJJK00114355 / 总集团 ZJJK00114413 / 集团 ZJJK00114505）→ 切换页签（客户概况/基本信息/业务信息/五级分类/征信分析 或 成员信息/存量业务/成员持股）只读浏览
- 前置：目标客户存在且有权查看
- 出处：chapters/06
- 待湿测：各页签后端数据聚合加载

### MC-16 客户台账查询→详情
- 步骤：综合查询→客户台账查询→ 对公(ZJJK00114418)/对私(ZJJK00114425)/同业(ZJJK00114426)→ 条件查询（未选管户经理默认本人名下）→ 选中→【查看】→ 按转正标识进正式/潜在详情（只读）
- 出处：chapters/07
- 待湿测：同业台账名称/管户经理筛选与排序未生效（文档自述缺陷）

### MC-17 中征网公告查看与分配
- 步骤：中征网公告管理列表(ZJJK00109712)→ 条件查询（普通用户限当前法人行）→【查看】→ 详情四页签（基本信息/合同/供应商/多维度）浏览；或【分配】→ 机构树(ZJJK00110039)→ 确认批量分配
- 出处：chapters/04

## 建议优先湿测主链
1. MC-01 新增黑名单（查重+编号+标签同步，校验点最密集）
2. MC-14 新增征信查询申请（条件显隐规则多：授权日期/关联合同/公积金授权码/联系号码）
3. MC-10 权限申请（在途业务/重复权限拦截）
4. MC-09 客户圈（编号口径与机构权限两处待湿测点）
