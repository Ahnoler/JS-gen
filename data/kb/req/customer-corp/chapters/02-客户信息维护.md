## 要点摘要
- **总体功能**：客户经理/业务经办在同业、对公、个人客户主页进入维护任务，补充基础信息、证照、关联关系、经营财务、联网核查等资料；辅助入口含客户放大镜、机构选择器、地址五级联动、影像查看、营业执照 OCR。
- **客户状态机（状态说明）**：
  - 新客户 → 暂存登记 → 草稿客户；草稿客户 → 正式提交 → 信贷正式客户
  - 信贷临时客户 → 客户转正 → 信贷正式客户；草稿客户 → 客户转正 → 信贷正式客户
  - 信贷潜在客户 = 三要素（证件类型、证件号码、客户名称）齐备但无业务往来
  - 合并注销 / 合并中 / 注销：不允许继续修改客户资料
  - 进件状态：对公进件 → 创建客户成功 → 客户已创建（关联客户编号）

## 对公客户管理（本分册核心）

### 对公客户主页【ZJJK00066153】（统一页面）
- 入口：【客户管理】→【客户信息维护】→【对公客户管理】
- 权限：客户经理（用户级/经办人）：查询、重置、新增、修改、查看、联网核查、法院信息、影像资料；数据权限=本人经办业务。
- 查询条件：客户编号 cstNo、客户分类 rtgCstClId（发展巩固/限制维持/压缩退出）、客户名称（模糊）、证件类型 crdtTp、证件号码、对公客户类型 cpctTp、客户状态 cstSt（1正式/2临时/3合并注销/4合并中/5注销/6草稿）、管户客户经理；【更多】展开隐藏条件。
- 规则：默认按当前客户经理查询有管户权/业务权的客户；列表按创建时间倒序。
- 修改按钮：合并注销/合并中/注销 提示不可修改；按操作人与管户客户经理是否一致控制可编辑范围。
- 查看：只读模式打开详情。
- 联网核查/法院信息按钮：合并注销/合并中/注销 拦截，提示"【合并注销、合并中、注销】不可发起联网核查！"。

### 新增（向导页）
- 新增对公客户主页【ZJJK00066158】：客户状态默认信贷潜在客户（cstSt 默认 2）；已有对公进件信息时 证件类型/客户状态/客户名称/证件号码 不可编辑；选担保公司 → 客户状态自动正式客户且锁定；切换对公客户类型清空证件类型。
- 【OCR识别】规则：未选证件类型提示"请选择证件类型"；仅营业执照可识别；图片限 jpeg/jpg/bmp/png；OCR 导入组件【ZJJK00164554PDCP】限 jpg/jpeg、≤1MB。
- 【保存】规则：
  - 必输校验"请输入XXX！"
  - 营业执照证件号码必须 18 位
  - 信贷系统内客户已存在 → 提示主办客户经理及所属机构并中断
  - 不存在 → 调 ECIF：返回客户编号则同步 ECIF 客户信息；否则 ECIF 创建对公潜在客户并同步
  - 页面客户状态为正式 → 待转正标识=是；否则客户状态登记为草稿客户
  - 登记当前操作人为主办客户经理
  - 路由：担保公司 →【对公客户类型为担保公司】场景 FS00005510；非担保 → 潜在客户 → FS00005518，正式 → FS00004007
  - 来源对公进件时保存成功后进件状态=客户已创建并关联客户编号

### 公共组件（场景内复用）
- 客户地址五级联动【ZJJK00098350】：默认福建省；省/市/区县/乡镇街道/行政村社区+详细地址 → 完整地址。
- 客户放大镜选择器【ZJJK00109101】：对公/对私客户选择，按当前用户及管户权过滤。
- 维护股东及关联人信息主页【ZJJK00104723】：股东信息列表【ZJJK00113713】（新增/修改/查看/删除/获取股东信息）、与其他客户关联信息列表【ZJJK00104759】、受益人信息列表【ZJJK00148952PDCP】（新增/修改/查看/删除）、关联人信息列表【ZJJK00108375】（关联类型 CorpRelTp：0股东/1高管/2法人代表家族成员/3实际控制人家族成员/4个人股东家族成员/5其他）、相关弹窗【ZJJK00105742】【ZJJK00096268】【ZJJK00113713】；持股比例计算规则。
- 实际控制企业【ZJJK00115908】：引入/新增对公信贷潜在客户。
- 新增对私客户信息弹窗【ZJJK00114724】+ 个人手机号验证清单【ZJJK00104683】（担保公司场景下登记实际控制人）。

### 联网核查（对公）
- 对公联网核查信息主页【ZJJK00104503】：核查时间/核查结果(olInspStcd 1通过 2不通过)查询；【发起实时核查】确认后带客户编号/名称/USCC/法定代表人信息发起；【查看详情】。
- 对公联网核查详情【ZJJK00105517】：企业信息页签 + 股东出资/董事监管/变更事项/异常经营/严重违法失信/营业执照作废 六类明细；全字段只读。

### 法院信息
- 对公法院信息查询主页【ZJJK00105073】：法院信息类型 courtInfTpCd（1涉诉/2失信被执行/3限制消费被执行）、是否有效；进入自动按客户编号查询。

### 影像资料
- 公共影像组件源码主页【ZJJK00100615】：有业务/客户/合同编号时展示影像区域；查看态或上一环节指定不可操作时禁操作（除非指定忽略）。规则详见附件《影像资料目录》。

- 列表查询默认收起"更多"条件；列表创建时间倒序。
- 保存/暂存必输校验统一提示"请输入XXX！"。
