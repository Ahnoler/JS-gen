## 1. 候选可贯通主链

### 主链 A：对公潜在客户新增 → 概况维护 → 客户转正 → 正式客户信息维护（首推湿测）
- **闭环目标**：从无到有创建一个对公潜在客户并补齐概况，转正为信贷正式客户且完成客户资料登记。
- **前置条件**：客户经理账号有【客户管理】菜单权与本人管户/业务数据权；证件类型=统一社会信用代码（营业执照走 18 位校验）；ECIF 可达。
- **有序步骤**：
  1. 对公客户主页【ZJJK00066153】→【新增】（打开向导抽屉）
  2. 新增对公客户主页【ZJJK00066158】：选对公客户类型（非担保公司）→ 录证件类型/客户名称/证件号码（或【OCR识别】营业执照回填）→【保存】
     - 校验：必输、营业执照 18 位、信贷系统内不重复；ECIF 有编号则同步，无则 ECIF 建潜在客户；客户状态登记为草稿客户，操作人=主办客户经理
  3. 进入创建潜在客户基础页面【FS00005518 / 任务页 ZJJK00107525】→ 维护对公客户概况主页【ZJJK00104633】
  4. 维护概况：国别、登记注册地址（地址五级联动【ZJJK00098350】）、宗旨/主营业务范围（按客户类型切换）、财务部联系人手机号、投资主体类型、成立/注册/失效日期、USCC、法定代表人（放大镜【ZJJK00109101】）
  5. 【联网核查】（法人证件号/USCC/法人名称为空拦截；事业类/国家机关不显示）→ 更新核查状态
  6. 【保存】（保存成功后客户状态=信贷潜在客户）；草稿客户可【暂存】
  7. 【客户转正】（维护场景 + 状态为信贷临时/草稿/潜在客户）→ 进入创建对公客户信息场景【FS00004007】
  8. 任务页【ZJJK00101443】按页签补齐：客户综合信息、财务信息、业务信息、影像资料、其他信息（非管户客户经理仅见财务信息页签）
  9. 概况【ZJJK00104640】【保存】/【暂存】→ 返回对公客户主页，列表可见该客户
- **章节出处**：章2 客户信息维护 > 对公客户管理 > 维护对公客户信息 > 新增（向导页 + 三场景）

### 主链 B：担保公司类型客户新增与维护
- **闭环目标**：新增对公客户类型=担保公司的客户并保存概况（客户状态自动=信贷正式客户）。
- **前置条件**：同主链 A；对公客户类型选"担保公司"。
- **有序步骤**：
  1. 主页【ZJJK00066153】→【新增】→【ZJJK00066158】选担保公司（客户状态锁定为正式客户）→【保存】
  2. 进入【FS00005510 / 任务页 ZJJK00107480】客户基本信息页签（概况/标签/股东及关联人/经营情况）
  3. 维护对公客户概况主页【ZJJK00106530】：机构资质、基本存款账户、实际控制人（【新增对私信贷潜在客户】弹窗【ZJJK00114724】+ 手机号验证清单【ZJJK00104683】）、行业代码（树）、注册资本/实收资本等
  4. 【验证清单】查看校验清单 →【保存】/【暂存】→【返回】
  5. （延伸）维护股东及关联人信息【ZJJK00104723】：股东列表【ZJJK00113713】【获取股东信息】、受益人列表【ZJJK00148952PDCP】、关联人列表【ZJJK00108375】、实际控制企业【ZJJK00115908】
- **章节出处**：章2 > 对公客户管理 > 新增 > 对公客户类型为担保公司

### 主链 C：对公客户修改 / 查看
- **闭环目标**：修改（或只读查看）既有对公客户资料并保存。
- **前置条件**：列表存在可选客户；状态非 合并注销/合并中/注销；修改需操作人=管户客户经理（否则受限编辑）。
- **有序步骤**：主页【ZJJK00066153】选中记录 →【修改】（校验"请选择有效数据"/状态拦截）→ 复用 A/B 场景页面（FS00005518 / FS00005510 / FS00004007，差异化规则：无）→ 保存；【查看】为只读模式。
- **章节出处**：章2 > 修改 / 查看

### 主链 D：对公联网核查（含详情六类明细）
- **闭环目标**：对选中对公客户发起实时联网核查并查看核查结果与明细。
- **前置条件**：已选客户且状态非合并注销/合并中/注销。
- **有序步骤**：主页【ZJJK00066153】→【联网核查】→ 核查信息主页【ZJJK00104503】→【发起实时核查】（确认弹窗，带 USCC/法代信息）→ 刷新列表 →【查看详情】→ 核查详情【ZJJK00105517】企业信息页签 + 股东出资/董事监管/变更事项/异常经营/严重违法失信/营业执照作废 六类明细（只读）。
- **章节出处**：章2 > 联网核查

### 主链 E：对公法院信息查询 / 影像资料查看
- **闭环目标**：查询客户法院信息（涉诉/失信被执行/限制消费被执行）或查看影像资料。
- **前置条件**：已选客户；法院信息同样受状态拦截。
- **有序步骤**：主页【ZJJK00066153】→【法院信息】→ 法院信息查询主页【ZJJK00105073】（进入自动按客户编号查询，类型/有效性筛选，查询/重置）；【影像资料】→ 公共影像组件【ZJJK00100615】（只读查看）。
- **章节出处**：章2 > 法院信息 / 影像资料

### 主链 F：对公客户分类修改（审批流）
- **闭环目标**：发起客户分类变更申请并通过审批，最终落库更新客户分类。
- **前置条件**：客户为对公且非担保公司（担保公司禁发分类修改）；客户经理账号。
- **有序步骤**：
  1. 【客户管理】→【客户关键信息修改】→ 主页【ZJJK00107849】→【新增】→ 客户主体选择抽屉（切对公、修改类型=客户分类）→ 确定（生成申请编号 GJ+yyyyMMdd+6位）
  2. 任务页【ZJJK00109829】→ 变更对公客户分类【ZJJK00109826】：原分类自动定调整类型（发展巩固→下调、压缩退出→上调、限制维持→限选）；保存校验"至少修改一个关键信息！"/新旧不可相同
  3. 下一步 → 提交流程【ZJJK00090538】签署意见提交（上调/初分→发展巩固类 = wf_cust_005；下调/初分→限制维持/压缩退出 = wf_cust_006）
  4. 审批链：网点负责人【ZJJK00113292】→ 部门负责人【ZJJK00109869】→ 行长/分管领导【ZJJK00113293】（同意/不同意/退回）
  5. 流程结束 → 申请状态=通过 → 更新客户资料
- **章节出处**：章3 > 维护关键信息申请 > 新增 > 对公客户分类修改申请

### 主链 G：对公一般关键信息修改（多页签审批流）
- **闭环目标**：变更客户类型/控股类型/成立日期/行业/注册资本/企业规模/法定代表人/实际控制人/股东/实际控制企业/关联人并审批生效（含 ECIF 同步）。
- **前置条件**：对公客户；申请状态为待发起/打回 且本人创建才可修改。
- **有序步骤**：主页【ZJJK00107849】→【新增】选对公+修改类型=一般关键信息修改 → 任务页【ZJJK00109892】（基本信息步骤）：变更客户关键信息【ZJJK00109846】/基本信息【ZJJK00109861】/企业规模【ZJJK00109862】（【测算】规则引擎回填，类型固定只读）/法定代表人【ZJJK00109863】（引入）/实际控制人【ZJJK00109864】（国家机关/社团/担保公司隐藏）/股东【ZJJK00109983】（原只读+现【ZJJK00113829】增改删）/实际控制企业【ZJJK00115741】（国有绝对/相对控股才显示）/关联人【ZJJK00109866】→【保存】（"至少修改一个关键信息！"）→ 签署意见 → 提交流程【ZJJK00090538】→ 审批（wf_cust_004 四层）→ 通过后停旧登新 + 同步 ECIF。
- **章节出处**：章3 > 新增 > 对公一般关键信息修改申请

### 主链 H：对私关键信息修改（客户类型/细分类型）
- **闭环目标**：变更个人客户客户类型（农户/其他自然人）与细分类型并审批生效（流程结束仅更新这两项）。
- **有序步骤**：主页【ZJJK00107849】→【新增】选对私 → 任务页【ZJJK00107848】→ 变更对私关键信息【ZJJK00107847】→ 提交流程 → 审批（网点【ZJJK00113204】/部门【ZJJK00109830】/分管【ZJJK00113212】）→ 落库。
- **章节出处**：章3 > 新增 > 对私关键信息修改申请

### 主链 I：同业客户新增与维护
- **闭环目标**：新增同业客户并完成基础信息、关联关系、股东、高管、经营信息等维护。
- **有序步骤**：同业客户主页【ZJJK00066696】→【新增】（抽屉）→ 维护同业客户场景【FS00001388】：校验基础信息 → 登记客户编号与客户权限 → 任务页维护业务信息/关联关系/法代/实控人/股东（复用对公组件 ZJJK00113713/ZJJK00105742）/组织机构/经营信息 → 法院信息/联网核查查看 → 返回。
- **章节出处**：章2 > 同业客户管理

### 主链 J：合作方（评估机构）维护
- **闭环目标**：新增/维护评估机构及其评估人员、影像资料。
- **有序步骤**：评估机构主页【ZJJK00105573】→ 筛选查询 →【新增】→ 任务页维护基本信息 → 维护评估人员（人员增改查删；证书标志联动证书编号必填）→ 影像资料 → 返回。其余五类合作方（汽车运输公司/第三方监管机构/房地产开发商/汽车经销商/工程机械经销商）同 CRUD 模式。
- **章节出处**：章4 > 评估机构 等
