# 对私进件申请

> 源章路径：对私进件申请（总体描述 / 预授信组件 / 授权准入组件（独立+前置）/ 授信组件 / 贷款申请组件 / 提额组件 / 提款组件）

## 要点摘要

- 面向自然人客户，覆盖授权准入、授信、贷款、提额、提款五类业务的申请录入、协议在线签署与结果反馈。
- 申请单状态：待发起 → 审批中 → 已通过 / 已拒绝；协议签署状态：待签署 → 签署中 → 已签署 / 已拒签（客户取消）。
- 对私侧独有：**新增前置授权准入**（对公无独立成节）、**提额额度预估页**、贷款前需身份证件填写/识别确认环节；大量页面标注「同对公」引用。

## 组件结构与关键规则

### 预授信组件（新增对私预授信申请，场景 FS00080884）
- 填写客户预授信申请信息主页【ZJJK00207092】：
  - 【测额】先校验数标必填（不通过终止）→ 按进件申请编号发起额度测算；未取得进件申请编号提示【测算异常】，测算不成功提示【额度测算失败】→ 成功跳额度测算结果页。
  - 【测一测】先保存数标 → 影像资料必填校验 → 按预授信申请编号提交预授信预约（失败【预授信预约提交失败】）→ 跳预授信申请结果页。
  - 界面原型同对公。
- 测额结果展示【ZJJK00204359】、获取预授信结果主页【ZJJK00244016】、授权准入结果页【ZJJK00204007】：均「同对公」，差异化规则无。

### 授权准入组件
- **新增独立授权准入**：
  - 授权准入产品首页主页【ZJJK00207098】：
    - 输出：cmpnPdNm 产品名称、pdLbl 产品标签、hgstCanLoanAmt 最高可申请额度、loanIntrt 年化利率、ahbTpNm 授权协议名称。
    - 页面初始化按入口加载产品信息。
    - 【授权准入】：未勾选协议提示【请先勾选同意协议】；勾选后跳授权准入申请页并带入申请单编号、产品编号、授权准入编号、提款对象编号、当前进度、借款人编号。
    - 【测一测额度】仅产品支持预授信时显示；可执行→测一测额度页，不可执行→结果查询页。
    - 授权协议规则：按当前产品、个人客户、授权准入阶段、关系人自身查协议文件列表；点协议名生成 PDF 预览。
  - 新增对私授权准入申请（场景 FS00080885）：填写身份证件信息【ZJJK00207099】→ 确认身份证件信息【ZJJK00207100】→ 签订授权准入协议【ZJJK00207106】+ 进件协议签署组件【ZJJK00204004】→ 获取授权准入结果【ZJJK00207102】。
- **新增前置授权准入**（场景 FS00080886）：授权准入产品首页 → 填写身份证件信息【ZJJK00207104】→ 身份证上传识别 → 确认身份证件信息【ZJJK00207105】→ 协议签署页 → 进件协议签署组件 → 授权准入结果页（反馈准入结论及后续授信/贷款/提款可办理性）。

### 授信组件（新增对私授信申请，场景 FS00080887）
- 授信申请产品首页主页【ZJJK00207108】：产品列表浏览 + 【新增申请】入口；无独立业务要素。
- 填写客户授信申请信息主页【ZJJK00207110】【提交】：先保存数标 → 必传文件校验 → 授信信息对话框确认额度（【立即签约】提交）→ 提交对私授信申请并切结果页。
- 授信额度预估页【ZJJK00244277】：录入客户基本信息/收入/资产负债 →【额度预估】测算（额度/利率/期限）→ 可返回重算 →【下一步】提交审批。
- 获取授信申请结果【ZJJK00207111】。

### 签订授信协议
- 对私授信协议签署页主页【ZJJK00248264】：关联进件协议签署组件完成签署。

### 贷款申请组件（新增对私贷款申请）
- 贷款申请产品首页主页【ZJJK00207114】：产品列表按名称/编码【查询】筛选；选产品【下一步】进录入页。
- 填写贷款申请信息主页【ZJJK00207115】【提交】：保存数标（失败终止）→ 影像资料必填校验 → 进合同签署步骤。
- 填写合同信息主页【ZJJK00244233】：带入客户姓名/证件号码；填写合同名称/编号/借款金额/期限/币种、放款账号/还款账号/还款方式/利率类型、担保方式（抵质押物/保证人）；【下一步】保存并进签约环节。
- 获取贷款申请结果【ZJJK00207117】：按贷款申请编号查审批结论、授信金额、产品信息、处理状态。
- 对私贷款协议签署页主页【ZJJK00248280】：关联进件协议签署组件。

### 提额组件
- 新增提额申请信息主页【ZJJK00207118】→ 提额额度预估页【ZJJK00244343】→ 获取提额申请结果主页【ZJJK00207120】；贷款申请结果页【ZJJK00196098】引用。
- 对私提额协议签署页主页【ZJJK00248291】：关联进件协议签署组件。

### 提款组件（新增对私提款申请）
- 提款申请产品首页主页【ZJJK00207122】→ 填写提款申请信息主页【ZJJK00207123】+ 还款计划自定义页【ZJJK00180005】+ 填写提款申请信息页【ZJJK00204020】→ 获取提款申请结果【ZJJK00207125】。
- 对私提款协议签署页主页【ZJJK00248288】：关联进件协议签署组件。

## 待湿测

- 大量页面标注「同对公」/「界面原型同对公」，实际运行差异（尤其字段集、协议清单）需湿测确认。
- 对私贷款场景「需先完成股东会决议维护与表决」的触发条件与对公侧联动规则未细化。
- 功能说明多处出现「对私及对私客户」「对私与对私两种办理入口」等疑似笔误（疑为「对公/对私」），待与产品确认。
