# 实名认证

> 源章路径：实名认证（总体描述 / 对公企业认证 → 新增企业实名认证）

## 要点摘要

- 面向对公客户的实名认证，覆盖认证发起、企业证照与法人身份资料采集、核验进度跟踪、认证结果展现；认证结果作为后续信贷流程（协议签署、授信、用信）的合规前置。
- 业务环节顺序：发起认证申请 → 企业证照与人员身份信息采集 → 证照影像与外部权威源比对 → 提交初审 → 复核认定 → 完成实名认证登记。
- 状态说明：企业实名认证状态 待提交 → 审核中 → 已通过 / 未通过（未通过调整资料后重新发起）。

## 关键规则/字段

企业实名认证流程页主页：
- 操作步骤：1) 填写企业基本信息（企业名称、统一社会信用代码、注册地址、联系方式等必填）；2) 上传营业执照、法人身份证件影像；3) 核对法定代表人信息并发起法人身份认证；4) 【提交】后展示审核进度；5) 审核完成后查看认证结果。
- 【去认证】入口规则：按客户类型分流——对私发起个人实名认证、对公发起企业实名认证；企业认证申请前校验当前用户允许发起企业认证；申请成功后按返回的认证地址携带租户标识、第三方认证编号、回跳地址跳转；失败提示【获取实名认证信息异常，请检查】。
- 本页无独立业务要素字段；操作权限为空表。
