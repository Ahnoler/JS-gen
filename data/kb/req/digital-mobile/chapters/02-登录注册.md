# 登录注册

> 源章路径：登录注册（总体描述 / 登录注册管理 → 用户登录注册）

## 要点摘要

- 登录：账户密码认证（签约手机号 + 登录密码），登录成功跳首页；含注册/忘记密码/取消/密码可见性入口。
- 注册：新用户依次选客户类型 → 手机号 → 获取验证码 → 密码/确认密码 → 工作地址（省市区弹窗）→ 协议阅读倒计时 → 提交注册 → 成功弹窗 → 立即登录。
- 状态说明：
  - 用户认证状态：待验证 → 已验证 / 验证失败（可重试回待验证）；
  - 用户注册状态：信息填写中 → 已提交 → 审核通过 / 审核未通过（可返回修改）。

## 关键规则/字段

登录页：
- 输入：签约手机号 form.number（必填）、登录密码 form.password（必填，支持显示/隐藏）。
- 【登录】验证身份跳首页，失败显示 errorMsg；【注册】跳注册页；【忘记密码】跳找回密码页；页面初始化加载法人行列表到租户选择器。

注册页字段：
- cstTp 客户类型（下拉，必填）、mblphNo 手机号（必填）、_pswd 密码、confirmPassword 确认密码、areaText 工作地址（省市区，必填）、vldCd 验证码（必填）、rcmmEmpeNo 推荐员工号（选填）、agreed 同意服务协议（复选，必填）。
- 【获取验证码】：先校验手机号格式；倒计时>0 时禁用。
- 【下一步】：校验已同意协议；协议倒计时>0 或未勾选时禁用；成功后弹窗提示。
- 字段联动：省未选→城市只读；城市未选→区县只读；修改客户类型联动刷新后续字段。
- 页面加载时获取公钥用于密码加密。
