# 服务中心

> 源章路径：服务中心（总体描述 / 申请进度 / 提款入口 / 贷款记录 / 签约中心）

## 要点摘要

- 客户自助贷后统一入口：申请进度、提款入口、贷款记录、还款信息、提前还款、还款账号变更、签约列表。
- 以查询类操作为主；仅【新增提前还款】与【变更还款账号】涉及审批；签约相关页面跳转至模块外协议签署组件。
- 状态说明：
  - 提前还款申请状态：待发起 → 审批中 → 已通过 / 已退回（可修改重提）；
  - 还款账号变更状态：待发起 → 审批中 → 已变更 / 变更失败。

## 关键规则/字段

### 申请进度（查询申请进度）
- 查看申请进度列表主页【ZJJK00244356】：按客户名称/申请编号查询，列表展示申请类型、提交时间、当前进度；下拉刷新；【查看】只读打开进度详情（处理人、处理机构、处理结果）。
- 各申请类型详情：查看提额申请详情【ZJJK00244375】、查看提款申请详情【ZJJK00244365】、查看贷款申请详情【ZJJK00244369】、查看授信申请详情【ZJJK00244360】、查看授权准入申请详情——各详情均含查看基本信息【ZJJK00244377 / 00244375 / 00244369 / 00244365 / 00244360】与查看客户信息【ZJJK00244368】；查看申请信息主页（提款 ZJJK00244380 / 授信 ZJJK00244371 / 贷款 ZJJK00244366）含还款计划自定义页【ZJJK00180005】与填写提款申请信息页【ZJJK00204020】引用。

### 提款入口（查询提款列表）
- 可提款进件列表主页【ZJJK00240000】：
  - 页面初始化：按进件编号与产品编号自动加载允许提款的营销产品列表；列表默认为空，可条件查询；【重置】清空。
  - 【立即提款】：校验产品可用额度>0，否则提示【剩余额度不足！】并中断；对公主体→对公提款申请首页，对私主体→对私提款申请首页。

### 贷款记录
- 查看贷款记录列表主页【ZJJK00240007】→ 查看贷款记录【ZJJK00240009】：申请编号、客户名称、业务品种、审批金额、状态等。
- 查看还款记录列表【ZJJK00244189】：还款历史查询。
- 查看还款计划【ZJJK00244191】：还款计划查询。
- 新增提前还款【场景 FS00104629】新增提前还款信息【ZJJK00244215】：录入借款合同编号、提前还款日期、本次还款金额、还款类型（全额结清/部分提前还款）、备注；提交后校验金额范围、扣款账户有效性、贷款状态→生成待扣款任务→资金扣划→冲减本金并重算还款计划→记入还款历史。
- 变更还款账号【ZJJK00244224】：录入新还款账号提交变更申请，审批通过后新账号生效。

### 签约中心（查看签约列表）
- 查看签约列表主页【ZJJK00248262】：集中留存追溯全程签约记录。
