# 对公进件申请

> 源章路径：对公进件申请（总体描述 / 预授信组件 / 授权准入组件 / 授信组件 / 贷款申请组件 / 提额组件 / 提款组件）

## 要点摘要

- 面向对公客户六大环节：预授信、授权准入、授信、贷款申请、提额、提款；覆盖资格预审 → 合同签署 → 放款支用全周期。
- 进件申请状态：待发起 → 申请中（提交后仍申请中）；协议签署状态：待签署 → 签署中 → 已签署。
- 全分册统一收口：各环节协议签署页以关联页方式调起【进件协议签署组件】完成电子签署；各环节【获取XX结果】页回执审批结论并路由下一步。

## 组件结构与关键规则

### 预授信组件（新增预授信申请，场景 FS00064611）
- 流程：授权准入产品首页 → 填写预授信申请信息 → 填写/确认身份证件 → 任务页 → 签订授权准入协议 → 进件协议签署组件 → 获取授权准入结果。
- 填写客户预授信申请信息主页【ZJJK00192099】：【测一测】先保存数标信息（失败中止）→ 校验必传文件（缺失提示【请上传所有必传文件】）→ 发起预授信预约提交（未取到进件申请编号提示异常）→ 跳测额结果展示。
- 测额结果展示【ZJJK00204359】：输出 cstNm/cstNo/clmAmt 测算额度/clmCcy/clType/clmRslt/clmDt/efctDt/exprDt/clmRmk。
- 获取预授信结果【ZJJK00192098】：入参 cstNo/aplyNumb；输出 crdtRslt 授信结论/crdtAmt/vldDt/rate；状态展示规则：审批中/审批通过（加载签约信息）/审批拒绝三种标题。

### 授权准入组件（新增独立授权准入，场景 FS00080601）
- 任务页【ZJJK00204008】：按办理进度路由（填证件 → 确认证件 → 获取结果）；授权书需逐份下拉到底且倒计时结束才能点【我已阅读并同意上述条款】。
- 填写身份证件信息主页【ZJJK00204010】：【下一步】校验身份证正反面已上传（否则【请先上传身份证信息】）→ 发起身份证 OCR 识别 → 保存后进确认界面。
- 身份证上传识别组件【ZJJK00200000】：frontFileList/backFileList 必传，上传后自动识别，可手工修正后【确认】回填。
- 获取授权准入结果【ZJJK00204007】：同预授信结果页（引用），差异化规则无。

### 签订授权准入协议
- 授权准入协议签署页主页【ZJJK00248229】：
  - 协议清单加载：有关联业务编号时查待签协议清单；查不到提示【获取签约协议失败！】；状态：全部完成→【已签署】、本人已签他人未签→【待他人签署】、否则【待签署】。
  - 【预览】取协议预览地址（失败【获取预览地址失败！】）；【同步】按协议编号+第三方签署任务编号同步结果并刷新；【签署】取电子签署任务地址（失败【获取签约地址失败！】）。
  - 【签署完成】：授权编号为空中止；【签约中】必须全部协议签字项完成（否则【协议未完成签署或状态未同步】）；提交后审核结果映射：通过→授权审批通过（记生效/到期日期、推进进件阶段）、线上转线下→授权审批中、拒绝→授权审批拒绝、其他→【获取授权准入结果异常！】。

### 授信组件（新增授信申请，场景 FS00076608）
- 授信申请产品首页主页【ZJJK00192124】页面初始化：按进件申请编号+营销产品编号+授信申请编号加载；客户/编号缺失不允许办理；无营销产品不允许；额度/利率未配置按0；无入口授信申请编号时找最新一笔未删除、非授信通过/拒绝的申请，找不到则新建（申请金额=最高可申请额度）；产品支持预授信且首阶段为授信进件时显示【测一测额度】；有效期内已通过授权准入记录可免重复授权；授权准入按独立/前置分流。
  - 【测一测额度】一个月内已有进度状态不可重复测算；【授信申请】需独立授权时提示【该营销产品未授权准入或授权准入已过期，请重新授权!】，前置授权进前置授权页，无需授权直接进申请页。
- 填写客户授信申请信息主页【ZJJK00196092】：
  - 信息加载：数标模板为空提示【数标模板为空，请联系管理员！】；新建申请时金额=最高可申请额度。
  - 业务数标校验：必填非空；身份证类格式、统一社会信用代码/组织机构代码格式、金额非负两位小数、手机号 1 开头十一位、整数非负；只读项/查看态不可改。
  - 【提交】：数标校验→保存（替换旧数标）→必传文件校验→额度确认弹窗（预计授信额度、起止日期，【立即签约】提交，四字段非空）→按授信申请编号提交对公授信申请；预授信结果映射：通过+有协议→签约中、通过+无协议→发签署完成通知并【授信通过】推进阶段、线上转线下→审批中、拒绝→授信拒绝+已失效、异常→提交失败；成功提示【提交成功！】切结果页。
- 授信额度预估页【ZJJK00244284】：进入自动按授信申请编号发起测额（编号/申请/模型结果非空校验）；输出 crgAmt/crgStdt/crgExdt；有效期开始=当前日期，结束=一年后。
- 获取授信申请结果【ZJJK00196093】：按进度状态展示（审批中动画/审批通过发起下一步查询/审批拒绝/签约中显示【去签署】）；通过后按阶段路由：允许提款→【提款申请】、授权准入/授信申请/贷款申请各阶段对应按钮；【下一步】待签约携关联业务编号跳协议签署页，审批通过携进件申请编号+伴随产品编号跳阶段首页。

### 签订授信协议
- 对公授信协议签署页主页【ZJJK00248278】【签署完成】：授信申请编号非空校验→查授信申请主档→协议签署阶段逐份校验协议完成→发起签署完成通知→回写额度生效/到期日期→进件进度【授信通过】推进阶段→跳对公进件申请结果页。

### 贷款申请组件（新增对公贷款申请，场景 FS00076601）
- 贷款申请产品首页主页【ZJJK00196000】：页面初始化按入口查产品详情；【贷款申请】按授权准入分流（独立授权过期提示/前置授权页/直接进申请页）；测一测额度仅产品支持预授信时显示，可测→新增预授信页、不可测→预授信结果页；【授权准入】跳授权准入产品首页。
- 填写贷款申请信息主页【ZJJK00196097】：贷款申请编号为空/查不到终止加载；数标模板为空提示；【提交】数标校验→保存数标→必传文件校验→进合同信息页；数标校验规则同授信（手机号表述为「以1开头的手机号格式」）。
- 填写合同信息主页【ZJJK00244247】：
  - 输入：dwmAmt 申请金额、pymd 支付方式、loanDdln 贷款期限(月)、yrIntrt 年利率（只读，签约环节不可改）、rpmd 还款方式、lendRepayAcctno 放还款卡号、loanUse 贷款用途；受托支付(2)联动显示 rcvpymtpsNm/rcvpymtpsAcc/rppdbnk。
  - 输出：dwmLwstAmt 最低可申请金额、spllmt 最高可贷金额、lgstCanLoanDdln 最长贷款期限、cstmgrEmpno、crcstNo、prmtBseqDwmInd 是否允许多次提款等；页顶展示「最高可申请{最高可贷金额}元」。
  - 【立即签约】：必填校验→金额≥0 且≤最高可申请（提示【贷款金额不能小于0】/【最高可申请XXX元】）→期限≤最长（【最大贷款期限月不能大于XXX】）→保存提交→跳审批结果步骤。
  - 【放款试算】：校验金额/期限/还款方式/年利率完整→弹窗还款计划（总还款、每期、利息）。
  - 申请金额放大镜：自动填入最高可申请金额。
- 获取贷款申请结果【ZJJK00196098】：展示受理结果。
- 对公贷款协议签署页主页【ZJJK00248281】【签署完成】：带贷款申请编号发起签约完成通知→跳对公新增贷款申请场景。

### 提额组件（新增提额申请，场景 FS00080626）
- 新增提额申请信息主页【ZJJK00204498】：录入客户编号（自动回显客户名称/统一社会信用代码/可用授信额度）、提额金额、币种、类型、起止日期、用途、担保方式、还款来源等；【提交】先保存数标（失败中止）→按提额申请编号提交→【提交成功！】进结果页。
- 获取提额申请结果主页【ZJJK00204500】：列表+【查看】详情+【返回】。
- 对公提额协议签署页主页【ZJJK00248292】：加载待签署提额协议，签署确认；业务规则为空表。

### 提款组件（新增对公提款申请，场景 FS00080604）
- 提款申请产品首页主页【ZJJK00204105】：输出 cmpnPdNm/avlLmt 剩余可借/loanIntrt 年化利率/crgExdt 额度有效期/crgAmt 授信额度；【提款申请】按授权准入分流（独立授权→重新授权提示、非独立→前置授权页、无需→提款申请页）；【提额申请】入口仅产品允许提额时显示（并显示额度信息）；【取消】关闭弹窗；【授权准入】跳授权准入产品首页。
- 填写提款申请信息主页【ZJJK00204020】与还款计划自定义页【ZJJK00180005】：同贷款合同信息页（引用），差异化规则无。
- 获取提款申请结果【ZJJK00204107】：按环节差异化提示（签约→引导签署；审批中→预计时间+短信通知；通过→额度/放款日期；拒绝/转人工→说明）。
- 对公提款协议签署页主页【ZJJK00248287】【签署完成】：借款合同签署完成通知→校验提款申请；【签约中】须全部协议签字项完成（否则【协议未完成签署或状态未同步】）；按营销产品参数的提款链接标识分信贷/合同通知分支回写合同编号、凭证编号、借据编号；完成后提款进度置【已签署完成】。

## 待湿测

- 「进件协议签署组件」作为统一签署收口被多章引用，但其页面本体未在本分册单独成章展开（仅经各签署页的【签署】/【签署完成】规则间接描述）。
- 前置授权准入页面在对公侧被引用（【前置授权准入页面】）但无独立小节。
- 贷款申请组件功能说明中提到「必要时联动股东会决议管理与身份证件信息校验」的触发条件未给出字段级规则。
- 外部调用接口各页几乎均标「无」，与页面初始化/签署流程明显依赖后台服务的描述不一致，接口清单待湿测补齐。
