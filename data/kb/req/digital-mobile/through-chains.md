## 主链明细

### MC1 登录注册
- 出处：chapters/02
- 前置：可访问移动端；页面初始化加载法人行列表、获取公钥。
- 步骤：登录页输入签约手机号+密码【登录】→ 成功跳首页（或新用户【注册】）→ 注册页选客户类型→手机号→【获取验证码】→验证码→密码/确认密码→工作地址→协议阅读并同意→【下一步】→ 成功弹窗【立即登录】→ 登录。
- 终态：已验证 / 注册审核通过。
- 旁路：忘记密码（本分册无实现细则）。

### MC2 实名认证（我的主页引导）
- 出处：chapters/03、04
- 前置：已登录；hasAuth=未通过。
- 步骤：我的主页【请实名认证】/ 实名认证信息页【去认证(个人/企业)】→ 携租户标识+认证编号+回跳地址进电子签约认证流程（外部）→ 完成后回跳我的主页重载 → 实名状态=已通过。
- 终态：trdptCtfnSt=2（认证通过）。
- 待湿测：外部认证流程、认证状态枚举全集。

### MC3 对公预授信申请（FS00064611）
- 出处：chapters/06 预授信组件
- 前置：营销产品支持预授信；已登录客户。
- 步骤：授信/贷款产品首页【测一测额度】→（一个月内无有效测额时）新增预授信申请页 → 填写客户预授信申请信息【ZJJK00192099】→【测一测】保存数标+必传文件校验+预授信预约提交 → 测额结果展示【ZJJK00204359】→ 获取预授信结果【ZJJK00192098】（审批中/通过加载签约信息/拒绝）。
- 终态：预授信结论（授信额度+有效期）。

### MC4 对公独立授权准入（FS00080601）
- 出处：chapters/06 授权准入组件 + 签订授权准入协议
- 前置：营销产品需授权准入且按独立授权办理。
- 步骤：产品首页【授权准入】→ 任务页【ZJJK00204008】按进度路由 → 填写身份证件信息【ZJJK00204010】（正反面上传 OCR）→ 确认 → 授权准入协议签署页【ZJJK00248229】：协议清单加载→逐份【预览】【签署】→【同步】→ 全部签字项完成后【签署完成】→ 审核结果映射（通过=授权审批通过并记生效/到期日期、推进进件阶段）。
- 终态：授权准入状态=授权审批通过；异常【获取授权准入结果异常！】单列。

### MC5 对公授信申请（FS00076608）
- 出处：chapters/06 授信组件 + 签订授信协议
- 前置：进件申请编号+营销产品编号有效；授权准入在有效期内（或需重授权先走 MC4）。
- 步骤：授信申请产品首页【ZJJK00192124】（初始化：找/新建授信申请，金额=最高可申请额度）→【授信申请】→ 填写客户授信申请信息【ZJJK00196092】（数标校验+必传文件）→【提交】→ 额度确认弹窗【立即签约】→ 提交对公授信申请 → 获取授信申请结果【ZJJK00196093】（签约中→【去签署】）→ 对公授信协议签署页【ZJJK00248278】【签署完成】→ 回写额度生效/到期日期 → 进件进度【授信通过】→ 进件结果页。
- 终态：申请进度=授信通过（或授信拒绝+已失效、审批中转线下）。

### MC6 对公贷款申请（FS00076601）
- 出处：chapters/06 贷款申请组件
- 前置：授信通过；产品授权准入要求已满足。
- 步骤：贷款申请产品首页【ZJJK00196000】→【贷款申请】→ 填写贷款申请信息【ZJJK00196097】（数标+必传文件）→ 填写合同信息【ZJJK00244247】（金额/期限/利率校验，受托支付联动收款信息，可【放款试算】）→【立即签约】→ 获取贷款申请结果【ZJJK00196098】→ 对公贷款协议签署页【ZJJK00248281】【签署完成】→ 签约完成通知。
- 终态：贷款协议签署完成，进入放款环节。

### MC7 对公提额申请（FS00080626）
- 出处：chapters/06 提额组件
- 前置：产品允许提额；已有授信关系。
- 步骤：提款申请产品首页【提额申请】→ 新增提额申请信息【ZJJK00204498】（客户回显+提额要素）→【提交】→ 获取提额申请结果【ZJJK00204500】→ 对公提额协议签署页【ZJJK00248292】签署。
- 终态：提额协议签署完成。

### MC8 对公提款申请（FS00080604）
- 出处：chapters/06 提款组件
- 前置：授信通过且剩余可借>0；授权准入要求已满足。
- 步骤：提款申请产品首页【ZJJK00204105】→【提款申请】→ 填写提款申请信息【ZJJK00204020】（含还款计划自定义页试算）→ 获取提款申请结果【ZJJK00204107】（签约中引导签署）→ 对公提款协议签署页【ZJJK00248287】【签署完成】→ 信贷/合同通知分支回写合同编号、凭证编号、借据编号 → 进度【已签署完成】。
- 终态：提款申请进度=已签署完成。

### MC9 对私预授信申请（FS00080884）
- 出处：chapters/07 预授信组件
- 前置：产品支持预授信。
- 步骤：待办任务进入 → 填写客户预授信申请信息【ZJJK00207092】→【测额】（数标必填校验→按进件申请编号测算）或【测一测】（保存数标→影像校验→预授信预约）→ 测额结果展示 → 获取预授信结果主页【ZJJK00244016】。
- 终态：预授信结论。对私侧页面多标「同对公」。

### MC10 对私授权准入（独立 FS00080885 / 前置 FS00080886）
- 出处：chapters/07 授权准入组件
- 前置：产品需授权准入（独立=已有入口带编号；前置=未取得准入资格）。
- 步骤：授权准入产品首页【ZJJK00207098】（输出产品名称/标签/最高额度/年化利率/授权协议名）→ 勾选授权协议【授权准入】→ 填写身份证件信息【ZJJK00207099/00207104】→ 身份证上传识别 → 确认【ZJJK00207100/00207105】→ 授权准入协议签署（进件协议签署组件 ZJJK00204004）→ 获取授权准入结果【ZJJK00207102】。
- 终态：准入结论 + 后续授信/贷款/提款可办理性提示。

### MC11 对私授信→贷款→提款（FS00080887 等）
- 出处：chapters/07 授信/贷款/提额/提款组件
- 步骤：授信产品首页【ZJJK00207108】→ 填写授信申请【ZJJK00207110】【提交】（数标→文件→额度确认【立即签约】）→ 授信额度预估【ZJJK00244277】→ 获取授信申请结果【ZJJK00207111】→ 对私授信协议签署页【ZJJK00248264】；贷款：产品首页【ZJJK00207114】→ 贷款申请信息【ZJJK00207115】→ 合同信息【ZJJK00244233】→ 结果【ZJJK00207117】→ 对私贷款协议签署页【ZJJK00248280】；提款：产品首页【ZJJK00207122】→ 提款申请信息【ZJJK00207123】→ 结果【ZJJK00207125】→ 对私提款协议签署页【ZJJK00248288】；提额：新增提额【ZJJK00207118】→ 额度预估【ZJJK00244343】→ 结果【ZJJK00207120】→ 对私提额协议签署页【ZJJK00248291】。
- 终态：各协议签署完成（协议签署状态=已签署）。
- 待湿测：对私贷款涉及股东会决议的前置触发。

### MC12 股东会决议·线上
- 出处：chapters/08
- 前置：对公贷款等业务触发股东会决议要求。
- 步骤：股东会决议管理列表【ZJJK00204357】【发起线上股东会】→ 任务页【ZJJK00204452】【发起】（决议表单+股东表单联动校验，标注线上）→ 股东侧：确认身份信息【ZJJK00204467】→ 表决人人脸识别【ZJJK00204570】（活体通过→状态已通过）→ 进行股决决议【ZJJK00204477】逐议案表决（同意/反对/弃权）【提交】→ 表决通过后进行在线签约【ZJJK00204474】（经协议签署页进进件协议签署组件）→ 查看线上股东会进度【ZJJK00204509】。
- 终态：决议状态=表决中→表决结果+配套协议签署完成。

### MC13 股东会决议·线下上传（FS00080649）
- 出处：chapters/08
- 步骤：管理列表【上传线下股东会决议】→ 任务页【ZJJK00204519】→ 维护决议信息【ZJJK00204387】+ 维护股东信息【ZJJK00204422】+ 上传线下股东会决议【ZJJK00149383】→【保存】→ 生效前校验（决议表单、股东表单、附件）→【生效】→ 决议状态=生效 → 返回列表。
- 终态：线下决议登记生效。

### MC14 服务中心·提款与贷后查询
- 出处：chapters/09
- 步骤：申请进度列表【ZJJK00244356】按类型下钻详情；可提款进件列表【ZJJK00240000】→【立即提款】（可用额度>0，否则【剩余额度不足！】；按主体分流对公/对私提款申请首页）→ 贷款记录【ZJJK00240007/00240009】→ 还款记录【ZJJK00244189】/ 还款计划【ZJJK00244191】→ 签约列表【ZJJK00248262】。
- 终态：信息查询闭环 + 提款入口接续 MC8。

### MC15 提前还款 / 变更还款账号
- 出处：chapters/09
- 步骤：贷款记录 → 新增提前还款信息【ZJJK00244215】（合同编号、还款日期、金额、还款类型全额结清/部分）→ 提交 → 校验（金额范围/扣款账户/贷款状态）→ 生成待扣款任务 → 扣划 → 冲减本金重算还款计划 → 记入还款历史；变更还款账号【ZJJK00244224】提交变更申请 → 审批。
- 终态：提前还款申请=已通过/已退回；账号变更=已变更/变更失败（审批为后台环节）。

## 旁路 / Out-of-scope 单列

- 忘记密码：登录页入口存在，找回密码页面实现不在本分册（ch02 待湿测）。
- 前置授权准入页面（对公侧引用）：无独立小节，规则未展开。

- 查看股决结果主页：MC12 流程描述引用，无独立小节与 ZJJK。

- 营销产品展示列表【ZJJK00192084】：仅展示导航，无审批与状态变更，作为各主链的共同入口旁路。
- 章节文本疑误：「营销产品中心」章总体描述写协议签署口径；「对私」章多处「对私及对私客户」疑为「对公/对私」笔误——均已标待湿测。
