# asset-preserve-ops · 可贯通主链清单（视图2）

> 源：P01天阳信贷管理系统-资产保全需求分册【日常管理及其他辅助】.docx
> 口径：主链 = 有闭环目标、有明确入口页面 → 有序步骤 → 有终态（审批通过/状态回写/列表刷新）的候选贯通链。
> 章节出处指向 `chapters/` 内对应文件。

## 主链 1：资产移交（正移交）申请与审批

- **闭环目标**：业务条线客户经理将高风险借据移交给资产保全条线管理；审批通过后借据纳入保全基础管理（所属机构=接收机构、移交状态=已移交、生成保全经理变更记录）。
- **前置条件**：借据存在于【用信放款】模块且经办人=当前登录人；客户经理兼职保全经理时需先配置保全经理角色；审批人（二级支行行长/业务审核/保全审核员/保全审查）可选。
- **有序步骤**：
  1. 移交管理主页【ZJJK00248197】→【新增】
  2. 任务页【ZJJK00210826】：基本信息（ZJJK00210788 移交类型=正移交+接收机构+申请原因；ZJJK00211654 弹窗选借据；ZJJK00211655 责任认定；担保合同/抵质押物只读展示）→ 影像信息 → 签署意见
  3. 提交流程审批【ZJJK00210742】：流程启动（校验借据已选 + 智能控制方案校验）→ 多级审批（AP_HDVMAN_HDVAPLY）
  4. 审批通过：状态=审批通过，借据移交状态回写、主办保全经理变更记录生成
- **章节出处**：chapters/01-不良资产日常管理.md（移交管理 · 正移交）

## 主链 2：逆移交（保全条线退回业务条线）

- **闭环目标**：客户经营改善时，保全经理将资产退回业务条线；审批通过后借据移交标志=未移交、清空保全经理及所属机构。
- **前置条件**：借据已移交保全条线；发起人=保全经理；多级保全审批链可选人。
- **有序步骤**：移交主页 →【新增】→ 任务页【ZJJK00210640】（移交类型=逆移交，隐藏接收机构）→ 选借据 → 影像 → 签署意见 → 流程 AP_HDVMAN_REVERSEAPLY 审批 → 通过后回写。
- **章节出处**：chapters/01-不良资产日常管理.md

## 主链 3：一般转让方案申请与审批

- **闭环目标**：不良资产单笔转让方案从立案到送审、批复归档；审批通过后可下载批复。
- **前置条件**：方案关联借据/担保合同/抵质押物/尽调报告；反委托标识=是时须选反委托客户经理。
- **有序步骤**：
  1. 任务页【ZJJK00210923】三步骤（基本信息五页签 ZJJK00210745/00210743/00210787/00211306/00248158）
  2. 流程 AP_TRANS_TRANSAPLY：处置方案申请 → 业务分发 → 审核 → 审查 → 风险委员会秘书岗（ZJJK00210510，审议结果 ZJJK00210544）→ 有权审批人（ZJJK00210509，批复 ZJJK00156148/00164003）→ 最终有权审批人（ZJJK00210508，有权机构决议 ZJJK00210543/00211337）
  3. 审批通过 → 执行结果登记（主链 4）
- **章节出处**：chapters/02-不良资产转让管理.md（转让方案申请 · 一般转让）

## 主链 4：转让执行结果登记

- **闭环目标**：审批通过的转让方案完成执行登记留痕。
- **前置条件**：方案审批通过；操作角色为组包批转业务员/保全经理（本人经办）。
- **有序步骤**：资产转让执行登记主页【ZJJK00210570】→【执行登记】→ 任务页（基本信息/借据信息/影像资料）→ 保存。
- **章节出处**：chapters/02-不良资产转让管理.md（执行结果登记）

## 主链 5：批量转让全链（备选库 → 组包 → 尽调 → 批量方案）

- **闭环目标**：批量转让资产从备选入库到方案批复的完整闭环。
- **前置条件**：备选库/资产包操作权限（总行/一级支行批转业务岗）；资产包未下发尽调任务才能修改/删除。
- **有序步骤**：
  1. 批转备选库【ZJJK00210771】→ 新增（AP_TRANS_ALLY 流程审批，ZJJK00211130 任务页）
  2. 资产组包【ZJJK00210755】→ 新增资产包（ZJJK00210766；借据可导入 ZJJK00211433）→【下发尽调任务】（限总行/一级支行）
  3. 尽职调查任务【ZJJK00210749】→【处理】（AP_TRANS_DUEDIL；撰写/上传尽调报告 ZJJK00248158）→ 提交审批
  4. 批量转让方案申请【场景 FS00084884】（AP_TRANS_BATCHAPLY）：按资产包归集借据/担保/押品/尽调报告 → 审批 → 批复
- **章节出处**：chapters/02-不良资产转让管理.md（批量转让备选库 / 资产组包管理 / 尽职调查任务管理 / 批量转让方案申请）

## 主链 6：以资抵债申请 → 抵债登记 → 资产入账

- **闭环目标**：以资抵债方案审批通过后，完成执行登记、抵债资产入账，形成可管理的抵债资产。
- **前置条件**：抵债资产基本信息（押品引入或新建）；合规性自查 11 项已填；方案具体信息文本域必填。
- **有序步骤**：
  1. 抵债资产申请主页【ZJJK00210726】→【新增】→ 任务页【ZJJK00210854】（AP_DEBT_APLY 审批）→ 通过（可下载批复）
  2. 抵债方案执行登记主页【ZJJK00210739】→【执行登记】（仅执行中）→ 任务页【ZJJK00211248】六页签（收取方式动态必填、入账信息、借据实际抵偿本金/利息）→ 保存
  3. 抵债资产基本信息主页【ZJJK00210673】→ 分配保管责任人【ZJJK00211383】
- **章节出处**：chapters/03-抵债资产管理.md（抵债申请 / 抵债登记 / 抵债资产基本信息）

## 主链 7：抵债资产日常管理登记

- **闭环目标**：对已入账抵债资产完成保管/处置/监盘/评估/租赁/收入/税费/保险/风险分类/盘点登记并审批归档；为后续处置方案提供"本息损失金额"数据。
- **前置条件**：存在入账状态=已入账、处置状态≠已处置的抵债资产（引入弹窗 ZJJK00211379 限定）。
- **有序步骤**：抵债资产日常管理主页【ZJJK00210663】→【新增】→ 引入抵债资产 → 任务页【ZJJK00210651】九页签 → 暂存/保存 → 流程 AP_DEBT_JURSER 提交审批。
- **章节出处**：chapters/03-抵债资产管理.md（抵债资产日常管理）

## 主链 8：抵债资产处置方案申请 → 处置执行登记

- **闭环目标**：抵债资产对外处置（拍卖/竞价/协议转让等）方案审批并登记执行结果，更新资产处置状态。
- **前置条件**：**须先完成日常管理登记**（流程启动校验"处置抵债资产前，请先发起日常管理登记。"）；方案须已关联抵债资产基本信息。
- **有序步骤**：处置方案主页【ZJJK00210659】→【新增】→ 任务页【ZJJK00211238】（基本信息/费用/买受人及付款方式/方案说明）→ AP_DEBT_DISAPLY 审批 → 流程结束自动创建处置执行登记 → 处置执行登记主页【ZJJK00210590】执行登记 → 保存后更新处置状态。
- **章节出处**：chapters/03-抵债资产管理.md（抵债资产处置方案申请 / 抵债资产处置执行登记）

## 主链 9：委外清收方案申请与审批

- **闭环目标**：委外清收方案立案并通过审批；收回/取消可逆向闭环。
- **前置条件**：方案关联借据（复用核销模块借据选择）与可选非标等资产。
- **有序步骤**：委外清收主页【ZJJK00210620】→【新增】→ 任务页【ZJJK00210644】（AP_OUTCOLL_REGISTER：提交 → 审批）→ 审批通过；【收回】仅审查审批中；【取消申请】仅待处理。
- **章节出处**：chapters/04-委外清收管理.md

## 主链 10：置换不良资产清单登记与保全经理分配

- **闭环目标**：置换不良资产登记审批归档，并指定责任保全经理；支持全量导出。
- **前置条件**：客户（五类放大镜选择）；保全经理角色用户存在。
- **有序步骤**：清单主页【ZJJK00210643】→【新增】→ 任务页【ZJJK00210633】（基本情况/收回情况/变动情况）→ 流程 AP_REPDEAD_REPDEADLIST 审批 →【分配保全经理】（员工查询弹窗 ZJJK00211345）→【下载】导出 Excel。
- **章节出处**：chapters/05-置换不良资产管理.md

## 主链 11：非标业务/其他资产清单登记与处置

- **闭环目标**：非标业务与其他类资产登记审批归档；非标等资产完成处置方案审批与执行。
- **前置条件**：角色数据权限（保全经理/三农岗/其他）；多角色审批人可选。
- **有序步骤**：
  1. 非标清单主页【ZJJK00210567】→【新增】→ 任务页【ZJJK00210776】（AP_OTAST_OTAST：提交→审批）→ 分配保全经理/变更记录/下载
  2. 其他资产清单【场景 FS00084820】（AP_OTAST_OTHER）：任务页【ZJJK00210559】九页签 → 风险委员会秘书岗 → 有权审批人 → 最终有权审批人会签
  3. 非标等资产处置主页【ZJJK00210554】→【新增】方案 → 审批（批复信息/有权机构决议）→ 执行
- **章节出处**：chapters/08-其他资产.md

## 旁路（不构成闭环主链，单列）

- **全辖管理业务查询与操作**（chapters/01）：借据列表查询 + 客户/合同/借据/担保合同/还款记录只读查看；下发处置督办、上传税前扣除凭证、移出备选库、补充责任认定均为单点操作，无端到端审批闭环。
- **我的业务**（chapters/01）：保全经理个人管辖借据查询 + 保全责任认定 + 还款流水确认，单点操作。
- **保全经理变更维护**（chapters/01）：指定主办/协办保全经理、查看主协办及变更记录，单点操作（其变更记录由移交/业务上收流程被动生成）。
- **业务上收**（chapters/01）：可独立发起（综合员 → 总行总经理 → 副行长审批），可视为移交管理的一条变体主链，待湿测后可升级。
- **财产线索 / 费用登记**（chapters/06）：账户动账查询、费用增删改查 + 关联方案，纯辅助无审批。
- **反委托资产管理**（chapters/07）：反委托借据查询 + 详情查看 + 分配责任人 + 导出，单点操作（反委托数据来自转让方案审批链）。
- **时效配置**（chapters/09）：参数维护（增删改查/启停），无业务闭环。

## 建议优先湿测主链

1. **主链 1（正移交）**：步骤清晰、副作用明确（借据移交状态回写），适合作为本模块首选贯通验证链。
2. **主链 8（抵债处置）**：跨日常管理登记与处置方案两条线，有强前置校验，湿测价值高。
3. **主链 5（批量转让全链）**：链路最长（4 段），可分段湿测。
