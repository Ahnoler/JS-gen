# 章节：不良资产转让管理

- **章节路径**：不良资产转让管理（H1）
- **H2 小节**：总体描述 / 批量转让备选库 / 资产组包管理 / 尽职调查任务管理 / 转让方案申请（一般 + 批量）/ 执行结果登记

## 要点摘要
- **总体描述**：为资产保全业务人员提供审批、查询、新增、关联、修改等功能。状态：审批通过（可作为后续业务操作依据）、待处理（中间节点）。
- 业务主线：批量转让备选库（筛选拟批量转让资产）→ 资产组包（打包+下发尽调）→ 尽职调查任务（上传/撰写尽调报告）→ 转让方案申请（一般/批量，多级审批+批复）→ 执行结果登记。

## 关键规则 / 字段 / 校验

### 批量转让备选库【主页 ZJJK00210771】
- 查询条件：备选库名称/合同编号/借据编号/客户编号/客户名称/流程状态；按经办过滤。
- 【修改】仅待处理；【收回】仅审查审批中（确认后状态回待处理）；【取消申请】仅待处理（确认删除）；【详情】只读。
- 新增【场景 FS00084821】【流程 AP_TRANS_ALTER】：备选库申请 → 备选库审核 → 备选库审查…（14 节点）。
- 任务页【ZJJK00211130】三步骤（基本信息/影像/签署意见）；暂存跳过借据非空校验。
- 方案基本信息【ZJJK00210759】：备选库项目编号为空自动生成（BXK+机构编号+8位随机数）；备选库名称、可行性分析必填。
- 新增借据【ZJJK00210758 + 弹窗 ZJJK00211390（"新增借据new-弹窗"，批量转让备选库/资产转让/以资抵债共用）】。
- 尽调报告【ZJJK00248158】复用尽调任务管理的报告组件。

### 资产组包管理【主页 ZJJK00210755】
- 查询：资产包名称（模糊）/已下发任务标志/组包日期；数据权限：总行或一级支行批转业务岗查本人组包数据，其他角色查本机构及下级。
- 新增【场景 FS00084888】任务页【ZJJK00210766】三页签（基本信息/借据信息/影像资料）。
- 基本信息【ZJJK00210769】：资产包编号为空自动生成（ZCB+机构编号+8位随机数）；债权总额/户数/借据数不可编辑（随借据联动）。
- 借据【ZJJK00210750 + 弹窗 ZJJK00211434 + 导入 ZJJK00211433】：支持 Excel 导入借据列表（选择文件解析校验后入包）、下载模板。
- 【修改】【删除】：已下发尽调任务的资产包不可修改/删除（提示"该资产包已下发尽调任务，不可…"）。
- 【下发尽调任务】：用户机构层级须总行或一级支行（二级支行提示"当前登录用户机构层级是二级支行，不允许下发尽调任务"）；已下发不可再次下发。

### 尽职调查任务管理【主页 ZJJK00210749】
- 查询：资产包编号/名称/流程状态/主办保全经理/下发机构/下发日期；保全经理仅查主办=本人的任务。
- 【处理】仅待处理可处理；【撤销】仅待处理（确认语："撤销任务后保全经理不可处理该任务，且本资产包内不可再次下发，是否确定撤销？"，状态→已撤销）。
- 处理【场景 FS00084889】【流程 AP_TRANS_DUEDIL】（37 节点表）：处置方案申请→审核→审查→…提交。
- 任务页【ZJJK00211204】：基本信息（只读，ZJJK00210748）/借据信息（可修改借据 ZJJK00211423：录入评估信息和预计收回金额）/尽职调查报告（ZJJK00248158：撰写【无匹配模板提示"没有匹配的模板"】/上传/模板下载/修改/查看/下载/删除）→ 影像 → 签署意见。
- 提交流程【ZJJK00210735】：流程角色 RL60323（总行组包批转业务员）/RL60325（一级支行组包批转业务员）。

### 转让方案申请 — 一般转让【场景 FS00084882】【流程 AP_TRANS_TRANSAPLY】
- 16 节点：处置方案申请 → 业务分发 → 处置方案审核 → 审查 → 审批 → …（含风险委员会秘书岗、有权审批人、最终有权审批人）。
- 任务页【ZJJK00210923】：三步骤；基本信息下五页签（基本信息/借据信息/担保合同信息/抵质押物信息/尽职调查报告）。
- 新增基本信息【ZJJK00210745】：方案编号/名称/处置类型（默认14转让）/转让基准日/债权总额及分项/债权第三方评估值/债权定价/预计收回金额分项 → 计算本息损失额与预计回收率；反委托标识=是时显示反委托客户经理（放大镜 → 弹窗 ZJJK00211329）。
- 借据信息【ZJJK00210743】新增/修改（ZJJK00211423 修改借据）/删除/三类详情。
- 担保合同【ZJJK00210787】保证/抵押/质押三列表 + 合同详情；抵质押物【ZJJK00211306】押品详情（新页签），最新认定价值小计/合计。
- 审批环节：
  - 总行风险委员会秘书岗【ZJJK00210510】：新增信用风险委员会审议结果【ZJJK00210544】（只读表，机构名称/审查日期/审查意见/意见详情）。
  - 总行有权审批人【ZJJK00210509】：含新增批复信息【ZJJK00156148JLCP + 弹窗 ZJJK00164003JLCP】（批复编号/日期/有效期/机构必填；已存在批复不可重复下发；取电子档案编号作为凭证编号）。
  - 最终有权审批人【ZJJK00210508】：含新增有权机构决议结果【ZJJK00210543 + 弹窗 ZJJK00211337】（有权机构 AUTH_INST 字典：01行办会/02董事会/03股东大会；支持新增/修改/删除）。
  - 中间审批任务页【ZJJK00210497】：审批按钮仅查看模式且流程节点不可编辑时展示。

### 转让方案申请 — 批量转让【场景 FS00084884】【流程 AP_TRANS_BATCHAPLY】
- 15 节点，同一般转让骨架；差异：基本信息须先选资产包（放大镜）与反委托客户经理，借据/担保合同/抵质押物/尽调报告按所选资产包归集；任务页【ZJJK00211045】。

### 执行结果登记（一般转让）【主页 ZJJK00210570】
- 角色：总行/一级支行组包批转业务员、保全经理（本人经办）；【执行登记】打开登记页面。
- 任务页：基本信息/借据信息/影像资料三页签，保存执行登记信息。
