# 章节：抵债资产管理

- **章节路径**：抵债资产管理（H1）
- **H2 小节**：总体描述 / 抵债申请 / 抵债登记 / 抵债资产基本信息 / 抵债资产日常管理 / 抵债资产处置方案申请 / 抵债资产处置执行登记

## 要点摘要
- **总体描述**：以资抵债业务全流程：抵债申请（方案审批）→ 抵债登记（执行结果登记、资产入账）→ 抵债资产基本信息（保管责任人）→ 日常管理（保管/处置/监盘/评估/租赁/收入/税费/保险/风险分类/盘点）→ 处置方案申请 → 处置执行登记。状态：草稿（可修改删除）、审批通过（可作为后续业务操作依据）。
- 抵债申请方案编号自动生成：`YZDZ`+机构编号+8位随机数；处置类型固定"以资抵债"。

## 关键规则 / 字段 / 校验

### 抵债申请【主页 ZJJK00210726】【场景 FS00084897】【流程 AP_DEBT_APLY】
- 查询：客户编号/名称/合同编号 + 更多（借据编号/方案名称/抵债资产名称/押品编号/抵债资产类型/流程状态）。
- 【修改】仅待处理；【收回】仅审查审批中（"请选择审查审批中的数据！"）；【取消申请】仅待处理；【下载批复】仅审批通过。
- 任务页【ZJJK00210854】三步骤；基本信息页签：基本信息、借据信息、担保合同、抵债资产基本信息、以资抵债合规性自查、预计税费、方案具体信息、尽职调查报告。
- 新增抵债资产【ZJJK00211301】：以资抵债基准日默认当前营业日期，不可选晚于已填基准日的日期。
- 新增借据【ZJJK00210718 + 修改借据 ZJJK00211402：预计抵偿本金/利息】。
- 新增抵债资产基本信息【ZJJK00210723】：是否我行押品/抵债资产编号/关联押品编号/资产分类/入账状态/取得方式/权属/评估信息/保管方式地址；押品引入链路（配置押品公共信息 ZJJK00211404 → 押品信息-以资抵债 ZJJK00211403）。
- 合规性自查【ZJJK00210722】：11 项是/否检查（禁止流通物、欠缴税费接近或高于资产价值、权属争议、伪劣变质残损、已抵押质押无剩余价值等），全部必填。
- 方案具体信息【ZJJK00210720】：税费测算/抵债方案/变现能力分析/变现计划/方案比较及合理性/处置计划说明/其他说明，均为必填文本域（≤4000 字）。
- 提交流程【ZJJK00210705】；审批任务页【ZJJK00210498】（审批按钮仅查看状态且流程禁用时展示；外部接口 IF00237558PDCP 授权规则计算）；最终审批【ZJJK00210499】+ 有权机构决议结果【ZJJK00210543/00211337】+ 批复【ZJJK00210542/00211336】。

### 抵债登记【主页 ZJJK00210739】【场景 FS00084887】
- 【执行登记】仅执行状态=执行中（"所选数据不支持执行登记操作"）。
- 任务页【ZJJK00211248】六页签：基本信息/抵债资产收取信息/抵债资产入账信息/借据信息/实际税费信息/影像资料。
- 【保存】校验必填项；**执行状态=执行完毕时，校验每笔借据的实际抵偿本金和实际抵偿利息均已录入**（"请录入借据信息列表每笔借据的实际抵偿本金、实际抵偿利息！"）。
- 收取信息【ZJJK00210690】：收取方式 apObtnModDict（1协议抵债/2法院仲裁裁决抵债/9其他）；法院裁决时法院裁定文号必填，协议抵债/其他时协议编号必填；协议编号自动去除小数点；收取日期不早于批复日期。
- 入账信息【ZJJK00210689】：首次入账金额/入账机构/内部账号（去小数点）/入账日期/抵债日期。
- 借据信息【ZJJK00210687 + 抵债登记_借据信息 ZJJK00244386：登记实际抵偿本金/利息】。
- 预计税费【ZJJK00210688 + 新增税费信息 ZJJK00211348】。

### 抵债资产基本信息【主页 ZJJK00210673】
- 查询：抵债资产编号/名称/方案编号/是否我行押品/入账状态/是否过户；方案仅显示审批通过的。
- 【分配保管责任人】→ 保管人查询【ZJJK00211383】（本机构及下辖已配置保管责任人角色且生效用户）；与当前保管人相同则提示"所选抵债资产管理人未变更，请检查！"。
- 【保管责任人变更记录】【ZJJK00211382】；【抵债申请详情】【抵债登记详情】【抵债资产详情】（权证押品基本信息 ZJJK00211334，只读）；【日常管理记录】【ZJJK00211381，盘点流水号可点开详情】。

### 抵债资产日常管理【主页 ZJJK00210663】【场景 FS00084842】【流程 AP_DEBT_JURSER】
- 【新增】先弹【引入抵债资产 ZJJK00211379】：仅可选入账状态=已入账且未被引用、处置状态≠已处置的抵债资产。
- 任务页【ZJJK00210651】三步骤；基本信息下九页签：保管信息、处置信息、监盘信息、评估信息、租赁信息、收入信息、实际税费、保险信息、风险分类。
- 保管信息【ZJJK00210661】：保管方式/保管机构/保管人/现时状态（debtAssetTp：01闲置/02出租/03自用/04他人自用…）。
- 处置信息【ZJJK00210662】：处置现状（debtAssetDispSituat 00未处置/01处置中…）、处置情况（debtAssetDispDesc 01不存在处置障碍/02无法处置）、是否可独立处置；处置情况=无法处置时"无法处置原因"变必填（字段联动）。
- 盘点信息【ZJJK00210656】：法律风险/物理风险/实物瑕疵（有瑕疵须选瑕疵情况 01轻微损坏/02严重损坏）；**账面价值 = 入账金额 + 抵债资产增值金额 − 抵债资产贬值金额**（空按零）。
- 收入信息【ZJJK00210655 + ZJJK00211375】：收入一级分类联动二级分类。
- 外部评估【ZJJK00210660 + ZJJK00211377】、租赁信息【ZJJK00210658 + ZJJK00211376】、保险信息【ZJJK00210653 + ZJJK00211374】、费用【ZJJK00210654】、风险分类【ZJJK00210652 + ZJJK00211373】。
- 提交流程【ZJJK00210650】（监盘人/保全副行长/总行总经理可流程提交）；审批任务页【ZJJK00244412】。
- 【处理】仅待处理；【收回】仅审查审批中（"确认是否收回？不可撤销"）；【取消申请】仅待处理。

### 抵债资产处置方案申请【主页 ZJJK00210659】【场景 FS00084885】【流程 AP_DEBT_DISAPLY】
- 主页按钮：新增/修改（仅待处理）/收回（仅审查审批中）/取消申请（仅待处理）/详情/下载批复（仅审批通过）。
- 任务页【ZJJK00211238】：基本信息（基本信息/抵债资产基本信息/抵债资产费用信息/买受人情况及付款方式/抵债资产处置方案说明）、影像、签署意见。
- 新增基本信息【ZJJK00210665】：方案编号自动生成 `YZDZCZ`+机构编号+8位随机数；处置类型固定"抵债资产处置"；转让基准日不可选当天及之后；转让方式 transfMethodTp（01拍卖/02竞标/03竞价转让/04协议转让…），选其他须填写。
- 抵债资产选择弹框【ZJJK00211349】：已入账且未处置；修改抵债资产基本信息【ZJJK00211350】（评估机构/评估日期/评估价值/认定价值）。
- 买受人【ZJJK00210649】：买方是否我行关联人=是时须填关联关系描述；预计付款方式必选，一次性付款时预计付款时间必选。
- 处置方案说明【ZJJK00210664】：历史沿革及现状/处置定价情况/处置方案/预期收益情况/未采取公开转让方式的原因/方案合理性与必要性分析，全部必填。
- **流程启动前置校验**：①方案须已关联抵债资产基本信息（"未选择抵债资产基本信息，请录入完整信息后提交！"）；②处置抵债资产前本息损失金额非空且绝对值≥0（"处置抵债资产前，请先发起日常管理登记。"）。
- 流程结束自动创建处置执行登记信息。

### 抵债资产处置执行登记【主页 ZJJK00210590】
- 查询：抵债资产编号/名称/执行状态（execStDict：01执行中/02执行完毕/03方案废止…）。
- 【执行登记】仅执行中；录入执行状态、执行登记情况、交易对手信息、抵债资产处置收回情况，保存后更新抵债资产处置状态。
