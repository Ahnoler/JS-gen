# 章节：不良资产日常管理

- **章节路径**：不良资产日常管理（H1）
- **H2 小节**：总体描述 / 移交管理 / 全辖管理业务 / 我的业务 / 不良资产保全经理变更

> SUT 实测 2026-09-06（structure，菜单口径，全模块通则）：SUT 一级菜单「资产保全」下**无「不良资产日常管理/不良资产转让管理」中间层**，实际分组为 移交管理 / 日常管理（全辖业务管理/我的业务/资产保全经理变更）/ 资产转让 等；SUT 另多出文档未收录分组（资产重组/债权减免/台账查询/核销管理/司法诉讼）。以下各页均存在，一一对应。

## 要点摘要
- **总体描述**：为资产保全业务人员提供审批、查询、新增、关联、处置等功能。业务流程图"无"。
- **移交管理**：客户出现高风险时，业务经营部门（个贷/对公等条线）可将资产移交给资产保全条线专门管理；保全条线可采取诉讼、减免、债权转让、债务重组、以资抵债等清收处置手段；客户经营改善时可逆移交回业务条线。移交后原经办人仍负责贷后检查、风险预警，保全经理负责组织和发起清收处置措施。客户经理兼职保全经理需在系统管理模块先配置保全经理角色，正移交审批通过后由各级业务分发综合岗分发至保全经理。
- **全辖管理业务**：面向总行/总部资产保全部门，全辖范围不良资产统一管理，覆盖资产入库、过程跟踪、处置执行到财务核销全生命周期，含客户/合同/担保/还款多维视图。
- **我的业务**：保全经理查看自己管辖的不良资产，可看客户/合同/借据详情、保全责任认定、关联担保合同、还款流水确认、处置情况、处置督办信息。
- **保全经理变更**：查询借据、指定主办/协办保全经理、查看主协办信息及变更记录。

## 关键规则 / 字段 / 校验
### 移交管理主页【ZJJK00248197PDCP】
- 页面初始化以「业务类型=移交(10)」为固定查询条件。
- 数据权限：客户经理/保全经理/业务综合员查本人经办；总行综合员/查询员查当前法人行全部；中心支行/一级支行查本机构及下级。
- 【修改】：仅流程状态=待处理可改；移交类型=业务上收时打开业务上收页面，否则打开移交申请详情。
- 【收回】：仅审查审批中可收回，二次确认"确认是否收回？不可撤销"。
- 【取消申请】：仅待处理可取消；若已启动审批流程则先终止流程。

### 移交类型（transferTypeDict）：01 正移交 / 02 逆移交 / 03 内部移交 / 04 业务上收

> SUT 实测 2026-09-06（structure）：任务页「移交类型」下拉实测仅 正移交/逆移交/内部移交 三项（X0023 角色），**无「业务上收」选项**——业务上收在移交主页为独立【业务上收】按钮直达（FS00108608，aplyTp=04），与文档「04 业务上收是移交类型之一（按角色可选）」口径不同。
- **正移交【场景 FS00084861】【流程 AP_HDVMAN_HDVAPLY】**：节点为 客户经理 → 二级支行行长审批 → 发起方业务审核 → 保全业务审核员 → 保全业务审查…（审批流选人模式）。
- **内部移交【FS00084831】【AP_HDVMAN_INAPLY】**：客户经理发起；内部移交且当前用户为一级分支行时接收机构不可选本机构（提示"请移交至其它一级分支机构"）。
- **逆移交【FS00084833】【AP_HDVMAN_REVERSEAPLY】**：保全经理发起，多级保全条线审批；逆移交时隐藏接收机构字段。
- **业务上收【FS00108608】【AP_HDVMAN_COLLAPLY】**：资产保全业务综合员 → 总行资产保全部总经理 → 总行副行长（保全）审批。
- 任务页（ZJJK00210826/00210638/00210640/00248183 等）：基本信息(四页签：基本信息/借据信息/担保合同信息/抵质押物信息) → 影像信息 → 签署意见 三步骤；【暂存】不校验必填（保存流程状态=待处理、有效标志=是、申请日期=当前）；【保存】校验必填项（提示"请检查表单中的必填项"）。
- 新增基本信息【ZJJK00210788】：申请流水号为空时自动生成（YJ+机构编号+8位随机数）；根据角色设置移交类型可选范围。

> SUT 实测 2026-09-06（wording）：申请流水号实测 `YJ988165457633` = YJ+机构编号(9881)+**12 位**序列，文档口径「8 位随机数」与实测位数不符。
- 新增借据【ZJJK00211654 弹窗】：正移交时以当前登录人为经办人实时查询【用信放款】模块全量借据（含结清/未结清）。
- 移交-责任认定【ZJJK00211655】：责任认定 prsrvtRsidDict：01认定有责/02认定无责/03未认定/04认定中；上传保全认定文件影像。

> SUT 实测 2026-09-06（wording/structure，叶9）：责任认定弹窗选项实测仅 **3 个——认定有责/认定无责/未认定**，文档 04「认定中」未见于 SUT；右侧含保全认定文件影像资料列表（与文档影像上传口径一致）。
- 提交流程审批【ZJJK00210742】：流程启动前校验借据已选择（"未选择借据信息，请录入完整信息后提交"）→ 智能控制方案校验 → 选人校验（防重复审批人）。**流程结束副作用**：
  - 正移交通过：方案内借据纳入基础管理，借据所属机构更新为接收机构，新增主办保全经理变更记录（变更类型=正移交），更新用信借据移交状态=已移交并清空保全经理。
  - 逆移交通过：借据移交标志=未移交并清空保全经理，新增主办变更记录（逆移交），更新协办变更记录移除信息，借据移交状态=未移交。
- 影像资料【ZJJK00211311 + 公共影像组件 ZJJK00100615】：操作权限级别须 7 位且仅含 0/1/*；查看状态权限=查看+打印，否则全部开启。

### 全辖管理业务
- 主页【ZJJK00211276】：借据列表查询，汇总模式下对借据金额、剩余本金、正常利息、逾期利息、本金罚息、利息罚息、罚息罚息合计（合计行追加列表末尾）。

- 还款记录【ZJJK00210738】：调核算系统 UCMP01050006 还款流水查询，与已确认记录合并展示；【还款类型】确认时已确认流水提示"所选还款流水记录已确认，不可再次确认！"。确认弹窗【ZJJK00211430】选择还款处置类型（repayAstPsvbsnTpDict）后确认，记录确认人/确认日期=当前营业日期。

- 处置督办信息【ZJJK00211429】：按借据查督办记录，创建时间倒序。
- 上传税前扣除凭证【ZJJK00211544】：须已核销（未核销提示"所选数据未核销，无需维护是否税前扣除状态！"）；确认后更新税前扣除标志并更新销账日期=当前营业日期。
- 移出备选库：按备选库标识分组，全部不在备选库时提示"…不在备选库，无需移出！"。
- 补充责任认定【ZJJK00211543】：责任认定必填，二次确认后更新借据责任认定。
