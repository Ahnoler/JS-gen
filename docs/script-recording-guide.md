# 操作手册 — 录制脚本输入规范

## 一、提交前自检清单

每次提交录制任务前，逐项确认以下内容：

- [ ] 目标页面的完整 URL 已提供
- [ ] 是否需要登录（是 / 否，若需要则提供账号密码）
- [ ] 每个操作步骤已编号
- [ ] 字段的取值已明确（具体值 / 自动生成 / 暂不确定）
- [ ] 特殊字段（手机号、身份证等）已标注是否需要随机生成
- [ ] 期望的验证方式已说明

---

## 二、标准输入模板

```
【目标URL】
http://xxx:port/#/path

【登录信息】（可选，已有登录态可不填）
账号：admin
密码：123456

【操作步骤】
1. 点击 "新增" 按钮
2. 填写 "客户名称" → [具体值: "XX科技有限公司"]
3. 填写 "联系电话" → [自动生成]
4. 选择 "客户类型" → "企业客户"
5. 选择 "客户状态" → "正常"
6. 填写 "备注说明" → [暂不确定，后续补充]
7. 点击 "确定" 提交

【验证要求】
期望：提交成功后弹出"操作成功"提示
```

## 三、填写规则

### 3.1 URL

> 必须是完整路径，包含协议、端口、query 参数。

| 正例 | 反例 |
|------|------|
| http://10.1.2.3:8080/#/order/manage | 订单管理页 |
| http://localhost:9200/#/login?redirect=%2Fhome | 登录后那个页面 |

### 3.2 操作步骤

> 每条一步，使用"动词 + 目标 + 取值"结构。

| 元素类型 | 动词 | 格式 | 示例 |
|----------|------|------|------|
| 按钮 | 点击 | 点击 "按钮文字" | 点击 "新增" |
| 输入框 | 填写 | 填写 "字段名" → [取值模式: 具体值] | 填写 "客户名称" → [具体值: "张三"] |
| 输入框(敏感字段) | 填写 | 填写 "字段名" → [自动生成] | 填写 "手机号" → [自动生成] |
| 输入框(待确认) | 填写 | 填写 "字段名" → [暂不确定] | 填写 "备注" → [暂不确定] |
| 下拉框 | 选择 | 选择 "字段名" → "选项文字" | 选择 "客户类型" → "企业客户" |
| 日期选择器 | 选择日期 | 选择日期 "字段名" → YYYY-MM-DD | 选择日期 "有效期" → 2030-12-31 |
| 单选/复选 | 选择 | 选择 "选项名" | 选择 "是否长期有效" |
| 级联选择器 | 级联选择 | 级联选择 "字段名" → 一级 > 二级 > 三级 | 级联选择 "所在地区" → 湖南省 > 长沙市 > 岳麓区 |

### 3.3 字段取值模式

| 模式 | 写法 | 含义 |
|------|------|------|
| 具体值 | → [具体值: "XX公司"] | 每次都用这个固定值 |
| 自动生成 | → [自动生成] | 系统随机生成合法值 |
| 暂不确定 | → [暂不确定] | 先留空，事后再补 |

### 3.4 非标准可点击元素

> 页面上有些可点击区域不是按钮、不是链接，而是自定义卡片、步骤节点、圆形进度条等。它们的 DOM 结构复杂（嵌套多层 div / svg），AI 无法像标准按钮一样自动识别。

对此类元素，必须在步骤中**额外描述元素的外观特征**，帮助 AI 定位。

#### 格式

```
点击 [元素类型]：其中包含文字 "[显示文本]"
```

| 元素类型 | 写法示例 |
|---------|---------|
| 步骤节点 | 点击 步骤节点：其中包含文字 "测试案例" |
| 卡片 | 点击 卡片：其中包含文字 "对公客户管理" |
| 进度条项 | 点击 进度条项：其中包含文字 "已完成" |
| 列表条目 | 点击 列表条目：其中包含文字 "信贷潜在客户" |
| 标签页 | 点击 标签页：其中包含文字 "基本信息" |
| 面包屑 | 点击 面包屑：其中包含文字 "客户管理" |

#### 为什么需要额外描述

```
<!-- 用户看到的 -->
┌──────────────────────┐
│  ✓ 测试案例           │  ← 看起来是个卡片/步骤，点击可跳转
│     已完成            │
└──────────────────────┘

<!-- 实际 DOM 是 -->
<div class="execution-steps-item">     ← 最外层 div
  <div class="progress">               ← 进度圈
    <svg>...</svg>                     ← SVG 圆环
    <span><i class="icon-duigou"></i></span>
  </div>
  <div class="content">
    <div class="title">测试案例</div>   ← 文字在这里
    <div class="desc">已完成</div>
  </div>
</div>
```

AI 看到这段 DOM 时，无法判断它是一个可点击的"步骤"。只有告诉 AI "这是一个步骤节点，里面写着测试案例"，AI 才知道要通过文字匹配找到 `.execution-steps-item`，然后对该容器执行 click。

#### 正误对比

| 不规范 | 问题 | 规范 |
|--------|------|------|
| 点击 "测试案例" | 文字不在 button/a 标签内，AI 找不到 | 点击 步骤节点：其中包含文字 "测试案例" |
| 点一下测试案例那个圈 | 描述了视觉但未指明元素类型 | 点击 步骤节点：其中包含文字 "测试案例" |
| 点进度条 | 太模糊，页面上可能有多个进度条 | 点击 进度条项：其中包含文字 "已完成" |

## 四、语义描述规范

### 4.1 字段名和按钮名 → 直接抄页面原文

> 用页面 label 的原文。不要意译或缩写。

| 页面上的文字 | 规范写法 | 不规范写法 |
|-------------|----------|-----------|
| 法定代表人手机号码 | 填写 "法定代表人手机号码" → [自动生成] | 写个法人电话 |
| 实际控制人证件号码 | 填写 "实际控制人证件号码" → [自动生成] | 填控制人身份证 |
| 登记注册失效日期 | 选择日期 "登记注册失效日期" → 2040-01-15 | 选失效时间 |

### 4.2 选项值 → 抄下拉菜单的完整文字

| 下拉菜单选项 | 规范写法 | 不规范写法 |
|-------------|----------|-----------|
| 信贷潜在客户 | 选择 "客户状态" → "信贷潜在客户" | 选第一个 |
| 有限责任公司(法人独资) | 选择 "企业类型" → "有限责任公司(法人独资)" | 选独资公司 |

### 4.3 禁止指代模糊

| 禁止 | 改为 |
|------|------|
| 填完所有必填项 | 逐条列出每个必填字段及取值 |
| 和上次一样操作 | 重新完整描述所有步骤 |
| 把那个也填一下 | 明确字段名称 |
| 下面那个 / 上面那个 | 直接写字段名 |

## 五、完整示例

### 示例一：最简场景

```
【目标URL】
http://10.1.2.3:8080/#/user/manage

【操作步骤】
1. 点击 "新增用户"
2. 填写 "用户姓名" → [具体值: "李四"]
3. 填写 "手机号码" → [自动生成]
4. 选择 "所属部门" → "技术部"
5. 点击 "确定"
```

### 示例二：含登录和验证

```
【目标URL】
http://10.1.2.3:8080/#/order/manage

【登录信息】
账号：701994
密码：1

【操作步骤】
1. 登录系统
2. 点击 "新增订单"
3. 填写 "订单编号" → [自动生成]
4. 填写 "客户身份证" → [自动生成]
5. 填写 "订单金额" → [具体值: "50000.00"]
6. 选择 "订单状态" → "待审核"
7. 点击 "暂存"
```

## 六、常见错误对照

| 用户输入 | 问题 | 应改为 |
|---------|------|--------|
| 把表单填一下 | 缺 URL、缺字段、缺取值 | 按模板逐条列出 |
| 填个身份证 | 缺字段名，无法定位 input | 填写 "证件号码" → [自动生成] |
| 选第一个下拉选项 | 文字对不上 | 打开下拉截图选项文字，原样抄下 |
| 姓名字段填 test | 中文名字段填英文 | 填写 "姓名" → [具体值: "张三"] |
| 电话填 123 | 位数不够，必报验证错误 | 标注 [自动生成] 让系统生成合法值 |
| 点那个蓝色按钮 | 颜色描述无法定位 DOM | 抄按钮上的原文：点击 "暂存" |
| URL 就是首页 | 不可用 | 提供完整地址 |
| 和上次的一样 | 无上下文 | 重新完整描述 |
