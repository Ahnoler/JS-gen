> 依据：Opencode 产出《产品要素管理 — 原子交易操作步骤》TX-01～09  
> 相对 Opencode 原稿的关键差异：**删除每笔交易开头的菜单导航步**（系统自动导航）；步骤从功能页内开始。

> 页面：分组主页 ZJJK00094373、新增类型/组件弹窗 ZJJK00094374、要素主页 ZJJK00094375、新增/修改要素弹窗 ZJJK00094376  

## 模块级布局契约（注入一次即可，不要每笔复制）

**左侧**：搜索框占位「搜索关键字」+ 放大镜；树根「产品公共要素」「产品个性化要素」；节点行右侧「+」(悬停「新增类型」/「新增组件」)、「−」(悬停「删除」)。  
**右侧**：选中类型节点 → 仅「基本信息」；选中组件节点 → 「基本信息」+「产品要素」。  
**产品要素页签**：查询区（组件要素编码/名称，占位「请输入」，【查询】【重置】）；【新增】【修改】(蓝)、【删除】(红)；列表列含单选、要素编码、要素名称、所属列表要素编码、要素类型、数据字典、数据组。

## Atom A — 新增产品要素组件

```text
1、点击左树节点「产品公共要素」
2、断言：节点高亮；该行右侧出现「+」图标（悬停提示「新增组件」）；右侧显示「基本信息」页签
3、点击「产品公共要素」行右侧「+」图标
4、等待弹窗标题「新增产品要素组件」出现
5、校验「组件编号」已自动生成且不可编辑
6、在「组件名称」（必填）输入：{{componentName}}
7、校验「组件类型」显示「产品公共要素」且不可编辑
8、点击弹窗【保存】
9、断言：操作成功提示；弹窗关闭；左树「产品公共要素」下出现「{{componentName}}」并默认选中；右侧出现「基本信息」「产品要素」页签

来源：<sourceDoc> / <sourceChapter>

关键数据：
组件名称：{{componentName}}
```

异常：名称为空点【保存】→ 提示「必填字段不能为空！」且弹窗保留。

## Atom B — 新增产品要素类型

```text
1、点击左树节点「产品个性化要素」
2、断言：节点高亮；行右侧「+」悬停提示「新增类型」；右侧仅「基本信息」页签
3、点击该行右侧「+」图标
4、等待弹窗标题「新增产品要素类型」出现
5、校验「组件分类编号」已自动生成且不可编辑
6、在「组件分类名称」（必填）输入：{{typeName}}
7、校验「组件类型」显示「产品个性化要素」且不可编辑
8、点击弹窗【保存】
9、断言：操作成功；弹窗关闭；左树出现子节点「{{typeName}}」并默认选中

来源：<sourceDoc> / <sourceChapter>

关键数据：
组件分类名称：{{typeName}}
```

## Atom C — 查询产品要素分组

```text
1、确认左树完整可见（含「产品公共要素」「产品个性化要素」）

3、点击搜索框右端放大镜（或回车）
4、断言：树仅显示名称含「AI测试」的节点及其祖先
5、清空搜索框
6、断言：树恢复显示两个根节点

来源：<sourceDoc> / <sourceChapter>

关键数据：
搜索关键字：AI测试
```

## Atom D — 保存产品组件基本信息

```text
1、点击左树「产品公共要素」下节点「{{componentName}}」
2、断言：右侧「基本信息」显示组件编号（只读）、组件名称「{{componentName}}」、序号

4、输入新名称：{{componentNameRenamed}}

6、断言：操作成功；左树该节点名称变为「{{componentNameRenamed}}」
7、校验：「组件编号」仍不可编辑

来源：<sourceDoc> / <sourceChapter>

关键数据：

新组件名称：{{componentNameRenamed}}
```

## Atom E — 查询产品要素

```text
1、点击左树组件节点「{{componentNameRenamed}}」（若未改名则用「{{componentName}}」）
2、点击右侧「产品要素」页签
3、断言：出现查询区与【查询】【重置】【新增】【修改】【删除】及列表表头
4、在「组件要素名称」（占位「请输入」）输入：{{dataItemKeyword}}
5、点击【查询】
6、断言：列表仅显示名称匹配行，或「共 0 条」与输入一致
7、点击【重置】
8、断言：两查询框恢复占位「请输入」；列表恢复该组件下全部要素

来源：<sourceDoc> / <sourceChapter>

关键数据：
组件要素名称关键字：{{dataItemKeyword}}
```

## Atom F — 新增产品要素

```text
1、点击左树组件节点「{{componentNameRenamed}}」
2、点击「产品要素」页签
3、点击【新增】（蓝色）
4、等待弹窗标题「新增产品要素」出现
5、点击「要素名称」下拉（远程搜索），输入：{{dataItemKeyword}}
6、在下拉中选择约定数据项
7、断言：「要素编码」自动填入且不可编辑；若有关联字典则「数据字典」自动填入
8、点击「要素类型」下拉，选择「文本」
9、断言：「数据字典」「字典组」「选项范围」不显示
10、点击弹窗【确定】
11、断言：操作成功；列表新增一行，要素名称=约定数据项、要素类型=文本、编码=步骤7自动值

来源：<sourceDoc> / <sourceChapter>

关键数据：
要素名称关键字：{{dataItemKeyword}}
要素类型：文本
```

## Atom G — 修改产品要素

```text
1、点击左树组件节点「{{componentNameRenamed}}」
2、点击「产品要素」页签
3、点击目标要素行（行首单选或单元格）使行选中
4、点击【修改】（蓝色）
5、等待编辑弹窗出现且预填要素类型=文本
6、将「要素类型」改为「数字」
7、点击【确定】
8、断言：操作成功；列表该行「要素类型」=数字

来源：<sourceDoc> / <sourceChapter>

关键数据：
目标要素：TX-07 新增行
新要素类型：数字
```

异常：未选中行点【修改】→ 提示「请选择一条数据！」

## Atom H — 删除产品要素

```text
1、点击左树组件节点「{{componentNameRenamed}}」
2、点击「产品要素」页签
3、选中目标要素行（要素类型=数字）
4、点击【删除】（红色）
5、等待确认框（文案含删除确认）
6、点击确认框【确定】（或「确认」）
7、断言：操作成功；列表中该行消失

来源：<sourceDoc> / <sourceChapter>
```

## Atom I — 删除产品要素分组

```text
1、点击左树「产品个性化要素」下子节点「{{typeName}}」
2、断言：行右侧出现「−」（悬停「删除」）
3、点击该行「−」
4、等待确认框「确认删除记录信息?」（以实际文案为准）
5、点击【确定】（或「确认」）
6、断言：删除成功；「{{typeName}}」节点消失；父节点「产品个性化要素」选中

来源：<sourceDoc> / <sourceChapter>

关键数据：
待删类型名称：{{typeName}}
```
