Update `tableFieldXpathSmartOf` for synthetic anchors:

```javascript
const tableFieldXpathSmartOf = (rowText, controlEl, occurrence) => {
    const rowT = normalizeControlText(rowText);
    if (!rowT || !controlEl) return '';
    // ... existing leaf / scopeKind selection unchanged ...
    let local;
    const syn = /^row#(\d+)$/.exec(rowT);
    if (syn) {
        /* SOURCE_B_ROW_INDEX_XPATH */
        const idx = syn[1];
        local = "(tbody/tr)[" + idx + "]//" + leaf;
    } else {
        const lit = xpathLiteral(rowT);
        local = "tr[.//*[normalize-space()=" + lit + "]]//" + leaf;
    }
    let xp = scopedXPath(local, scopeKind);
    const n = Number(occurrence) || 0;
    if (n > 1) xp = withOccurrence(xp, n);
    return xp;
};
```

**Implementer note:** Match `scopedXPath` / table-relative pattern already used for text rows; synthetic path must resolve to the N-th body `tr` under the same table/scope. Keep markers `SOURCE_B_EMPTY_LEADING` and `SOURCE_B_ROW_INDEX_XPATH`. Do **not** leave `if (!rowText) continue`.
