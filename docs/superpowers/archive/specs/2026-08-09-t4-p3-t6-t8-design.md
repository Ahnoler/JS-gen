# Design: T4-P3 — Source B empty-row naming (T6) + CTRL selectOption lazy-load (T8)

**Date:** 2026-08-09  
**Status:** Implemented — plan at `docs/superpowers/plans/2026-08-09-t4-p3-t6-t8.md`  
**Backlog:** T4-P3 (subset **T6 + T8** only)  
**Related:** Source B `SCAN_SOURCE_B_EL_TABLE`；`scan_editable_summary` (T4-P0/P1)；Agent `JS_SELECT_OPTION` / `SELECT_LAZY_LOAD_ON_MISS`；assembled `CTRL.selectOption`

## Problem

1. **T6:** Source B skips entire rows when `getRowLeadingText` is empty (`if (!rowText) continue`), so editable cells in empty-leading rows never enter the inventory / summary.
2. **T8:** Agent live select already load-on-miss scrolls dropdown wraps; `CTRL.selectOption` (`src/ctrl-actions/select.js`) still opens + `setTimeout(200)` and matches only the first pool — assembled replay can miss long / lazy lists.

## Goals

1. Empty-leading `el-table` rows still yield classified controls in Source B (and thus `scan_editable_summary`).
2. Display names stay deterministic: prefer col header / placeholder; else synthetic `row#N|#k`.
3. Weak synthetic names are left for the **main Agent** to interpret from business + page-structure summary — **no LLM call inside scan**.
4. Port Agent miss→stable-scroll→rematch policy into **both** CTRL select paths (label + placeholder), with characterization cues.
5. Record post-T4 follow-up: fix `save_form_snapshot` replay (currently fails / Type-B painful) — **out of this cut**.

## Non-goals

- T5 non-`el-table` grids
- T1r tree / replay label fallbacks
- T4-P4 MCP a11y
- Extracting a shared JS module for Agent↔CTRL select (dual copy OK this cut)
- Making `CTRL.selectOption` `async` / changing success string conventions (`ok-triggered*`)
- Typeahead / remote filter selects
- Changing Agent `JS_SELECT_OPTION` behavior
- Implementing `save_form_snapshot` replay repair in this slice

## Architecture

### T6 — Source B

```
SCAN_SOURCE_B_EL_TABLE
  for each body row (skip pager):
    rowText = getRowLeadingText(row) || ('row#' + visibleRowIndex)
    // NEVER skip solely because leading cells are empty
    for each collectTableControls(row):
      displayName = buildTableDisplayName(rowText, …)  // rowText|col|ph|#k
      xpath_smart = tableFieldXpathSmartOf(rowText, el, occurrence)
        // when rowText is synthetic row#N: locate by stable row index / position,
        // not by empty cell normalize-space text
```

**Rules**

1. Visible body row index `N` is 1-based among rows that pass pager/visibility filters used today.
2. `buildTableDisplayName`: if `!rowT` return `''` today — after change `rowT` is never empty when we reach it (synthetic guaranteed).
3. Prompt (`agent-tools-form.md` or table tools): note that labels like `row#3|金额` are machine anchors; Agent may map to business names using scene/summary — still operate via xpath / recorded tools, not by renaming scan output in-place this cut.

### T8 — CTRL `selectOption`

```
open dropdown (unchanged)
setTimeout pick:
  match pool
  on miss → SELECT_LAZY_LOAD_ON_MISS
    findWrap(dropdown)  // __wrap / scrollbar / overflow scrollable
    ≤8 rounds: scrollTop = scrollHeight; wait; rebuild pool
    stop when scrollHeight + option count unchanged for 2 rounds
    rematch
  click if hit (same as today)
```

Apply to **both** form-item label loop and placeholder fallback loop.

Caps / cues mirror Agent: ≤8 rounds, `stableStreak >= 2`, marker comment `SELECT_LAZY_LOAD_ON_MISS`.
