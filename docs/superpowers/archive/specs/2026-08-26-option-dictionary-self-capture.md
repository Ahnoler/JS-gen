# 下拉选项码值字典自采集（页面自采） Spec

> 日期：2026-08-26
> 状态：**挂起**——已完成澄清与设计，评估通过后再执行；当前非重点
> 关联：2026-08-26-message-capture-elk-validation.md（回填验证）、sut-three-interfaces.md（三接口契约）

## 1. 需求澄清结论

1. **问题**：报文 requestBody 中下拉字段为码值（diffplcCstInd=0、hldgEcnTp=B0102、oprtSt=01），页面展示为中文文案；回填必须做 码值→文案 转换。
2. **信贷系统开发人员无法提供转换表**（业务字典各自维护，无统一接口）。
3. **本项目自行解决**：页面下拉选项即字典源——已实证（2026-08-26 真机）目标页面下拉选项为标准 Element UI ElOption 组件，每个 li 的 Vue 实例 `$props` 含 {value(码值), label(文案)}：
   - 实测 diffplcCstInd 下拉 → 采集到 {\"0\":\"否\",\"1\":\"是\"}，按码值 0 点击后表单显示「否」
4. **决策**：采用「页面自采字典」方案（首选），录制反推与 AI 推断仅作兜底。

## 2. 目标 / 非目标

### 目标
1. 录制/扫描时采集**字段级 码值↔文案 字典**：打开下拉 → 读所有 li 的 $props 的 value/label/disabled → 缓存（会话内 + 可持久化到本地字典产物）；
2. 回填阶段：报文码值 → 字典 label → 点击对应选项（精确匹配 value）；
3. 无字典字段：按 label 文本模糊匹配，并标注「码值未验证」。

### 非目标
- 不依赖信贷人员提供转换表 / 字典接口；
- 不改三接口契约（接口一/二内容不变）；
- 不做全局字典持久化数据库（先会话/文件级）。

## 3. 关键实现点（后续执行时细化）

| 点 | 说明 |
|----|------|
| DOM 入口 | 目标页面为 Element UI（Vue2），选项 li.__vue__.$props 可取；custom-select-dropdown 仅外层样式，底层仍是 ElOption（已实证） |
| 采集时机 | 展开下拉瞬间；需等待选项渲染稳定（懒加载接口返回），否则重试 |
| 缓存 | {prop: {value: label}}；会话内存 + 落地为本地 JSON（scripts/log-extract/option-dicts/ 或随 form snapshot） |
| 回填匹配 | 报文码值 → 精确查字典 → 点击；查不到 → label 匹配 → 查不到 → 未填+标注 |
| 兼容 | 仅对 el-select/ElOption 生效；树选择器(行业代码)走既有的树选择 action 与兜底文案 |

## 4. 验收标准（将来执行时）

1. 对公客户管理页面：可展开下拉的字段 字典采集覆盖率 100%；
2. 有字典字段：码值→选项 回填命中率 100%；
3. 无字典字段：回填标注「码值未验证」；
4. characterization pin 采集/匹配纯函数；verify-all ALL GREEN。

## 5. 风险

| 风险 | 对策 |
|------|------|
| 下拉选项懒加载 | 采集前轮询选项数量稳定（2 次相同） |
| 虚拟滚动只渲染部分选项 | 当前页面选项规模小；后续可加滚动采集（记录风险） |
| Vue3/非 Element UI 项目 | 检测 li.__vue__.$props 缺失时降级为 label 文本匹配 |
