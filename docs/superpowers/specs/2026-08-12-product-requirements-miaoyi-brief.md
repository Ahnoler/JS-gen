## 已锁定

### PR-LOC 录制定位 / 整页 stitch
- **现在做**：长页滚动拼接成一张整页长图（stitch）。
- **触发**：每次录制停止 / 阶段结束自动生成 **1** 张。
- **归属**：绑定 **phase**（与 step 级 screenshot 不同）。
- **存储**：`trajectory_phase` 新字段（如 `stitchScreenshotId` / URL）。
- **以后做**：操作**完成之后**，按页上操作元素高亮再截图（步骤级；挂起）。

### PR-PART 元素分区
- 完善现有元素分区算法（同页同名可区分）。
- 工程主线：unify-partition / L1c / picker / regionAnchor / 1448067。

### PR-LAYER 元素分层
- **排在分区之后**。
- 产品树效果：`页面` → `tab页签` / `步骤向导面板` / `弹窗` →（可选）`功能分区` → 控件叶（类型标签 +「输入/点击 …」）。
- 效果图已附（对话资产）；细规则可再开 design。

### PR-DATA 数据捞取
- **非消费型**：可重复提交、不因「已使用」失效的字段值（姓名、证件号样例等）；排除验证码、一次性 token。
- **目录来源**：被测系统开发提供的**静态配置**（我们只消费）；元素结构含 `{name, prop, url}`；接口元数据含方法/地址/入参/出参。
- **流程**：页面 URL → 页面元素 → 触发接口元数据 → AI 分析当前分区表单对应接口 → 按接口地址捞历史报文。
- **用法/时机**：AI 录制过程中**动态**捞取；走现有 **软文本**（case-data / Agent·助手）填写路径。

### PR-BATCH 批量导入增强（原「交易列表加任务」）
- 前端现状：简单 summary（共 N / 受理 / 草稿 / 录制 / 失败）+ 行状态；见 Vue `BatchImportDialog` / `batchImport` store。
- **缺口**：
  1. 每个用户只能看自己的任务（与 PR-USER 交易隔离同源）。
  2. 按行进度条。
  3. Agent 结束 phase 的 **done 说明** → 写入该阶段 **`trajectory_log` 数组**。

### PR-USER 用户 / 系统树（规则已述，权限源挂起）
- 系统树可共享可见。
- 交易仅本人可见。
- 仅管理员可删系统树；其他人可增改。

### PR-SSO 产品登录（协议已述，管理员映射挂起）
- 对接公司账号中心 **HTTP API**（用户名密码或 token 换本产品会话）。
- **管理员如何映射**：见下方挂起项（等会议）。

### PR-PUSH 推送到自动化
- **已完成**（草稿不可推；`recorded`/`completed` 可推）。

### PR-EXEC 脚本执行
- **挂起**。本侧只提供浏览器操作与设计（回放 + browser-use 注册 actions）；执行引擎/执行机调度暂不排。

6. **PR-SSO / PR-USER** 等 **PR-SSO-ADMIN** 会议结论后再 design
