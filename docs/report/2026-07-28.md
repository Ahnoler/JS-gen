## 主要事项

1. 空案例数据时跳过写库；缺 trajectory_id 列时按「未配置」处理，不报错。
2. Add remote_session idle/bindings migration and multi-traj lifecycle acceptance smoke.
3. 按交易隔离 BiB 推流，并支持 stream/detach 只断画面不关浏览器。
4. 推流后画布无法操作，多交易隔离后，点击走 remote:input 必须能解析到对应执行机会话；但点击没带 trajectoryId，服务端 resolveExecutorPick 回退又是空的。推流仍由 prepare 的 bib_start 广播，所以会出现「能看不能点」。另外无范围的 remote:status 还可能把画布误锁成「仅观看」。 已修 控制面：补全 resolveExecutorPick（traj 绑定 → sessionId → runtime）；点击路由带 traj/session；bib_input 去掉路由字段 前端：所有 remote:*（含鼠标/键盘）带上 trajectoryId/sessionId；WS 重连自动重新 subscribe 状态：忽略无 traj 的 attach 广播，避免误锁；登录结束后刷新 watcher 状态
5. Fix BiB input routing with resolveBibTarget, boot rehydrate, and lifecycle acceptance.
6. 在 scripts/session_runner.py 里为 Linux root 自动加上： --no-sandbox --disable-setuid-sandbox --disable-dev-shm-usage
