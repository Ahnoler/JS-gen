# 正向样例（较密 · 学步骤结构）

模块文案仅作形态参照；换模块时替换页名/ZJJK/对象名，保持「进页→定位→一项能力→断言」结构。

## 1. 维护产品基本信息

- produces: `["已维护产品信息"]`
- dataDependsOn: `[{"key":"产品","source":"atom"}]`

```
1、进入查看产品信息主页，等待加载（ZJJK00107304）
2、搜索/定位并选中已有「产品」
3、维护基本信息字段
4、【保存】成功

来源：… / chapters/…

关键数据
产品：KB测产品
已维护产品信息：KB测产品信息
```

## 2. 设置产品阶段（弹窗）

- produces: `["产品阶段关系"]`
- dataDependsOn: `[{"key":"已维护产品信息","source":"atom"}]`

```
1、进入产品阶段主页，等待加载（ZJJK00094364）
2、定位并选中已有产品
3、点击【设置阶段】
4、在弹窗选择阶段
5、【确定】保存成功

来源：… / chapters/…

关键数据
已维护产品信息：KB测产品信息
产品阶段关系：KB测阶段关系
```

## 3. 设置管控要素（多页仍一项能力）

- produces: `["产品管控要素"]`
- dataDependsOn: `[{"key":"产品阶段关系","source":"atom"}]`

```
1、进入产品阶段主页，等待加载（ZJJK00094364）
2、定位并选中已有「产品阶段关系」
3、点击【设置管控要素】
4、进入产品要素编辑主页（ZJJK00098070），通过【添加组件】/【配置单一要素】/【配置组合要素】等维护产品组件列表
5、点击【保存】成功

来源：… / chapters/…

关键数据
产品阶段关系：KB测阶段关系
产品管控要素：KB测管控要素
```

## 4. 查询产品信息

- produces: `["产品查询结果"]`
- dataDependsOn: `[]`

```
1、进入查询产品信息主页，等待加载（ZJJK00095907）
2、填写产品名称、产品编号、产品状态、产品目录等查询条件
3、点击【查询】
4、列表展示符合条件的产品记录
```
