📋 当前三大问题 & 解决方案

执行层 · Browser Use
1AI探索时 Element UI 组件无法操作
面对 Element UI 组件（下拉框、级联选择、日期选择器等），Agent 时常无法进行正确的浏览器操作。 目前已经重写了 Browser Use 的默认浏览器操作，大部分操作和场景已可识别， 但完整的测试尚未完成。阶段任务的断言功能当前会导致阶段任务错误终止，已暂时移除。
完成 Browser Use 新操作的完整测试，验证内置 system prompt 是否正确注入、 注册新操作列表，以及新操作是否满足 Element UI 组件的需求。 同时完善阶段任务断言逻辑，保证阶段任务状态是根据任务结果正确设定。
AI 层 · 知识库 / LLM
2表单特殊规则输入正确率低
面对含有特殊规则（如 18 位身份证、手机号等）的输入框，Agent 常常无法根据 Element 知识库 自主正确填写。点击保存后看到错误提示，有时能自行纠错解决，有时不能。 总体正确率约 50%。
完善 Element 知识库，提供级联操作选择树，应对多种操作场景，实时引导 Agent 操作。 考虑提取技能内置的 Python 代码作为一个完整的 Python 程序，Agent 可以自行运行程序 生成对应的数据（如身份证、手机号等标准规范数据）。
AI 层 · Playwright-skill
3脚本生成定位精度不足
Playwright-skill 使用过程中会自行使用 locator 或 text 进行模糊定位， 而不是操作历史文件中的 XPath 精确定位，导致生成的脚本质量层次不齐， 需要二次修正脚本瑕疵。
解决特殊规则技能注入却没有生效的问题，重新精简技能结构， 建立索引和查询机制。确保技能中的定位策略能正确覆盖到 XPath 精确定位方式。
