- **select_tree_option(label_text, option_text) — 仅用于真正的 TsscMultiTree 树形选择器（如行业代码、分类目录）。三段式匹配：P0 精确匹配（label/id）→ 非叶节点 DFS 取第一个叶后代；P1 UI关键词搜索 → 过滤列表下非叶节点 DFS 取第一个叶后代；P2 兜底取全树第一个叶节点。** **`option_text="first"` 会直接选第一片叶子（`ok-fallback:first`），是正常结果。`ok-fallback` 同理——系统已选最接近的叶节点。信任该结果，不要重新填写。** **🚨 若返回 `disabled`：字段只读（如新增弹窗里由侧栏树带出的「分类目录」）——禁止再 select/fill，跳过即可。** **🚨 若返回 `no-tree-component`：字段不是 TsscMultiTree（页面侧栏 `.el-tree` 也会误导）——禁止再次调用 `select_tree_option` / 禁止 check↔select 空转。立刻改用 `fill_form_field(label, 具体值)`（不要用 `"first"`），或若是 el-select 则用 `select_option`。`ok-fill-fallback` 表示系统已自动改用 fill 并成功，视为已完成。**

- **tree_check_confirm(label_text, node_text) — 勾选树（show-checkbox el-tree，如「流程选人」、多选目录/要素树）。一次注入完成：触发字段 → 定位 node_text 节点 → 真实勾选（预设勾选态自动双击收尾，确保真实 check 事件写入所选列表）→ **校验**（节点 is-checked 且树内勾选数≥1）→ 返回 `ok`。**只勾选；确认按钮（弹窗「确 定」）由你用 `click_save(button_text='确 定')` 点击（click_button 点保存类会被守卫拦截并返回 err-use-click-save）。** 失败语义：**`err-tree-node-not-found`**=触发后 1.5s 内未见节点（先查是否展开了目录/是否弹窗未开）；**`err-tree-check-unverified`**=勾选态未确认（所选列表未写入——不要盲目重试，检查状态后改用 click_button 节点文本兜底或上报）。与 select_tree_option 的分工：**单选叶子树（行业代码等）=select_tree_option；多选勾选树（选人/目录）=tree_check_confirm**。

- **tree_picker_click(label_text, path_texts) — 品种/产品树逐级点文本选叶（「维护方案品种明细」等产品树弹窗，$emit 三段式注入对该组件不触发时用这个）。path_texts 为根→叶节点文本 JSON 数组串，如 `["贷款","对公","房地产贷款","住房开发贷款"]`。一次注入完成：打开触发器 → 逐级真实点击节点文本（每级等展开）→ **校验回显**（field input 回显含叶子文本）→ 返回 `ok`（含 echo）。只负责选叶，弹窗确认按钮（「确认」，无空格）由你用 `click_save(button_text='确认')` 点击（click_button 点保存类会被守卫拦截并返回 err-use-click-save）。失败语义：**`err-tree-node-not-found`**=某级节点 2s 内未渲染（检查路径拼写/弹窗是否打开）；**`err-tree-no-echo`**=叶已点但 input 未回显——**不要盲目重试**，先 check_field_value 读状态或上报。与另外两个树动作分工：**$emit 无效的产品/品种树=tree_picker_click；单选叶子树（行业代码等）=select_tree_option；多选勾选树（选人/目录）=tree_check_confirm**。
