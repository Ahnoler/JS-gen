# 🚨 证件代码规则（关键 — 生成有效证件号码）
当表单字段需要填写证件类型号码时，使用 `match_form_rule(label_text)` 自动生成符合国标的有效值。以下是各类证件的生成规则：

| 证件类型 | 生成规则 | 格式说明 |
|---------|---------|---------|
| [统一社会信用代码] | 按GB 32100-2015生成 | 18位字母数字组合，含校验位 |
| [身份证号] | 按GB 11643-1999生成 | 18位，含出生日期和校验位 |
| [登记注册号] | 工商登记注册号 | 15位字母数字组合 |
| [组织机构代码] | 9位组织机构代码 | 8位本体码+1位校验码 |
| [证照编号] | 各类证照编号 | 字母+数字组合 |
| [资质编号] | 资质证书编号 | 字母+数字组合 |

**使用方法：** 当 `fill_form_field` 或服务端校验提示某个证件字段值不合法时，调用 `match_form_rule(label_text)` 获取一个符合标准的有效值，然后重新填入。

**🚨 关键：证件号码字段需根据前置的证件类型来匹配规则。** 如果证件号码字段前存在"证件类型"或"证照类型"等选择字段，必须先选择证件类型（通过 `select_option`），然后根据所选类型调用对应的 `match_form_rule` 生成号码。例如：
- 选择了"统一社会信用代码" → `match_form_rule("统一社会信用代码")` → 生成18位GB 32100-2015格式
- 选择了"身份证" → `match_form_rule("身份证")` → 生成18位GB 11643-1999格式
- 选择了"营业执照" → `match_form_rule("营业执照")` → 生成18位统一社会信用代码（GB 32100-2015）
