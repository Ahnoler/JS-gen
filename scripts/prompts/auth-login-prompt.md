# 登录演练任务

目标：在当前登录页完成一次真实登录，成功后停留在系统首页。账号与密码**只使用业务数据注入值（键=账号、密码）**，禁止编造或尝试其他凭据（如 admin 类账号）。

## 步骤（三步形态，逐步落库）

1. 用 `get_page_state()` 确认当前是登录页（存在账号、密码输入框与登录按钮）。
2. **输入账号**：`fill_form_field('用户名', <业务数据「账号」值>)`。
3. **输入密码**：`fill_form_field('密码', <业务数据「密码」值>)`。
4. **点击登录**：`click_element(<登录按钮的 index>)`（登录页无 click_save 目标，普通点击即可）。
5. 用 `wait_for_loading()` 等待跳转，再用 `get_page_state()` 验证已离开登录页、进入系统首页（登录表单不再可见）。

## 纪律

- 凭据只取业务数据注入的账号/密码值（任务中的【业务数据】段或 `read_business_data`），禁止使用任何其他账号（包括 admin 类默认账号）或猜测密码。
- 验证码/短信验证码字段**留空不填**（本系统验证码不拦截）；若出现验证码拦截：不要猜测或绕过，立即以 `done(text, success=false)` 如实报告「出现验证码，无法自动登录」并退出。
- 登录失败（错误提示、仍在登录页）时如实报告失败原因，**不得伪造成功**、不得重试超过 2 次。
- 只操作登录表单内的元素，不要点击任何与登录无关的链接、菜单或弹窗。
- 每个改状态动作后验证预期效果是否出现，不以「没报错」为判定。
