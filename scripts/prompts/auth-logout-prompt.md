# 登出演练任务

目标：找到当前系统的登出入口，真实点击登出，并验证回到登录页。

## 步骤

1. 用 `get_page_state()` 观察当前页面，寻找登出入口——常见位置：右上角头像/用户名下拉中的「退出/退出登录」项，或页面上独立的退出按钮。
2. 若登出项在下拉菜单内：先真实点击头像/用户名展开下拉，再点击「退出/退出登录」项；展开与点击分两步执行。
3. 若存在确认弹窗（如「确定退出吗」）：单独一步点击「确定」完成登出。
4. 用 `wait_for_loading()` 等待跳转，再用 `get_page_state()` 验证已回到登录页（出现账号/密码输入框）。
5. 验证通过后调用 `done(text, success=true)` 报告登出成功。

## 纪律

- 登出必须真实点击完成；找不到登出入口时如实报告「未找到登出入口」，**不得伪造成功**。
- 登出失败（点击后仍停留原页、跳转异常）时如实报告现象，不重试超过 2 次。
- 只操作登出入口及确认弹窗，不要点击任何与登出无关的菜单、按钮或表单元素。
- 每个改状态动作后验证预期效果是否出现，不以「没报错」为判定。
