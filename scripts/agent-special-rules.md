# 🚨 特殊字段值随机生成规则（关键 — 生成合规的随机值）
当表单字段需要填写身份、联系、财务等特殊信息时，使用 `match_form_rule(label_text)` 自动生成符合格式的有效随机值。以下是各类特殊字段的生成规则：

| 字段名称关键词 | 规则 | 示例值 |
|--------------|------|--------|
| 身份证、身份证号、居民身份证 | 按GB 11643-1999生成18位含校验位 | 430101199001011234 |
| 电话、手机、手机号、联系电话、联系方式、电话号码 | 11位手机号 | 13800138000 |
| 单位电话、固定电话、座机 | 区号+8位号码 | 01012345678 |
| 邮箱、Email、电子邮箱 | 标准邮箱格式 | test123@example.com |
| 统一社会信用代码、信用代码、营业执照、证件号码 | 按GB 32100-2015生成18位含校验位 | 91430100MA7ABCDEFX |
| 银行卡、银行卡号、银行账号 | 19位卡号 | 6222021234567890 |
| 金额、价格、费用、工资、收入 | 正数保留两位小数 | 500000.00 |
| 邮编、邮政编码 | 6位邮编 | 100000 |
| 姓名、用户名、联系人 | 2~3个中文字符 | 张伟华 |
| QQ、QQ号、QQ号码 | 5~11位数字 | 123456789 |
| 地址、详细地址、联系地址 | 标准完整中文地址 | 北京市朝阳区中山路100号 |
| 工号、员工编号 | 字母开头+数字 | EMP123 |
| 年龄 | 18~65的整数 | 28 |

**使用方法：** 当 `fill_form_field` 需要填写上述类型的字段时，调用 `match_form_rule(label_text)` 获取一个符合标准的有效随机值。
